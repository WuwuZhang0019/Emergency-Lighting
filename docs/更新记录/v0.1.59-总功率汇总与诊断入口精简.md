# v0.1.59 总功率汇总与诊断入口精简

日期：2026-10-16
状态：源码及 26 项定向检查通过；按用户要求提供 CAD2020 试用包，原生 AutoCAD 验收待执行

## 总功率汇总

在回路列表与第三步之间增加一行总功率，按当前回路包含的设备实例去重汇总，预留回路不计入。功率未填或连接仍待核对时显示“已知总功率”，详细原因输出到命令行；未拾取前显示“总功率：未统计”。移除容量选项下方的默认值说明及对应空白行。

## 诊断入口与底部布局

“导出诊断日志”和“打开所在文件夹”合并为“导出诊断日志并打开文件夹”。完成本次导出后自动打开资料所在位置，再返回原面板。每次点击先清空上一次结果；导出失败时保留原始原因，不打开旧结果或未完成目录。打开失败时弹出本次完整路径，便于手动打开。

移除诊断路径标签、文本框、单独的打开按钮、底部提示及取消按钮。退出交由原生 Esc 处理；必要的生成错误继续弹出说明，详细信息写入命令行，不再占用底部反馈区域。
