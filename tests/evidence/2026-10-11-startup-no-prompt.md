# 启动二次选文件回归修复
日期：2026-10-11
状态：31 项定向检查通过；真实 AutoCAD 2020 待复测

## 原因和修改

提交 493e0de 为让日志回到交付包目录，在 EL:StartupRoot 的自动发现与记忆目录均失败后插入 EL:StartupSelectRoot。该函数调用 getfiled，发生在内嵌资源释放之前，因此 066 的无弹窗启动行为出现回归。

移除启动路径内这次人工选择。启动仍按注册表、搜索路径、记忆的有效交付目录自动定位，失败后直接使用内嵌资源初始化当前用户本地运行目录。主动输入 ELROOT 时仍可选择交付包并记住日志位置；初始化失败不报告就绪，不弹选择框。

## 检查和交付协调

`python -X utf8 -m unittest discover -s tests -p test_root_init.py`：31 项通过。覆盖无注册表和搜索路径、重复启动、资源不完整、错误版本、写入失败时零弹窗；记忆目录和 ELROOT 主动切换仍有效。测试同时构建临时包并检查 GB2312、ZIP 和 LISP 解析。

本修复不修改 UI 源码、不递增 PACKAGE_NO、不覆盖 output 根目录下的正式交付包。另一个对话负责界面乱码并计划统一发布 082；最终构建会自动包含本次 src/startup.lsp 修改。独立验证包输出在 output/startup-no-prompt-validation 下，仅用于本次验证。

## 真实 CAD 复测

加载统一交付包的 START-CAD2020.lsp，应直接显示插件数据目录与就绪提示，不再要求选择文件。自动发现失败时数据保存在命令行显示的 LOCALAPPDATA 运行目录；旧解压包配置不会自动迁移。主动输入 ELROOT 才应弹出目录选择。自动检查不等于真实 CAD 验收。
