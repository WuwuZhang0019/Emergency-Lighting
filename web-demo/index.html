用一分钟，走完设计流程。

  1. 点击“开始体验”，或先在平面图中点选绿色配电箱，再识别回路。
  2. 点击回路行或彩色导线，查看设备归属；修改默认功率，观察实时统计。
  3. 点击“试试断开末端导线”，查看末端设备退出统计，随后恢复连接。
  4. 点击“生成当前箱系统图”，下载 SVG 矢量图和 CSV 统计清单。

体验范围

本页是 CAD 项目的独立浏览器简化适配版，基于两张人工构造的教学示例，实际执行二维直线导线连通搜索、矩形设备区域接触、整数功率汇总及系统图绘制。导线中段单纯交叉不会自动并为回路；空功率保持待核对。

本页不包含 DWG / DXF 导入、天正专有对象、复杂曲线与完整 CAD 几何规则，也不连接本机 AutoCAD。生成图仅供功能体验，不作为施工图或规范审查结论。

原项目与使用方式

原 CAD 项目版本为 v0.1.84。网页无需安装、登录或联网，全部计算在当前浏览器完成；刷新页面会恢复示例初值。使用 Edge、Chrome 等现代浏览器打开本 HTML 文件即可。
