# 03 加载、使用与验收说明

日期：2026-10-08。状态：源码及自动检查已交付，CAD 实测待执行。

## 1. 运行条件与加载

首版使用 AutoLISP、Visual LISP ActiveX 和 DCL，目标为 Windows AutoCAD 2021+，`LISPSYS=1` 或 `2`（修改后需重启）。Mac、LT 和其他 CAD 平台未验证。图纸须保存；识别范围为当前 DWG 模型空间二维对象。

将整个仓库放在可信且可写的本地目录，保留 `src/`、`ui/`、`config/`、`output/` 的相对结构。可将 `src/` 加入支持文件搜索路径后 APPLOAD `src/load.lsp`；也可在 CAD 命令行明确设置根目录再加载：

```lisp
(setq *EL:Root* "D:/CAD/Emergency-Lighting/")
(load (strcat *EL:Root* "src/load.lsp"))
```

未找到根目录时，加载器会请用户选择本插件的 `src/load.lsp`。配置和结果使用 UTF-8 数据关联表，读取使用 `read` 和字段校验，不执行配置中的代码。首次生产使用前完成下面的 CAD 清单。

配置读取和保存也会检查插件目录。根目录为空、类型错误或文件已移走时，选择完整包内的 `src/load.lsp` 即可重新定位；取消选择会停止本次操作，不会继续拼接空路径或建立配置。已有完整有效的目录和图纸设置继续沿用。AutoCAD 2020 兼容包的 `UPDATE-009.lsp` 可在尚未设置根目录的当前 DWG 中加载，只有目录检查通过后才显示可用提示，无需手工输入路径命令。

## 2. 命令与操作顺序

| 命令 | 用途 |
| --- | --- |
| `ELSETUP` | 采样箱体、导线、设备图层，可沿用已有采样；单位固定 mm，无需确认；参数回车直接采用显示值，输入 2 调整；首次或改动后输入 1 确认启用统计，回车保存草稿；已确认且未改变的毫米配置沿用确认结果；有效配置保留功率、模板和配对，失效配置先留备份 |
| `ELSAMPLE` | 追加 Panel／Wire／Device／Leader 样本；同层角色须登记相应块身份 |
| `ELGAPTEST` | 点选具体断口端点，临时高亮源／目标／竞争端点，查看拒绝理由；不保存配对、不生成图形实体 |
| `ELTRACE` | 拾取箱体，逐条核对出线候选（进线选 No），建立隔离回路并列出设备及诊断 |
| `ELPAIRGAP` | 明确拾取两个端点，说明人工例外原因，经端点占用／层与平面／全局出线隔离检查后保存；核对采用该箱体全部出线候选，若进线同层，先完成样图校准 |
| `ELPAIRLEADER` | 拾取一对跨层引线，登记引线身份，保存双向关系；正式统计仍检查整体归属 |
| `ELCLEARPAIRS` | 明确清理本图 Gap 或 Leader 配对，随后重新识别 |
| `ELSTAT` | 依次执行识别和功率表；功率表每次修改行后点“保存此行”，最后 OK 应用 |
| `ELPOWER` | 使用仍有效的统计重新编辑功率，保存并重算，无需重新追踪 |
| `ELISSUES` | 列出连接、功率和独立对象问题，选择序号高亮对应句柄；下一次拾取命令清理定位高亮 |
| `ELSAVELIB` | 把本图确认值存入项目设备库；同名但定义／动态状态不同的设备须重新核对 |
| `ELSAVERESULT` | 保存统计、连接依据和问题快照到 `output/` |
| `ELTEMPLATE` | 采集真实箱体／回路动态属性、三档样本、接线点、各档文字样本和排列向量 |
| `ELGEN` | 检查统计有效性、172W、真实属性映射，选择档位、顺序、预留、插入点及旋转缩放，临时预览后确认生成 |

采样、统计箱体、断口/引线配对和模板采集中的对象拾取会持续亮显，并在命令行显示对象类型、图层及句柄。已拾取的样本在选择下一个样本和核对参数时仍保持亮显；当前命令正常完成、取消或出错后统一清理。统计时确认的出线保持亮显，选 No 的候选取消亮显。亮显只改变显示反馈，不修改对象颜色、图层或几何。实际 CAD 上的视觉效果仍需实测。

`ELGAPTEST` 可先独立运行。缺少角色配置时，临时采集导线层，只显示几何试查。v9 起，没有已保存参数时自动采用默认值，不再逐项要求回车；已有自定义参数则直接沿用。没有箱体上下文时不宣称全局通过。有仍有效的箱体结果时，同时显示全局检查结果，仍不提交此次预览。

### 断口预览菜单及超过 200 mm 的断口

输入对应字母后回车，也可输入完整英文选项：

| 输入 | 操作 |
| --- | --- |
| `N` / `Next` | 重新点选另一处断口 |
| `S` / `Swap` | 检查当前同一段导线的另一端，不是切换到对面的导线 |
| `R` / `Range`（v9 新增） | 只修改最大搜索距离，并立即重查当前端点，不必重新拾取 |
| `P` / `Params` | 显式进入高级参数逐项调整；回车保留当前值，调整后重新点选断口 |
| `L` / `Locate` | 将视图放大定位到当前端点，退出时恢复原视图 |
| `D` / `Details` | 显示候选、拒绝原因和当前参数；超出搜索范围的对象不在候选列表内 |
| `E` / `Exit` 或直接回车 | 退出并清理临时预览，不保存连接 |

200 mm 是默认搜索上限，不是允许的最大断口长度。例如实际断口约 350 mm，可输入 `R`，再输入 `500`，重查当前端点；其他偏差参数保持原值。扩大范围后仍必须通过方向、偏移、端点占用等检查，多候选不能凭最近距离认定连接。

`R` 和 `P` 仅调整本次预览；退出不保存参数。正式统计需要在 `ELSETUP` 的参数选择中输入 `2`，设置同样的最大搜索距离并核对。仅显示“无合格候选”不能认定一定是超过 200 mm，也可能点错端点或未通过几何条件。

若运行后出现 `numberp: nil`，先确认当前 DWG 已加载最新完整包的 `UPDATE-009.lsp`。v9 包含先前的空值比较修复，并补齐多段线标志缺失时的默认值。异常提示会附加 `ELGAPTEST 失败阶段`；若发生在对象采集阶段，还会显示对象句柄、类型和图层。保留从 v9 加载提示到报错的完整记录用于定位，不要仅凭此错误修改几何容差。

### 参数提示如何选择

`ELGAPTEST` 自动沿用保存值或采用默认值，无需逐项确认。以下数字提示用于 `ELSETUP`：旧版 `Keep` 的意思是采用屏幕显示的参数，`Custom` 才是逐项修改。现在改为中文数字提示：**参数选择时回车或输入 1 直接使用显示值，输入 2 才调整**。调整时各项回车保留当前值，不会重置已保存的自定义参数。单位固定为 `mm`，不要求输入，也不修改 CAD 图形尺寸。

“误差”是判断接线是否接触、两段断线是否对齐时允许的绘图偏差。当前建议值用于试查，尚未针对用户实际 DWG 校准：

| 屏幕参数 | 用途 | 当前建议值 |
| --- | --- | --- |
| 线端允许接触偏差 | 判断普通线端之间是否接触，应小于实际断口长度 | 0.1 mm |
| 线端到设备轮廓允许偏差 | 判断导线端点是否接触灯具或配电箱轮廓 | 0.1 mm |
| 断口横向允许偏差 | 判断打断的两段线是否左右错位过大，要结合相邻回路间距核对 | 0.5 mm |
| 导线高程允许偏差 | 排除不同高程的导线 | 0.01 mm |
| 断口方向允许偏差 | 判断两段线是否接近共线且相向 | 0.01 rad，约 0.57° |
| 断口初始搜索距离 | 初始搜索范围，不能据此提前认定唯一连接 | 20 mm |
| 断口最大搜索距离 | 搜索上限，超出范围的断口不会自动找到 | 200 mm |

最大搜索距离不是固定断口长度，也不是把范围内所有导线连接起来；还要检查方向、横向偏移、端点占用和回路归属。不要只增大容差来消除识别问题。

**末尾的“识别参数确认”是另一项选择：未核对时回车或输入 2 保存草稿；已核对后输入 1 启用统计。** 草稿保存后，用 `ELGAPTEST` 检查典型断口、最大断口及邻近回路，确认应连接的目标正确且没有误选邻近回路，同时核对正常接线的偏差，再运行 `ELSETUP` 沿用采样和参数并确认。局部预览通过不代表整箱统计已通过，正式统计仍检查回路归属。

已确认且采样、参数数值和毫米单位未改变时，不重复询问确认。重新拾取样本、更改参数或将旧配置单位改为毫米后，须重新确认；配置保存失败时不显示成功。

## 3. 功率、模板与结果有效性

未知设备必须确认类别。照明灯默认 5W，疏散／出口标志默认 1W；本次输入优先于本图保存值，再优先于设备库。功率只接受非负整数；0W 要明确确认用途。超过 172W、未解决断点、归属冲突和功率缺项均阻止生成。整数运算超范围时报告 `POWER_OVERFLOW`，不输出正常总功率。

模板采集需要两种动态块的六个已显示正确档位的参考实例：箱体 0.3kW、0.6kW、1kW；回路普通、地面、预留。程序从真实属性列表选择档位属性，读取当前真实值及 AllowedValues，不猜测“可见性”等名称。各档点选接线定位点，回路各档再拾取 TEXT／MTEXT 统计文字样本，最后点选箱体相邻两个接线位置取得排列向量。模板样本须为正等比缩放，字体必须存在，输出图层与平面角色图层分开且可见、未冻结、未锁定。保留采集时最后一个箱体／回路样本，生成前会重新检查其属性允许值；删掉样本后重新采集。

实际回路文字模板必须含 `{回路功率W}`，还可用 `{回路编号}`、`{设备数量摘要}`；预留使用独立文字，不伪造 0W 和数量。实际回路只能选择普通或地面；预留须新增。预览显示各档采集轮廓、文字定位标记和逐回路文字明细；字体、动态块最终外观须通过真实模板的 CAD 视觉核对。

修改接线、块状态、几何参数、角色或配对后重新运行 `ELSTAT`；只修改功率可用 `ELPOWER`；只修改模板则重新排布。生成前和预览确认后均检查源快照。首次生成不会覆盖旧图；本次对象组成一个撤销组，失败只清理本次创建对象，启用 UNDO 且不存在外部未结束撤销组时才生成。

## 4. 已支持边界与保留项

导线支持 LINE 和开放 LWPOLYLINE，使用真实邻接线段的端部方向，允许内部转折和弧段。弧形断口没有自动延续模型，明确报告不支持；可用人工例外确认，但不能绕过平面、图层、端点占用或回路隔离。T 接、闭合线路、异常分支和其他配电箱均保留诊断。自动候选用完整范围全量扫描，未实现空间索引；大图性能待测。

图块轮廓读取当前块记录中的可见 LINE、LWPOLYLINE、CIRCLE、ARC 和嵌套 INSERT，忽略文字／属性，应用旋转、镜像和非等比变换。圆弧采用受控离散（局部误差按变换尺度限制到边界容差约 1/8，最多 4096 段）。实际灯具的内部几何、动态可见状态和接线轮廓仍需样图适配与核对。倾斜平面、外参、其他轮廓实体或退化轮廓报告不支持；不支持对象的包围盒只用于阻止未经验证的连接，不能作为确认连接的依据。

图纸配置以保存路径隔离；改名／另存后建立新配置。人工断口配对保存端点、参数和整个处理范围快照，删除、移动、反转、改层或新增干扰对象时停用；这是一项保守校验，周边无关变更也可能要求重新确认。跨层配对另检查两个实例及其状态，并排除负载统计。跨 DWG、外参内部对象和任意弧端续接未实现。

## 5. 自动验证与合成 CAD 样例

在仓库根目录运行：

```bash
python3 tests/fixtures/generate_fixture.py
python3 tests/run_checks.py
```

自动检查读取实际 LSP 源码，在有限 AutoLISP 测试宿主中执行纯函数，另做源结构、DCL 键／回调语法和替代接口测试；不等价于 AutoCAD 编译或运行。证据为 [automated-checks.json](../tests/evidence/automated-checks.json)，包含各测试结果、基线参数和源码 SHA-256。

可在 CAD 中打开 [cad-plan.dxf](../tests/fixtures/cad-plan.dxf)，另存为测试 DWG。此 DXF 由脚本合成，尚未在本环境导入 CAD。箱体 `(100,100)`，三条出线接入 `(110,80)`、`(110,100)`、`(110,120)`。按 [预期文件](../tests/fixtures/cad-plan.expected.json) 确认 ELA_LAMP 为照明 5W，ELA_SIGN 为标志 1W，预期各回路分别 10W、2W、5W，总计 17W。首回路有 20 单位断口及独立横穿线；横穿线两端应作为独立问题展示，不阻止当前箱体完整。该样例没有真实动态块，不能用于 P05 模板验收。

集中 CAD 验收按 [验收清单](../tests/evidence/cad-acceptance.md) 逐项记录；真实样图参数不能照抄合成值。
