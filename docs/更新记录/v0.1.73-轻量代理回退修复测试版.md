日期：2026-10-21
状态：本地完整测试版；原图识别耗时、预览及生成待复测，未合并、未推送、未发布

## 加载

1. 完整解压`应急照明-v0.1.73.zip`。
2. APPLOAD加载根目录 **ELFULL73.lsp**，再输入 **ELFULL73**，确认显示`v0.1.73`。同一CAD会话也执行这个新命令，避免旧入口继续运行旧版本。
3. 自包含后备目录为`%LOCALAPPDATA%/Emergency-Lighting/runtime-172/`，内部标记`package-172.marker`。实际诊断路径以命令行显示为准，完整目录加载时可能写入本包output。

交付LISP/DCL使用严格GB2312无BOM，供简体中文Windows AutoCAD 2020测试。旧v0.1.72包和runtime-171保留，CADTools菜单没有更新；不要直接加载UTF-8源码或混用旧模块。

## 本轮修复

- `c2f3bef`：轻量包络的局部`length`改名为`chord-length`，避免原生函数遮蔽；记录具体校验回退原因和捕获的异常原文，每次调用清空旧原因。
- `5a5c19b`：每批汇总回退原因和至多三个首例；全部导线回退时直接继续原完整识别，跳过新增依赖发现与候选保序。完整源事实、配色来源、编号和源新鲜度保护继续保留。

正常及部分回退仍沿拾取起点发现依赖，远端回路、断口候选/竞争/阻挡、设备链和反向T按原规则处理。本轮没有修改接触容差、编号分配、预览绘制或生成流程；当前ZE1仍可能来源auto，未修复天正注记正文不可读。

v72日志显示3067条导线全部回退，新增发现3.765秒、保序9.890秒；它们均包含在采集总时间内。整箱识别38.188秒，最后拾取完成至首个结果面板40.297秒。v71相同边界为29.281和32.266秒。本版真实原图秒数待测，不用适配器运行时间估算实际提速。

## 原图复测

1. 使用相同商业照明测试副本、F072箱体、四个起点和方向、相同配置及设备库。使用默认模式0；若此前切换过ELPERFAB，关闭初始面板后恢复0，再运行ELSTAT。
2. 观察最后一条导线拾取并按Enter完成，到结果面板显示的等待；首次与重复识别分别记录。
3. 核对38设备、4实际/2预留、总94W，ZE1为73W、ZE2～ZE4各7W，编号/UID/功率整条对应。
4. 查看全部回路和单回路预览、退出恢复，再生成新系统图，检查闪回、遗漏或错配。保存重开及原生Undo/Redo另在副本核对。
5. 每轮完成或取消后立即运行 **ELDIAG**，在开始下一轮、重新加载或关闭图纸之前保留完整诊断压缩包。说明是否生成、是否预览，便于分离阶段。

## 日志判断

| 字段或事件 | 含义 |
| --- | --- |
| `root-scope-proxy-wires` | 真正成功构造轻量代理的数量 |
| `root-scope-wire-fallbacks` / `root-scope-fallback-reasons` | 性能会话累计回退数及原因分布 |
| `ROOT_SCOPE_FALLBACKS` | 单次采集的原因分布和首例；每类最多一个，总计最多三个 |
| `root-scope-all-fallback-bypass` / `ROOT_SCOPE_BYPASSED` | 全部回退时跳过新增发现与保序；无导线单独记录，不算全回退 |
| `source-wire-record-reads` | 实际完整精算读取，包含保守回退及发现/保序所需依赖 |
| `root-scope-light-wires/fine-wires/skipped-wires` | 输入清点、发现后精细依赖和跳过数；light数不能代表代理成功 |
| `recognized-connected-wires/devices` | 最终本箱连通结果，原图参考40条导线和38设备 |

若仍全部回退，应看到旁路事件，且该批不再执行`ROOT_SCOPE_DISCOVERY`、`ROOT_SCOPE_CANDIDATE_ORDER`；异常类会保留原始错误。代理成功后，精算可能包含未连通竞争/阻挡和保序依赖，数量可以大于40。原始候选范围仍可能7850，不能当作本箱设备数。

程序回归覆盖旧写法冲突复现、修复清空旧原因、全回退冻结对照、混合代理、远端追踪、编号/实际预览、源变更和owner/epoch保护。精确测试结果见`tests/evidence/2026-10-21-v0.1.73-root-scope-fallback-fix.json`；严格GB2312、ZIP/目录一致、四入口和内嵌资源检查见`tests/evidence/2026-10-21-performance-trial-package-v0.1.73.json`。这些检查不代替原生CAD耗时、图面、生成、保存重开与Undo验收。
