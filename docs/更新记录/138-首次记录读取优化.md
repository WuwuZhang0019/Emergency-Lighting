## 本次修改

- 整数压缩串每块最多 224 字符，改用一次原生 `read` 解析这一小块，减少逐整数搜索、切片和转换。传入 `read` 的字符串含自加括号最多 225 字符；读取前限定为数字、负号和空格，读取后检查全部值都是 32 位整数，并将完整规范文本逐字符比对。保留溢出、空值、重复空格、前导零、非法符号和不完整解析的拒绝路径，不执行 `eval`。
- REAL 坐标继续使用原生 DXF 40 双精度值；原始字符串和 REAL 均不进入新的整数文本解析路径。列表内连续 REAL 直接取值，减少递归调用，保留精确值和类型。
- 内联高频取值与原子索引访问，正常分支直接检查条件，仅在失败时调用错误报告函数；用一次原生遍历同时确认普通列表形状和长度。
- 保持 `EL_COMPACT_TYPED_V3` 格式及旧格式兼容，保留完整结构、引用边界、尾部、模板副本一致性检查，以及 `dictsearch` / `entget` 原生载荷核对和缓存身份校验。
- 新增 `STORE_UNPACK_INTS`（展开整数数据）和 `STORE_VALUE_DECODE`（还原记录字段结构）计时，进一步拆分原来的 `STORE_EXPAND`。
