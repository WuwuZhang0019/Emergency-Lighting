## 修改

1. 当前流程已经取消历史源图回放和旧图原位更新。`EL:InputRecord` 将新保存记录标记为 `input-record-version = 2`，不再复制 `source-signature`、`draft-source-signature` 的整张源图几何。功率、容量、设备覆盖、回路编号、起始导线配置、回路身份、结果、模板及出图关联照常保存。完整识别结果仍在当前命令内存中供实时校核，不能将轻量记录用作源图未变化的凭证。
2. 首次输入保存仍在原生放置之前完成。编码格式继续使用既有 V3，完整回解、逻辑记录比较、`dictsearch` 与 `entget` 两路原生载荷检查、提交后的核对和失败回滚保留。旧记录可继续读取；其他配电箱的记录及其原始快照不因本次保存被改写。
3. 识别时保留本次采集依据，仅在同一命令、同一 DWG 和完全相同的识别配置/结果下尝试复用。放置后重新获取完整选择集，逐个读取原生 DXF，核对所有已采集块的外包范围、已使用的有效块名、导线图层表及箱体轮廓。对象增删、移动、宽度、线型、图层、配置或范围变化会回到完整采集路径。
4. 即使上述原生数据未变，仍重新读取网络曾使用的设备实例和定义几何。块名及外包范围相同、内部轮廓变化也会触发重新构网并拒绝旧结果。编号、设备库、模板、事务和交互边界检查保留。只有这些检查通过，才省去导线几何重建、候选空间树和稳定快照的重复计算。
5. 新增 `SOURCE_NATIVE_VERIFY` 计时及原生对象/范围核对、派生结果复用计数。`FRESH_SOURCE_SCAN` 显示为“核对当前源图”，继续包含实际核对耗时。统计方式没有隐藏鼠标等待或把工作移到计时区间之外。
