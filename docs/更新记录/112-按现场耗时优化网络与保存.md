## 实施范围

1. 网络缓存排除仅供系统图输出使用的 `template` 配置；其余配置、完整新采集快照、图纸身份与设备几何仍精确核对。进入面板补入模板不再让第一次保存无故重建网络。
2. 空间索引为每项预先生成一次排序键，避免每次递归排序比较重复转换；树内保留原始对象。
3. 断点互选使用端点与候选行索引，减少重复解释执行的全表查找；保留互相唯一、遮挡、高程、距离及真实接触判定。
4. 候选图块范围减少自环与双向重复边；完整候选范围仍参与连接计算。
5. 保存回读复用诊断阶段已经提取的两路原始字段，省去再次遍历。仍逐字段精确比较 `dictsearch` 与 `entget` 的完整载荷，保留写前编码往返、损坏诊断、事务和提交后回读。
