# 115 功率图例刷新与生成后保存优化
日期：2026-10-13
状态：代码与定向检查完成，原图 CAD 复测待执行

## 现场依据

用户提供 `ELPERF (6).log`、`ELTRACE-debug (25).log` 及 114 包截图。完整日志最终为 `FAILED`，错误为“函数已取消”，最后可见事件为 `LEAVE UNDO_END`。不能将图形已经出现等同于命令正常结束。

- 总用时 235531 ms，程序用时 116593 ms，放置后程序用时 74891 ms。
- 两次写库保留生成前草稿和生成后正式记录，最终记录有 477016 个 DXF 字段。
- 正式记录序列化 8563 ms，预解码 6422 ms，替换字段 5609 ms，两路回读阶段 10860 ms。
- 全流程采集源图五次，其中包括四次新鲜度核对；检查阶段有重叠，不能直接把所有阶段时长相加。
- 功率输入后相同行从原图块名切换为设备库名称，而图例缓存仍使用原名称，导致预览查找失败。没有证据表明源图块实体被删除。

## 修改

1. 功率成功入库并刷新设备匹配后，立即重建图例缓存。复用库图例或已捕获预览，不重新拾取、隔离或生成源图预览。
2. 新增 `EL_COMPACT_TYPED_V3` 存储表示：仅将连续整数编码合并为有界文本片段，短序列仍直接保存整数。坐标等 REAL 保留原生 group 40 双精度，业务数据完整还原，不删字段、不使用有损取整。
3. 保持旧文本、`EL_TYPED_V1`、`EL_COMPACT_TYPED_V2` 可读；正常保存升级为 V3。旧记录备份、事务回滚、预解码比较、dictsearch/entget 两路完整回读、提交后的检查继续执行。
4. 正常生成已经验证正式记录，面板收尾不再额外读取整库。生成前草稿及取消后的恢复行为保持。
5. 增加提交后检查的独立阶段日志 `STORE_CONTEXT_COMMIT`、`STORE_CONTEXT_READ`，以及图形完成后“正在核对并保存记录”的提示，便于区分插入、保存和最终确认。

## 必要检查

仅执行 17 个相关定向用例：功率入库后名称变化的图例恢复；新整数编码边界、坏输入、旧格式兼容及完整往返；双精度与 GB2312；双路回读差异拒绝；提交回调变化与晚期损坏；旧记录升级、降级及失败回滚；两回路生成、重复更新及取消后重试。

固定几何样例的完整 DXF 字段数由 3375 降为 1332，约减少 60.5%。这是存储工作量证据，不是用户原图耗时承诺；原图新字段数和耗时需用新日志验证。

交付包通过 `tools/build_cad2020.py` 构建；全部 LISP/DCL 严格 GB2312 编码、ZIP/解压目录一致性和 LISP 解析检查通过。

## 使用

完整解压 `应急照明-115.zip`，APPLOAD 包内 `START-CAD2020.lsp`，确认版本 115。检查输入功率后图例保留，并在系统图放置后等待“系统图已同步”和“主面板已保存到本图”提示；关闭前保存 DWG。

本包写入的新格式应继续使用本包或后续版本读取。如需回到旧包，先在支持 V3 的版本中执行项目已有的旧格式转换命令 `ELSTORELEGACY`，确认成功后保存 DWG。
