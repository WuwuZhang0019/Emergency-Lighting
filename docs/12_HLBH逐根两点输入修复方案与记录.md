# HLBH 逐根两点输入修复方案与记录
日期：2026-10-11
状态：修订 2026.10.11.3 已完成，46 项离线检查通过；修复后真实 CAD 复测待完成

## 这次实测与用户确认

用户提供 `HLPLBH-debug.log` 和 CAD 截图。修订 `2026.10.11.2` 已通过启动提示检查，但在第一根导线 `ROW_BEGIN` 后报告“点无效。”，没有 `CREATED` 记录，原生命令仍活动。本次实测中的 `CMDACTIVE` 是 `1`、`CMDNAMES` 是 `HLBH`，不再推测本次失败由 ObjectARX 状态位引起。

旧实现向选线步骤传入 `(entity pick)` 选择列表，而用户确认的交互是导线上点一次、空白处再点一次。自动化必须向这两步分别传入坐标点，一根导线的两个点全部完成并核对生成结果后，才能进入下一根。

用户已选择“每根固定偏移”：文字点相对各自导线中点向右 500、向上 500，不再要求点击一次空白处确定整组对齐位置。默认沿用图纸毫米单位和当前 UCS，编号仍按中点自上而下、同高度从左到右递增。

## 执行方案

1. 第一输入严格为当前 UCS 中的导线真实曲线中点 `(x y z)`；实体名只保留用于排序、快照与日志，不作为 HLBH 的选点参数传入。
2. 第二输入严格为 `(x+500 y+500 z)`，独立发送；不把实体、两个点或其他关键字拼成一次输入。完成两点并核对新增原生文字和编号后再处理下一根。
3. `HLPLBH` 只询问起始编号和框选导线。`HLPLBHSET` 改为设置 X、Y 偏移，回车保留当前值，默认都是 500。固定偏移不再按字高改动位置，文字排列随每条导线的实际位置变化。
4. 失败退出优先使用原生命令提示中的空输入退出。若正在等待文字点，第一次空输入取消该条，第二次退出选线循环；有限次数后仍活动则保留恢复状态，禁止发送 UNDO。恢复继续要求用户先结束活动命令。
5. 测试适配器改为只接收数值坐标点，并据曲线上真实中点确定所点导线；拒绝旧版实体/点列表，增加顺序、非直线曲线中点、固定偏移、UCS、第一点失败和第二点失败回归检查。
6. 源码与记录 UTF-8，仅导出 `output/HLPLBH.lsp` 为严格 GB2312；不打包、不改应急照明加载入口。完成对应检查后仅提交本功能相关源码、测试和文档。
