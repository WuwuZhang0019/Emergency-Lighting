# 140 六回路识别优化与移除暂存

日期：2026-10-15
状态：实现与 97 项定向检查完成；原图 AutoCAD 2020 耗时待实测

## 实测依据与目标

用户明确不需要独立暂存用途，要求六条回路尽量控制在 1 秒内，并保持识别结果。`output (7).zip` 中 139 版 `ELMONITOR-20261015.003926-ELSTAT.md` 实测整箱识别为 8.453 秒：候选采集 2.172 秒、网络准备 3.109 秒、回路划分与编号范围 2.719 秒，其余 0.453 秒。识别来源为 773 条导线、556 个候选图块，实际回路 6 条。

这里比较首次完整识别，不将用户拾取、面板等待或生成记录写入混入识别耗时，也不将重用上次识别结果的时间当作首次识别时间。

## 修改与边界

- 移除主面板“保存当前输入”按钮及回调绑定，默认按钮改为“生成新系统图”，提示文字和使用文档同步更新。生成前自动保存、生成失败恢复以及设备库的资料保存功能保留。
- 完整列表的稳定数据转换使用原生 `mapcar` 遍历，保留整数、实数、字符串、实体句柄、嵌套列表和点对尾部的原有表示。
- 同一次同步识别中，快照未改变的同一字段对象只转换一次；所有未知字段仍进入证据。缓存按对象身份命中，写入/交互代次或 DWG 所有者变化后失效；函数退出即清理，下一次识别不会直接沿用旧图纸结果。
- 空间树仍采用原轴顺序、并列键、树布局及查询顺序，减少解释器中的列表分割；射线一旦在某轴确定不相交就结束，已执行轴的浮点运算顺序与容差不变。
- 建网时，同一导线/设备对的相同接触判定只计算一次，命中与未命中均复用。本次新鲜读取的块定义几何可供紧接着的编号划分使用，仍核对网络对象、DWG 所有者和代次。实例与姿态轮廓按原阶段顺序重新构建，避免改变模板平移的浮点运算顺序。
- 编号范围仍执行原来的 32 次二分，保留原谓词顺序；只复用完全相同轮廓下的相同点、相同完整线段判定，不减少二分次数，不改变接触容差。

## 使用

完整解压 `应急照明-140.zip`，APPLOAD 加载 `START-CAD2020.lsp`。继续使用原图、同一箱体和相同六条起始导线，核对编号、设备归属、数量、功率与连接诊断后，查看 `RECOGNIZE_FIXED_RUN`、`SIMPLE_COLLECT`、`SIMPLE_NETWORK`、`SPLIT_NETWORK` 与 `CIRCUIT_NUMBER_SCOPE` 的程序耗时。
