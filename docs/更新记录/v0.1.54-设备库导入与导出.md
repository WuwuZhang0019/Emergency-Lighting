# v0.1.54 设备库导入与导出

日期：2026-10-16
状态：源码及 15 项定向检查通过，真实 AutoCAD 2020 验收待执行，本次不打包

主面板和独立设备库统一使用“导入设备库”“导出设备库”按钮，移除原图例修复入口。导入入口读取实际 `catalog.eld` 及其图形资产，原旧配置迁移函数保留兼容，但不再绑定这两个按钮。已发起图例任务的回调逻辑保留。

导出选择保存位置后创建全新文件夹，复制当前索引引用的 DWG、SLD 和可选识别预设，并逐个核对字节；索引最后写入并回读核对。当前库在复制前后都检查是否变化或被占用，成功后打开导出目录。已删除、草稿、空功率、0W 确认、名称、别名和地面参数保持原值；不把空功率推为 0W，也不导出写锁、历史修订或未完成图例任务。

导入完整设备库时复制到当前用户目录的新独立库，全部核对成功且目录设置写入成功后才切换使用。原库与原会话仍保留在原位置及目录状态中，可通过“更改库目录”切回；不会合并覆盖原库的功率、别名或删除状态。只收到 `catalog.eld` 且缺少对应图形时会明确要求完整 `assets`，不冒用其他库中同编号的图形。

取消选择不创建副本或改变当前库；复制失败、文件损坏、写锁、源索引在复制过程中变化、目标目录冲突或目录配置写入失败时均保留原库，不报告成功。两个界面调用导入导出前沿用当前输入保存流程，结束后返回原界面，不再触发图例修复。

文件夹选择使用 Windows Shell 的 [BrowseForFolder 方法](https://learn.microsoft.com/en-us/windows/win32/shell/shell-browseforfolder)。当前实现未执行真实 AutoCAD 文件夹选择、文件管理器打开及原图验收；检查仅覆盖有限接口适配器和真实临时目录内的文件操作。

版本顺延为 `v0.1.54`，内部兼容标识 153。本次仅修改源码、使用说明和必要检查证据，不运行构建脚本、不生成交付包；程序自带默认功率库继续等待用户重新保存的完整文件。
