# v0.1.58 回路分隔与预览色块

日期：2026-10-16
状态：源码及 20 项定向检查通过；按用户要求提供 CAD2020 试用包，真实 AutoCAD 2020 验收待执行

## 回路列表

回路行标签由“回路1”至“回路8”改为 `ZE1`～`ZE8`，每行下方增加细横线。标签后增加颜色块，与第三步“在图面查看全部回路”的临时配色逐行对应。界面标签表示行序号，右侧仍显示识别到的实际回路编号及功率，不改写原编号。

面板和预览共用同一份按行排序的配色，展开、收起和返回面板不会重新分配。配色候选排除红色、绿色、洋红色及对应色系，继续避开原导线的图层色与真彩色。预览结束、按 Esc 或出错时沿用原有清理流程，恢复源对象并删除临时副本。

## 诊断区布局

删除设备库展开按钮下方“可展开设备库查看或编辑设备”的提示。“导出诊断日志”、路径和“打开所在文件夹”连续排列，减少预留的空白反馈行；较长反馈完整输出到 CAD 命令行。

## 交付与检查

版本为 `v0.1.58`，内部兼容标识 157；本次按用户要求生成 `应急照明-v0.1.58.zip`，保留旧版本交付物。同版本补充检查或重打包沿用该版本号。

20 项有限 CAD/DCL 适配检查覆盖面板切换与输入保留、颜色对应、禁用色系排除、原色避让、预览退出及异常清理。交付时检查全部 LISP/DCL 的严格 GB2312 编码、LISP 解析、三个加载入口中的最新面板函数，以及 ZIP 与解压目录的文件清单和字节一致性。这些检查不替代原生 AutoCAD 的显示、交互及原图验收。

完整解压后，用 `APPLOAD` 加载包内 `START-CAD2020.lsp`，确认显示 `CAD2020 v0.1.58`，再运行 `ELSTAT`。不要直接加载仓库中的 UTF-8 LISP/DCL 源文件。
