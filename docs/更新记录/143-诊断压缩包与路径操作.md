# 143 诊断压缩包与路径操作

日期：2026-10-15
状态：实现完成；定向适配器和 Windows 压缩检查见证据，真实 AutoCAD 2020 验收待执行

## 用户操作

在主面板点击“导出诊断日志”，或运行 `ELDIAG`，自动汇总为一个 `ELDIAG-日期时间.zip`。文件默认在当前交付目录或本地运行目录的 `output`；输出目录不可创建时尝试 CAD 临时目录。相同时间再次导出追加序号，不覆盖已有 ZIP。

面板中的路径使用 Windows 反斜杠 `\`，放在可选中复制的文本框里。点击“打开所在文件夹”打开资源管理器并选中 ZIP；该按钮使用实际导出结果，修改文本框不会改变打开目标。导出或打开文件夹后回到原面板，保留功率、容量和设备库编辑。压缩失败时路径指向保留的原始资料目录。

## 包含的资料

| 文件 | 内容与范围 |
| --- | --- |
| `README.md`、`manifest.eld` | 导出日期、图纸、版本、文件清单、缺失资料及关联核对问题 |
| `timeline.md` | 当前图纸最近有效运行的全过程时间轴、最近加载阶段、错误和诊断事件 |
| `run.eld` | 对应运行的原始事件、耗时、计数，不使用显示日志的文本截断 |
| `load.eld` | 本次会话最近一次插件加载的原始动作与计时；可能晚于 `run.eld` 中的运行 |
| `association.eld` | 最近成功出图或明确选中的旧系统图关联；仅在对象身份与成员核对通过时收入 |
| `drawing-store.eld` | 当前图纸已保存记录的只读快照；不代表所有旧系统图成员均已核对 |
| `current-result.eld` | 当前内存识别结果，可能与最近成功出图不同 |
| `runtime-*.log`、`active-*.log`、`temp-*.log` | 当前输出目录、当前日志路径及 CAD 临时目录已有的 `ELTRACE-debug.log` / `ELPERF.log`；属于历史共享文件，可能含此前命令或其他图纸 |

只收集明确列出的文件，不递归收集 DWG、设备库、旧诊断 ZIP 或其他文件。缺少成功出图记录、关联成员已删除或读取记录异常时，仍打包可收集的日志并注明原因，不把失配对象标为已核对关联。历史日志保持原字节；本次创建的 `.eld` 和 `.md` 使用 UTF-8。

每张打开的图纸保留最近有效运行和最近成功出图。**请在关闭图纸前导出**，内存诊断不会随 DWG 保存。生成流程没有新增文件写入或压缩等待。

## 压缩与失败处理

压缩仅在手动导出时运行，使用 Windows PowerShell 和 .NET ZIP，不需要安装 Python 或压缩软件。子进程隐藏窗口并等待完成；先写 `.partial`，重新读取每个 ZIP 条目，核对长度与 SHA256 后发布正式 ZIP。成功后清理本次已知的暂存文件，不递归删除目录；失败保留原始资料，不宣称成功，不覆盖旧 ZIP。

PowerShell 命令采用 UTF-16LE Base64，文件路径作为 PowerShell 字符串正确转义，支持中文、空格、单引号、方括号、`&` 和百分号。三个加载入口及独立启动文件的嵌入运行目录均包含压缩脚本。系统策略阻止 PowerShell 或输出权限不足时，面板报告失败并保留已收集资料。
