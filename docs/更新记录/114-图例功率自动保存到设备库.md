# 114 图例功率自动保存到设备库
日期：2026-10-13
状态：代码完成，真实 CAD 验收待执行

## 原因

原图例功率编辑只更新本箱覆盖值及本箱缓存，公共设备库必须另按右侧“保存到设备库”。更换配电箱后，没有库默认功率的相同图块仍为空。另外，已登记图形但资料尚未齐全的设备草稿，原来不能提供默认功率。

## 本次修改

- 图例功率编辑完成时自动写入当前设备库；直接点击保存或切换时，也会收集尚未离开输入框的有效修改。
- 使用设备库原有事务、版本冲突判断和文件回读；同一次收集的多个功率批量写入一次。没有新修改时不写库。
- 新配电箱按图块名及已登记别名读取库功率。已有图形的设备草稿也可提供已填写的默认功率，无须重新登记或拾取图形。
- 同步更新右侧库默认功率，保留设备名称、别名、图形、地面资料等其他信息和未提交的编辑。
- 空白不覆盖库值，明确填写 0 才保存为 0 W。历史记录中的本箱覆盖值不会仅因打开或浏览而反向覆盖公共库。
- 写库失败或有版本冲突时保留当前输入及待保存值，提示未保存，避免将失败当成成功。

## 验证与交付

仅执行功率发布、跨箱别名取值、空白与零值、批量写入、失败保留重试、编辑区同步等定向检查，以及相邻功能的必要回归。交付由 `tools/build_cad2020.py` 生成，并检查全部 LISP/DCL 的 GB2312 编码、ZIP 内容一致性及 LISP 解析。

完整解压 `应急照明-114.zip`，APPLOAD 包内 `START-CAD2020.lsp`。现场核对：修改一种图块的功率，确认右侧库默认功率同步，再拾取另一配电箱，确认相同图块自动带值；重启 CAD 后仍应保留。
