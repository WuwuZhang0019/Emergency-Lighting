# v0.1.67 识别与系统图性能原图测试版

日期：2026-10-21
状态：当前性能分支测试版；未合并、未发布，原图及原生 CAD 验收待完成

## 识别与候选处理

相同块定义、相同姿态且能证明平移数值安全时，共享已完成的采样轮廓、闭环、孔洞与接触索引；不满足条件则回退原算法，不改变真实椭圆或接触容差。候选 ID 使用单次采集内的字符索引去重，保留原对象顺序、首遇代表、远端/断口候选与贴临设备链。

## 系统图模板与来源

核对已知样本句柄，在受控阶段复用完整事实一致的定义签名与动态属性；交互、写入、切图和探针清理后仍按规则重查。默认使用本图已有系统图块与样式，面板提供“检查本图图块”和“从图库补入缺项”。补入仅限本次动作，不覆盖已有同名定义，完成或失败返回原面板并保留输入。

## 耗时与业务状态

区分本轮识别/生成结果与此前成功系统图的关联。新增候选批次、模板复核、生成准备、完整计划、原生插入、动态切换、放置后核对、回路/文字创建和事务收尾计时。父子区间不能相加；首箱原生放置仍含 CAD 处理与用户操作，不虚构预览就绪或纯 CPU 耗时。

## 加载与原图复测

1. 完整解压 `应急照明-v0.1.67.zip`，APPLOAD 加载根目录 `ELFULL67.lsp`，输入 `ELFULL67`，确认显示 `v0.1.67`。
2. 用相同 DWG 副本、箱体、起始导线和配置，对照首次/重复识别、已有定义/实例与首次导入，并核对数量、编号、功率、预留回路及图面。
3. 每次完成或取消后、关闭图纸前运行 `ELDIAG`，或使用面板的“导出诊断日志并打开文件夹”，保留完整 `ELDIAG-时间` 文件夹，可自行压缩后反馈。先导出再开始下一轮，避免最近运行被替换；另用副本验证保存重开、Undo 和取消重试。

加载文件只注册命令；执行 `ELFULL67` 才初始化本版。继续沿用自动目录发现与自包含后备运行目录，旧版文件和 CADTools 安装菜单均不更新。测试版只来自当前分支，未合入 `main` 的并行提交 `91cc1bc`，因此不包含该提交的闭合回路空功率生成改动。

诊断资料中的 `run.eld` 和 `timeline.md` 包含本轮完整细分阶段与聚合指标，`manifest.eld` 区分本轮业务状态与历史系统图关联。旧关联的 `VERIFIED` 不证明本轮识别或生成成功；不存在独立 `ELPERF.log` 时，也应保留整份诊断文件夹。
