# v0.1.75 只读 .NET 冷路径性能原型测试版
日期：2026-10-22
状态：本地测试交付；真实 CAD/原图待验收，未合并、未推送、未发布

本轮目标是每个新箱体首次完整识别在3秒内，不以预热、重复识别或上次结果缓存作为提速依据。当前交付先验证 .NET 批量读取、索引和保守候选发现；精确接触、断口判定、编号、源图证明和预览仍由原 LISP 负责。报告明确 `complete-recognition=false`，本轮不宣称完整3秒目标已达成。

## 只读原型

每次调用新建采集和索引容器，按原预设选择集批量读取，使用 ForRead 事务；不插入、修改或删除图内对象，不保存统计和系统图。原型异常、读取不支持、源变化或候选展开达到限额会失败并保留报告，不能以不完整候选继续正式识别。

三轴预排序树保留现有中点及有序查询行为。生产 `ELSTAT`、编号、预览和生成算法没有切换。原型候选尚未应用全部角色/块名/配色/线型过滤，数量是上界，不能直接与38设备/40导线作等价判断。

## 原图操作

1. 完整解压 `应急照明-v0.1.75.zip`。新开 AutoCAD 2020，用原图副本测试。APPLOAD 根目录 **ELCOLD75.lsp**，输入 **ELCOLD75**；确认提示 `v0.1.75`。加载只注册，DLL 在拾取结束后按需 NETLOAD，第一次加载和 JIT 会包含在外层计时中。
2. 默认选 `Prototype`。拾取一个新箱体及相应起始导线，保持原方向、容差和配置，最后 Enter 完成。原型返回命令行耗时和报告路径，不打开结果面板。
3. 在另一个新箱体重新运行。每次都重新采集、建树和计算；不需要先运行一轮预热。若要检验程序集也首次加载的情况，再开新 CAD 会话测试。
4. 需要同输入的完整业务参照时，在模式提示输入 `Both`，它在原型后另跑现有完整只读识别，单列旧路径耗时与编号业务字段。这是顺序参照，CAD/系统读取缓存可能受前一步影响，不能作严格冷A/B。
5. 每轮完成或失败后，立即输入 **ELDIAG**，保留完整诊断目录/ZIP。内含 **cold-probe.json**、**cold-comparison.eld**（成功写出时）和原有日志。不要只发性能日志，也不要在开始下一轮或关闭图纸后才导出。

当前内部 `PACKAGE_NO=174`，后备目录 `%LOCALAPPDATA%/Emergency-Lighting/runtime-174/`，标记 `package-174.marker`。若找到完整交付目录，报告也可能写在该目录的output；以命令行显示为准。旧包及旧运行目录保留，不更新CADTools菜单。NETLOAD如被安全策略拦截，检查实际错误和完整包受信任路径，本版不会修改安全变量。

## 看哪些时间和结果

| 字段 | 边界 |
| --- | --- |
| `prototype-pick-to-return-ms` | 最后拾取结束至候选原型及边界抽查返回，含清理、NETLOAD/JIT、选择、桥接及JSON写盘 |
| `load-and-clear-ms` | 第一次DLL加载与拾取叠加图形清理，后续DLL已加载时会自然缩短 |
| `managed-bridge-ms` | 原生函数调用的外层时间，含JIT、读取、索引、候选追踪、报告和返回封送 |
| `read-ms / index-ms / coarse-trace-ms` | .NET内部固定批次阶段 |
| `bounds-audit-ms` | 最多16个块与原COM GetBoundingBox逐样本核对 |
| `legacy-full-ms` | Both模式的原完整识别，另外计时 |

`bounds-audit` 应 `missing=0 / different=0`。任何错误、限额或不一致都保留原图与报告再分析。抽样一致不代表全规则等价。JSON内部总时间不含最终写盘，外层bridge覆盖；LISP对照报告末次写盘在end-to-end取点之后，不把它算作候选算法时间。

上一版 v0.1.74 / output (29) 完整识别10.922秒、最后拾取至面板12.375秒。本轮实际原图时间未知；原型处理范围与完整识别不同，不能拿两者直接相减宣称整体提升。

## 正常功能与回归边界

同包 **ELFULL75.lsp → ELFULL75** 保留正常面板流程。在相同原图/F072/四起点下核对38设备、4实际/2预留、94W，ZE1为73W、ZE2～ZE4各7W，编号与UID、设备/功率对应以及全部预览颜色、范围和退出恢复保持。ZE1历史来源仍为auto，本轮不猜测或改写天正编号。只读原型不会生成系统图。

核心9组离线回归、真实AutoCAD2020 API零警告编译，以及77项独立入口/只读/识别/编号/预览有限宿主回归完成，交付包按GB2312严格转换并检查ZIP、源码、嵌入DLL及五个入口一致性。编译、宿主和包检查不代表AutoCAD原图验收；本机没有可运行的AutoCAD，真实首次性能、动态块边界及正式功能以原图证据为准。
