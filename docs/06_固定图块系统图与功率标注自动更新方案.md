## 2. 未指定细节的实施默认值

以下是为执行方案补齐的默认值，不冒充用户已经指定的参数。实现时提供配置或样本采集入口，无需为这些细节阻塞本文落盘。

- 坐标按块定义的局部坐标解释，项目单位默认 `mm`；默认整体比例 `1`、WCS 旋转角 `0`，用户指定系统图箱体插入点。
- 实际回路文字默认 `{回路功率W}W`，例如 `172W`；预留由动态块“预留”状态表达，不生成额外功率文字，不要求填 `0W`，不参加实际负载合计。预留功率数据为“不适用”，与实际回路明确填写的有效零功率区分。
- 实际回路排在前面，两条预留固定排在最后。实际回路先沿用本次核对顺序，之后持久保存输出顺序；不根据功率重新排序。
- 默认独立 `TEXT`、左下基点对齐、局部文字角度 `0`。字高、样式和宽度因子优先从用户拾取的现有文字样本采集；无样本时使用当前有效文字样式、正值 `TEXTSIZE` 和宽度因子 `1`。固定字高样式以其有效字高为准，校验失败就提示修正。默认输出图层 `EL-SYSTEM`。
- 用户提供的文字坐标是最终定位依据，不再叠加额外的“偏下一点”。对齐方式改变时仍以文字实际对齐基点落在指定坐标为准。
- 自动更新的触发点是成功重新统计或保存有效功率修改，不要求用户每次重新插入系统图。第一期不实现每次拖动或编辑后的常驻实时监听。
- 目标默认 `ELSTAT` 保留“拾取配电箱、拾取导线”的入口，接入可靠的逐回路识别后打开第 4.2 节主面板；复用 `ELTRACE` 的逐回路能力和现有设备功率表。只有整箱结果时可保留汇总查看，但须明确缺少逐回路数据，不能伪造回路表或均分功率。自动分回路有歧义时集中核对，不增加正常流程的逐回路重复拾取。
- 当前结果必须识别完整、功率齐全且满足既有生成条件。`n=0` 不自动生成只有两条预留的系统图，提示未取得有效实际回路。

## 3. 坐标和数量计算

令 `i` 从 `1` 开始，包含实际及预留行，`1 <= i <= n+2`。局部 Z 坐标均为 `0`。

```text
回路基点 B(i) = (6427, -5500 - 1200*(i-1), 0)
文字局部偏移 T = (10636, -438, 0)
文字相对箱体坐标 A(i) = B(i) + T
                         = (17063, -5938 - 1200*(i-1), 0)
```

以箱体插入点 `O`、正等比缩放 `s` 和绕 WCS Z 轴旋转 `theta` 生成：

```text
回路世界基点 = O + R(theta) * (s * B(i))
文字世界基点 = O + R(theta) * (s * A(i))
R(theta)*(x,y,z) = (x*cos(theta)-y*sin(theta),
                    x*sin(theta)+y*cos(theta), z)
```

图块插入坐标已经指向块基点，不再自行加减块定义原点。用户拾取的 UCS 点先转换到 WCS，再应用上述局部排布；首次支持模型空间、正等比缩放和绕 Z 轴旋转。镜像、非等比缩放、倾斜法向或纸空间不静默套用本公式，应明确阻止并提示。

例：`n=3`，`O=(0,0,0)`，`s=1`，`theta=0`，输出如下。

| 输出行 | 类型 | 回路基点 XY | 文字基点 XY | 文字 |
| --- | --- | --- | --- | --- |
| 1 | 实际回路 1 | `(6427,-5500)` | `(17063,-5938)` | 该回路实际功率，例如 `120W` |
| 2 | 实际回路 2 | `(6427,-6700)` | `(17063,-7138)` | 该回路实际功率，例如 `85W` |
| 3 | 实际回路 3 | `(6427,-7900)` | `(17063,-8338)` | 该回路实际功率，例如 `172W` |
| 4 | 预留 1 | `(6427,-9100)` | 不创建 | 无独立功率文字，块选“预留” |
| 5 | 预留 2 | `(6427,-10300)` | 不创建 | 无独立功率文字，块选“预留” |

公式 `B(i)` 适用于全部 `n+2` 行；文字公式 `A(i)` 只用于前 `n` 条实际回路。独立实体数量为 `1` 个箱体 INSERT、`n+2` 个回路 INSERT、`n` 个功率 TEXT，块内部自带的文字不计入独立 TEXT 数量。可使用 CAD 组便于整体选择，但不能只依赖组成员顺序判断回路身份。

### 4.0 日常流程与首次设置的职责（新增，待实施）

日常只需进入 `ELSTAT`。先拾取平面配电箱、该系统导线，完成逐回路识别和功率统计，再打开主面板。仍有出线归属歧义时沿用既有集中核对；不以减少提问为由跳过识别问题。

```text
拾取配电箱 → 拾取导线 → 自动统计设备、各回路功率及箱体合计
    → 主面板：显示容量、回路类型、判定来源和待核对项
    → 保存草稿，或生成/更新
        → 复用有效模板；缺失/变化时集中完成首次适配
        → 自动选择对应动态状态，预览后提交
```

区分三个动作：

| 动作 | 执行时点 | 用户需要做什么 |
| --- | --- | --- |
| 确定“1 kW”代表业务容量“1kW”等模板名称对应关系 | 首次适配时由程序识别并缓存，后续只校验是否失效 | 名称明确时无需选择；真实歧义时才在设置中集中核对 |
| 确定当前箱体容量、当前实际回路是否为地面类型 | 拾取和统计完成后 | 有明确规则则自动带入；面板只要求核对未确定项，并允许人工修正 |
| 把已确定的容量和类型写到输出动态块 | 生成或成功保存更新时 | 不再选择属性序号或动态值序号，由程序写入并读回验证 |

`ELTEMPLATE` 保留为首次适配或更换模板的维护入口，不要求每次统计前执行。正常重复统计复用配置；缺模板不影响统计、功率填写和草稿保存，但正式生成须完成适配。设置取消时返回已有统计面板，保留本次面板草稿和旧模板，不要求重新拾取箱体与导线；明确取消整个主面板时仍按既有规则丢弃未保存草稿。

### 4.1 动态属性选择和写入

程序可以切换动态块选项。复用现有 `EL:DynamicProperty`、`EL:AllowedValues`、`EL:SetDynamicValue`：读取真实属性名、类型、可写性和允许值，建立业务选项到实际属性值的映射。不得硬编码属性一定叫“可见性”，也不能把面板显示字符串未经校验直接写入。

| 对象 | 面板业务选择 | 输出动态状态 |
| --- | --- | --- |
| 箱体 | `0.3kW` / `0.6kW` / `1kW` 三选一 | 所选容量对应的实际动态属性值 |
| 实际回路 | “是否为地面”未勾选，即否 | `普通` 对应的实际动态属性值 |
| 实际回路 | “是否为地面”勾选，即是 | `地面` 对应的实际动态属性值 |
| 两条预留 | 固定预留，不参与地面选择 | `预留` 对应的实际动态属性值 |

首次适配时，唯一匹配的允许值直接建立映射；属性名或候选值存在真实歧义时集中选择一次并保存。以下对应规则加入 S07，不再因空格或本模板的已知别名让用户选择：

- 容量匹配可忽略空白和单位字母大小写，例如 `1 kW` 与 `1kW`、`0.3 kw` 与 `0.3kW`；仅用于匹配，写入时保留模板的原始允许值及类型，不改块定义。
- 当前指定回路模板 `fghjftyuk` 中的“埋地”作为业务“地面”的已知别名，显示“地面（模板状态：埋地）”。该别名只解释输出模板状态，不证明任何平面设备或回路实际属于地面类型，不扩展成任意图块的安装方式识别规则。
- 别名与规范化结果必须唯一；若同时有多个属性或多个实际状态符合某一业务含义，才要求集中核对。保存模板有效名、属性名、原始值及定义/映射版本，定义变化后重新验证。
- 不再出现含义不明的 `1-1` 提问。已知含义唯一时自动对应；唯一剩余但含义未知时不能仅靠排除法认定，须明确显示目标业务含义、实际状态及确认/取消操作。

必须验证箱体三档、回路三档均可用；缺少“预留”状态时报告模板不匹配，不回退成普通状态加文字。写入后读回检查，并在真实 CAD 中检查可见图形；只读或写入失败时整次事务回滚。

箱体容量的目标行为调整为统计后按明确规则自动带入，并在主面板显示来源、计算依据及人工修改入口。人工已确认的选择优先于自动规则；规则变化或统计变化时提示复核，不静默覆盖人工选择。既有版本的 `0.3kW` 默认值仅属历史初始值，不能当作自动选型结论。

容量自动规则尚待确定：采用哪一项完整负载合计、是否计入预留或容量余量、是否存在降额、档位临界值如何处理、超过 `1kW` 或功率未齐时如何处理。实现前需固化规则和版本，不能仅因某档看似大于总功率就自行认定适用。规则未配置时，在统计面板复用已确认容量或标“容量待核对”，由用户选择后才能正式生成；仍允许保存草稿。切换容量不改动实际回路、设备、功率或地面勾选。

普通和地面使用同一组已确定的回路基点和文字偏移；切换动态状态后需校验位置不漂移。其他无关动态属性保持不变。已有内部符号若与外部功率文字冲突，应在真实模板适配时报告，不擅自删改块定义。

交互要求：

1. 点击主表回路行，右侧仅显示该回路的“设备图块／数量／单个功率（W）”，沿用当前单功率编辑、按块名记忆和图面定位的使用方式。定位只高亮当前选中回路内该类设备，不能扩散到其他回路。
2. 切换行前将有效编辑保存到面板草稿；非法输入定位到错误字段并阻止切换，不丢失未保存数据。保存才提交功率库及 DWG 更新；取消丢弃本次未保存草稿。
3. 数量来自识别，只读；单个功率按现有块名复用规则统一。修改某类设备功率后，重算本箱所有含该设备类型的实际回路，同时刷新主表与箱体合计，不只刷新右侧当前一条回路。高级流程有独立旧功率记录时先明确来源和优先级，不让两套功率库静默互相覆盖。
4. 勾选地面只改变该回路的输出动态状态，不改变其设备归属或功率。勾选状态、输出顺序按 `circuit-uid` 保存；切换回路、切换箱体档位、重新统计和保存重开均不得把人工选择重置为否。
5. 点击预留行，右侧显示“预留回路，无设备统计，无需填写功率”，清空前一回路设备行并禁用功率编辑；主表功率显示 `—`，不能用 `0W` 假装已统计。预留不能改成普通/地面，也不能把已有负载的实际回路改成预留。
6. 主表保留未完成、功率缺项和超限的实际回路，显示问题状态，不能隐藏它们凑成可生成结果。保存草稿可保留问题状态，正式输出仍须通过完整性和功率校验。
7. 面板上的“生成或更新”根据是否已有受管系统图执行首次插入或原位更新；保存成功后按既定自动更新规则同步已绑定图形。仅切换查看行或箱体档位草稿不立即修改 DWG。
8. 新增流程中，待核对容量、待核对回路类型与模板适配问题在同一结果面板集中展示；已确认项不逐条重复询问。待核对项未解决时可保存草稿，正式生成或更新保留最后成功输出。用户可在面板集中确认已有普通/地面选择，不强制逐回路弹窗。

实现时不得把装饰性的 `□/☑` 字符当作完成了勾选交互。需验证当前 DCL 方案能否实现最后一列的独立可操作勾选；必要时使用可滚动的同步行控件或可支持表格勾选的界面组件。主表数据行、最后一列勾选和右侧选中回路必须按 UID 对齐，不以显示行号作为持久身份；不能以额外弹窗替代用户要求的主表末列操作。

### 4.3 未来地面疏散指示图块自动识别

既有实现为手动勾选及后续识别接口；本次方案将自动规则的执行时点明确为拾取、识别及统计完成后。目前没有用户指定的地面疏散指示图块名单，不能按名称含“地面”、功率、位置高低、最近距离，或输出模板含有“埋地”状态就自行推断实际回路类型。

后续由用户配置固定地面疏散指示图块的有效名称及必要身份条件，严格在当前已识别回路的设备集合内匹配，命中时可建议或自动设置“是否为地面”。需明确混合设备回路如何归类，以及未命中时是否有足够依据判为普通。记录 `ground-source`（默认、人工、自动规则）、规则版本及命中设备证据；人工明确选择优先于自动识别，包括人工取消勾选。重算不覆盖人工选择；无规则或证据不足时标待核对。自动规则状态在重新识别后按当次证据重算，歧义或识别不完整时提示核对，不据此断言安装方式。

## 5. 稳定关联与持久化契约

### 5.1 数据记录

关联以 DWG 内命名对象字典及 XRecord 为主记录，实体附轻量 XData 标识；外部 `.eld` 仅作导出和诊断副本。随 DWG 保存重开后可恢复，不依赖当前进程的全局变量或插件目录路径。

| 层级 | 必需字段 |
| --- | --- |
| 文档 | `schema-version`、持久 `drawing-uuid`、系统图记录索引 |
| 系统图 | `diagram-id`、`source-panel-handle`、`panel-output-handle`、`template-version`、模板参数、`capacity-option`、已验证动态属性映射、`origin/rotation/scale`、`source-signature`、`power-signature`、`status`、最后成功更新时间；S08 新增容量来源、确认状态、规则版本及判定证据 |
| 实际回路 | 持久 `circuit-uid`、当前 `seed-key`、当前显示编号、`output-order`、`is-ground`、`ground-source`、未来规则证据、动态状态、回路块句柄、文字句柄、最后写入功率和实体状态 |
| 预留回路 | 固定键 `reserve-1` / `reserve-2`、回路块句柄、固定 `reserve` 动态状态；功率和文字句柄不适用，不绑定任何真实负载 |
| 输出实体标识 | 应用标识、`diagram-id`、实体类型、`circuit-uid` 或预留键 |

`source-panel-handle` 指平面图箱体，`panel-output-handle` 指系统图箱体，不能混用。句柄只在当前 DWG 上下文中解析，每次同时核对类型、所属系统图和实体标识，不对错误句柄写入。

### 5.2 身份匹配

当前 R1/R2 等来自遍历编号，插入、删除种子后可能改变；它们只能是显示编号，不能作为更新唯一键。初次生成创建持久 `circuit-uid`，以当前图纸、来源箱体和可靠出线种子建立一对一映射。后续相同有效种子匹配原 UID，保留其输出顺序。

若 BREAK、重画或删除导线使种子身份消失，不能按相同 R 编号、最近距离或相同功率把新回路绑定旧文字。集中显示旧回路与新候选，由用户明确映射，或明确按删除旧回路、增加新回路处理；有歧义期间不修改该系统图。身份未变而其他设备或线段变化，只要重新识别完整，仍更新对应原行。

同一来源箱体默认只维护一套受管系统图，再次生成进入更新。复制出的带标识实体应检测标识重复，不能同时当作原实例；跨图粘贴、WBLOCK 等不自动继承可更新关系，需显式重新绑定。原始样本及未标记图形不接管、不删除。

## 6. 生成和自动更新流程

### 6.1 首次生成

1. 获取当前箱体新鲜、完整的逐回路结果；所有实际回路功率为有效整数 W，沿用 `can-generate`，不得隐藏超限或未完成回路。
2. 打开统计结果主面板，按有效规则带入容量和回路类型，显示判定来源；集中处理未确定项、缺功率及真实歧义。无有效规则时按第 4.1、4.3 节核对，不以默认值冒充自动判定。
3. 点击生成时复用已验证模板；仅缺失或定义变化时进入集中适配，自动处理明确名称及别名并采集文字外观。适配取消返回统计面板。确认后，程序按已确定容量、回路类型和两条固定预留自动选择实际动态状态，不再提问属性或值序号。指定系统图箱体插入点，预览各动态状态及实际回路文字位置；坐标、间距和预留无文字规则沿用第 1 节。
4. 提交前再次核对来源签名；事务内插入对象、写入关联记录。成功后报告实体数量与位置；取消或任一步失败恢复操作前状态。

### 6.2 重新统计或改功率

成功完成接入后的 `ELSTAT` / 既有 `ELTRACE` 逐回路结果发布，或主面板 / `ELPOWER` 保存有效结果后，调用共同更新入口。箱体容量和地面勾选的保存也纳入更新，不以功率是否变化作为唯一触发依据。另提供 `ELUPDATE` 命令，用于保存重开后选择受管系统图并重新识别来源箱体、重算和同步；该命令已在本次增量中实现，真实 CAD 操作仍待验收。

1. 按来源箱体找到已有受管系统图；没有则只发布统计结果，不自动决定插图位置。
2. 检查来源是否新鲜、逐回路数据是否完整、关联是否唯一、输出对象是否可写；从既有实体读回当前位置和样式。
   新增流程还需核对容量/类型的来源和确认状态；有效人工选择按 UID 保留，自动规则来源按本次证据重算。出现待核对项时在统计面板集中提示，保留最后成功图形，不在更新途中逐项询问模板序号。
3. 匹配稳定回路 UID，构建新增、修改、删除及预留移位计划。实际回路数始终为本箱 `n`，最终仍为 `n+2` 行。
4. 仅功率改变：在原文字实体上修改文本内容，文字及回路块句柄保持不变，保留用户调整过的位置和样式。两条预留始终不创建功率文字。仅地面或容量选项变化时，原位设置对应动态属性并读回验证，保持对象句柄、回路关联和实际功率不变。
5. 回路增加：默认追加到已有实际回路后、预留前，新增对应块和文字；两条预留对象保留身份并向下移动。回路减少：确认身份关系后删除本功能管理的对应块和文字，按保存顺序压紧排列，预留保持最后两行。
6. 行数或排序改变时，未被手工调整的布局按第 3 节重排；发现单独移动的块或文字与受管位置不一致时，集中预览受影响对象，由用户选择按模板重排或先保留现场并取消本次结构更新，不静默覆盖手工排版。
7. 数据、位置和动态状态均相同则不写入，实体数量和句柄不变。成功后同步关联记录、签名和更新时间；无须用户再次执行“插入”。若已有受管旧记录含预留功率文字，只清理经标识与句柄双重确认属于该预留行的旧文字，不能按文字内容全图搜索删除。

### 6.3 移动、损坏和失效

- 整套系统图平移、正等比缩放或旋转：下次更新以箱体当前变换为参照，核对所有成员的局部相对位置，一致则采纳新整体变换；仅移动箱体而未带动其他成员时作为布局冲突处理，不误判整组已移动。
- 实际回路文字被删除但对应回路块和唯一关联仍可靠：只补建该条文字并记录新句柄；预留无文字是正常状态，不能触发补建。回路块被删、箱体被删、映射不唯一或疑似手工替换时报告修复项，不擅自重建整图。文字内容手工改过时，下次有效统计以计算值覆盖；位置和样式按前述规则保留。
- 新统计失败、取消、缺少功率、超过 172W 或来源过期：不写入部分功率，不把未知值改为 `0W`，保留最后成功文字；将关联状态置为 `stale`，在统计/更新结果中明确列出“原系统图未更新，仍为上次结果”。保存重开后保留已知失效状态；未重新核验时不能宣称当前有效。
- 保存重开后恢复关联不等于数据自动变新。重新统计或 `ELUPDATE` 才执行完整复核；本期无常驻监听，用户仅编辑平面图而不重算时，旧文字不会实时变化。
- 系统图输出实体无论所在图层是否与识别层重叠，都须按受管标识从平面图统计和来源签名中排除；否则自身文字和图块变化会污染统计或触发循环失效。不得只按块名排除平面图中的同名真实对象。

### 6.4 事务和撤销

现有 `EL:RollbackCreated` 只能覆盖新建对象，更新实现必须补齐修改和删除的恢复。先完成差异计划及全量可写性检查，再在单一撤销组内应用；保存原实体数据、动态状态和关联记录，失败时恢复修改、删除及新建，避免半套更新。DWG 主记录成功才算更新成功，导出 `.eld` 失败单独报告。

一次 UNDO 应同时撤销图形和关联记录变更；事务结束前后任何取消都应清理预览、关闭撤销组并恢复必要系统变量。不能用“新建一套后删旧套”替代仅功率变更的原文字更新。

收尾实现采用以下具体方式：

- DCL 每页同步 8 行，上一页/下一页翻页。真实 toggle 位于每行最后一列；右表与选中回路绑定，预留禁用。该实现不是装饰性方框，实际 CAD 控件可用性仍需验证。
- 没有线路方向语义时，不能从接触箱体直接断言进/出线。首次及候选集合变化时只集中核对一次，默认保留全部候选；明确排除的进线按种子保存。正常重复统计不逐回路重新拾取。
- 首次生成使用真实动态实例做事务内预览；核对后 Yes 保留，No/Enter/Esc 撤销。结构变化的重排预览仅为位置示意，真实母线长度与图形覆盖需人工在模板中核验。
- 丢失种子时提供“删除旧回路并新增”集中确认，不按编号、功率或最近距离匹配。尚不提供任意旧/新 UID 的手动配对编辑器；取消后保留旧图，不影响该保守处理路径。
- 输出同层也按标识排除；未标记的历史图形不接管。复制/跨图关联及损坏块会阻止更新，需恢复原对象或另行首次绑定，程序不提供自动猜测重绑。
- DWG 是主记录。共享功率库和 `.eld` 导出失败会单独报告；DWG 成功写入的功率副本仍保留。未完成草稿可保存，正式图形保留最后成功结果。
