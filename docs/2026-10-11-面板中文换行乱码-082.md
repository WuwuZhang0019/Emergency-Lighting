# 面板中文换行乱码修复
日期：2026-10-11
状态：源码及定向检查已完成，真实 AutoCAD 2020 验收待执行

## 现象与原因

“回路与图块设置”左侧的容量提示、设备合计和核对提示出现问号或错乱汉字，其他中文正常。
`EL:PanelText` 原先用 `substr` 每次截取长度 1，再按汉字宽度累计换行。AutoCAD 2020 的旧字符串引擎按字节计数，GB2312 汉字占两个字节；逐字节处理使宽度被重复计算，并可能在汉字的两个字节之间换行。

## 修改

通过固定中文字符串的 `strlen` 判断当前引擎是否按双字节计数。在旧引擎中遇到中文高位字节时一次截取两个字节，整体累计宽度并整体换行。Unicode 引擎仍按单字符处理。保留提示行数、清空旧行和超长信息输出到命令行的行为。

## 检查与验收

- `python -X utf8 -m unittest discover -s tests -p test_panel_repairs.py`：6 项通过。
- 回归测试模拟 GB2312 字节索引，覆盖容量提示、设备合计、43 个 ASCII 字符后紧接汉字的边界及空文本清理；逐行严格解码并校验拼接后等于原文。
- 使用 `tools/build_cad2020.py` 构建 082；脚本严格转换全部 LISP/DCL 为 GB2312，并检查 ZIP 与解压目录字节一致性。
- 真实 CAD 尚待确认：加载 082 后运行 `ELSTAT`，打开“回路与图块设置”，确认截图箭头所指的容量提示和合计文字无乱码、换行完整。
