# v0.1.68 模板闪回修复与三项优化测试版

日期：2026-10-21
状态：当前性能分支原图复测测试版；不合并、不发布，原生 CAD 生成和性能验收待完成

## 模板首次读取与生成闪回

修复模板探针缓存和动态检查缓存为空时先读取字段、导致`参数类型错误: consp nil`并回到面板的问题。首次未命中继续查真实样本、动态属性或必要探针，保留定义变化与放置后复核。同步修正测试宿主的`NTH(nil)`语义；严格回归还发现并修复缺失图例文件时读取空文件头的问题。

默认使用本图已有系统图块和文字样式；有缺项时列出问题，允许在面板显式从图库补入，不覆盖已有同名定义。取消、不兼容或失败仍保留识别结果、功率和容量。

## 三项小优化与计时

- 预览 RGB 精确去重，保持原避色阈值、候选顺序和面板/图中预览的一致调色板。
- 角色表在句柄唯一、数量及顺序一致时逐项恢复；重复、乱序或不满足条件时回退原查找语义，完整快照比较继续执行。
- 图层颜色与线型仅在各自单次同步操作内缓存，不跨下次取色、采集或切图使用；线型缓存遇写入边界变化后重读。

新增`PANEL_SELECT_EXITS`、`PANEL_COMPUTE`、`PANEL_PREVIEW_PALETTE`，以及取色/筛色、输入/输出快照规范化、接触证据、角色恢复和最后完整比较的独立阶段。诊断会同时记录 RGB 重复数、图层读取/命中数及角色顺序处理/回退数。父子计时不能相加，适配器操作量不能换算为 CAD 秒数。

## 加载与原图复测

1. 完整解压`应急照明-v0.1.68.zip`，APPLOAD加载根目录`ELFULL68.lsp`，输入`ELFULL68`，确认显示`v0.1.68`。本版内部标识为`167`，自包含后备运行目录为`runtime-167`。
2. 使用相同DWG副本、箱体、起始导线和配置，先复测`F072`。保持默认本图图块来源，点击“生成新系统图”，观察是否正常进入箱体原生预览，再左键放置，核对实际/预留回路、编号、功率、文字和图面。旧同箱记录为38设备、4实际回路、94 W，输入未变时应对照一致。
3. 对比首次与重复识别、面板打开耗时和配色结果；需要时分别测试图内已有实例、只有定义、显式补入缺项、取消后重试。不要把不同配置或新增图形后的差值全归因于缓存。
4. 每次成功、闪回、失败或取消后，在关闭图纸及开始下一轮前执行`ELDIAG`，也可用面板“导出诊断日志并打开文件夹”，保留完整`ELDIAG-时间`目录。`run.eld`、`timeline.md`及聚合指标用于核对本轮路径和耗时；可自行压缩后反馈。
5. 另用相同条件单独复测`219C9`密集椭圆箱。该箱尚无优化后的完整原图对照，不能用F072替代；保存重开、原生Undo及取消重试使用副本验证。

用户反馈首箱放置中的鼠标操作约2秒；旧44.531秒原生放置区间扣除该估计后，约42.5秒仍需定位CAD命令处理。现有计时将命令返回后的动态状态、计划重建、源图复核和各回路插入分别记录，不虚构原生命令内部“预览已就绪”的时刻。

加载文件只注册命令，执行`ELFULL68`才初始化当前版。旧v0.1.67包及目录保留，CADTools安装菜单不更新。本包仅来自`codex/lighting-shape-reuse`，未合入并行提交`91cc1bc`的闭合回路空功率生成行为；出现闭合回路阻止生成时，应与模板读取闪回分开判断。
