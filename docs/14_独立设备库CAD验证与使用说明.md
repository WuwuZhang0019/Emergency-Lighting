# 独立设备库 CAD 验证与使用说明

日期：2026-10-12
状态：107 独立拾取、图例与生成提示已实现；自动检查见更新记录，真实 AutoCAD 2020 验收待执行

## 1. 加载与数据位置

完整解压 `应急照明-107.zip`，保留 `src`、`ui`、`config`、`output`、`templates` 等目录。使用 `APPLOAD` 加载本包的 `START-CAD2020.lsp`，确认命令行显示 **CAD2020 v107**。不要直接加载仓库 UTF-8 源文件。已经打开的其他图纸需在各自图纸中加载本包入口。

107 保留图例表右侧设备库资料编辑区，增加独立拾取入库，并改用临时图纸生成现场图例及合并缺功率提示。先在一张空图运行 `ELSTAT`，应显示拾取入口、完整设备库入口且历史记录列表为空；关闭或取消不写图、不报错。再使用下面的真实设备样本验证。

新命令为 `ELDEVLIB`。设备库默认保存在运行 CAD 的用户的 `%LOCALAPPDATA%/Emergency-Lighting/device-library/`，窗口顶部显示实际路径；升级插件目录不会覆盖该库。这里的用户名取自运行 CAD 的计算机账户，与本次开发机器的账户可以不同。

用户库包含 `catalog.eld`、`assets`、`history`；备份或转移设备库时复制整个目录。在“更改库目录”中选择新目录里的 `catalog.eld`，目录配置会记住。单独复制索引不能搬走图块图形和图例。正常统计和材料表的手填值只保存为本箱覆盖；独立拾取会直接保存图形及条目，库资料编辑在明确保存、删除、恢复时生效。

未保存的管理器输入可在当前图纸会话中保留；关闭 CAD 或重新加载程序前，应将需要保留的设备资料保存为正式项或停用草稿。

## 主面板右侧快捷编辑（102）

点击图例图形，在右侧编辑对应库资料，点击“保存到设备库”提交。左下“保存”用于本图草稿，两者分别生效。图例表的本箱手填功率和地面不会因库默认值保存而被覆盖；主动点击“应用当前库值”才覆盖本箱值。

切换图例或按 Esc 会保留本次 CAD 会话内未保存的库输入。“在图中查看选中设备”保留定位功能；“完整设备库”以及右侧拾取、修复入口打开原管理窗口，继续使用当前草稿。库目录管理、导入和搜索仍在完整设备库操作。

预览可能来自图中缓存，只有资料及资产齐全才可启用。未登记图形时填写资料可以先存草稿，再到完整设备库独立拾取入库；已填写的原始输入保留，图形直接保存。请在实际分辨率和缩放下检查四栏能否完整显示。

## 2. 首次登记及增删改查

建议先用 DWG 副本登记两种设备，以便核对：一个普通设备，例如 5W 应急灯；一个地面设备，例如 1W 地面标志。填写真实设计参数，示例数值不作为工程默认值。

1. 运行 `ELDEVLIB`，无需先新增或选中设备，点击列表下的“拾取设备入库（可多选）”；或独立执行 `ELDEVPICK`。按预设设备图层选取多个实际设备 INSERT，Enter 完成选择，同名实例只处理一次。
2. 程序读取有效图块名、导出独立 DWG，并打开本次临时图纸生成图例。锁定、冻结、关闭图层只在该临时图纸里调整；原图状态保留。图形有效后条目直接写入设备库，缺资料时为草稿，已有有效图形复用。完成后回到来源图纸及设备库窗口。
3. 选中入库条目，检查线、文字、填充、比例及动态状态，再填写设备名、真实整数 W，将“是否地面”选为“非地面”或“地面”，勾选“启用名称匹配”，点击“保存设备”。只有参数、图形和图例都有效的启用条目才提供库默认值；0W 必须明确确认。入库前功率保持空白，不会自动推成 0W。
4. 搜索图块名、设备名或别名，修改设备名或功率，保存并重新打开；图形资产版本应保持不变，不重新截取图例。
5. 删除后勾选“同时显示已删除设备”，选择并恢复。原图形和历史仍保留；资产缺失时恢复为停用草稿，补齐后再启用。

另外验证以下操作：拾取时按 Esc，应回到同一项并保留输入；关闭再打开管理器，当前会话草稿仍在；同名或别名冲突应显示冲突名称并拒绝发布；改图块名默认保留旧名为别名，也可取消该选项。

普通、动态、旋转缩放、嵌套及天正来源块至少各检查一个真实样本。打开库内导出的 `block.dwg`，核对块结构、属性、文字、线型、填充和登记状态，确认来源图未被炸开、重定义或修改。一个有效块名对应一种固定参数；同名动态状态需要不同功率或地面属性时，应采用不同块名登记。

图形登记需要多图纸模式 `SDI=0`。导出或图例任务失败时不显示保存成功，保留编辑值；返回来源图纸执行 `ELDEVLIB` 可重试已完成的回调。临时图纸尚未关闭时不能当作完成；保留失败现场和提示供排查。

登记前后分别查询 `FILEDIA`、`CMDECHO`，成功登记和故意使图例生成失败时都应恢复原值。来源图纸的视图与对象状态也应保持，不能因登记改变后续打开／保存文件的操作。

## 3. 识别、材料表和人工值

1. 运行 `ELSTAT`，按既有操作拾取来源配电箱和回路；已登记设备应按完整有效块名匹配，材料表显示标准图例、设备名、数量、单个功率和地面值。
2. 人工数设备，逐条核对数量乘功率与回路功率；实际归属、导线接触和断口判断应与 095 一致。同一项的别名且参数一致可合并；相同设备名但不同参数应分行。
3. 点击材料表图例定位，核对高亮的是当前回路的实际源对象。日常打开材料表不应逐行隐藏源图或为图例重生成。
4. 从材料表进入设备库，修改并保存默认参数，再关闭管理器。返回后应保留当前回路、容量和手填值，刷新库默认值；不会自动生成系统图。
5. 将一个本箱功率改为 7W，另做明确 0W 和非地面覆盖，保存并 `QSAVE`，关闭重开 DWG，再统计。这些手填值应保持，不隐式回写共享设备库。
6. 在库中修改默认功率，再重新统计或 `ELUPDATE`：标记为库默认的值跟随新库，人工值保持。已有系统图只有在保存／生成／更新时改变。材料表的“应用设备库默认值”会明确重置已匹配设备的手填功率和地面覆盖，使用前核对当前值。

库修改发生在其他窗口时，当前面板第一次保存或生成应提示默认值已刷新、手填值保留，并停留供核对；第二次操作才能按看到的参数提交。提交期间仍会再次检查实际索引，发生变化时拒绝混用版本。

## 4. 未登记设备、旧资料和故障

使用一个未登记但实际接线的设备，确认材料表保留该项并提示待登记；不能漏算后称功率齐全，也不能按 0W 或非地面自动生成。可在库中登记后返回，或明确填本箱功率和地面；非设备对象使用已有排除入口，保留排除记录。

点击“导入旧图块功率 / 设备资料”，选择旧交付目录 `config` 中的 `block-powers.eld` 或 `device-library.eld`。同目录两种文件一起校验和备份；原文件不修改，备份位置显示在候选窗口中。同名不同参数只选择一种，导入已有名称或别名会被拒绝。导入只生成待补资料的草稿，须逐项补图形、确认地面与 0W 后保存。

旧 DWG 和旧本箱缓存中明确的功率、地面值作为人工值保留。新独立缓存优先；尚无新缓存时，先查当前配置与明确选择的旧配置目录，再按交付目录序号倒序查同一用户的 `runtime-*/config/`，只读取本 DWG、本箱对应的缓存。旧缓存不改写，后续保存使用独立目录。高级 `ELTRACE` 的旧身份库继续兼容。首次打开旧图与新登记的新图分别验证，避免把旧图的人工值误当作库默认。

在测试库副本中，将一项 `legend.sld` 改名：参数仍保留，管理器应显示待修复图例；点击“从库内图形修复图例”，预览后保存，应产生新的资产版本，旧版本仍在。原始 DWG 缺失时重新拾取图形。删除或临时移走库后重开已保存 DWG，旧系统图和参数应仍能显示；重新生成需要修复库，不能因库缺失变成 0W 或删除旧图。

测试只读目录、损坏索引及两个窗口先后保存。写入失败、锁占用或版本冲突必须保留原文件和当前输入，不报告成功；关闭写入窗口后刷新或重试。写锁不要在另一个窗口仍写入时删除。

## 5. 系统图及性能复测

使用同一机器、同一 AutoCAD 2020、同一 DWG 副本、同一配电箱和日志设置，分别验证新增系统图、只改功率、完全无变化更新。原图实际回路和预留数、箱号、用途及每条功率均应保持正确。只改功率应增量改受影响文字；完全无变化应无实体修改、无主记录写入、无事务启动。首次从旧版本迁移或库修订变化属于实际数据变化，另测一次稳定状态的无变化更新。

保留 095 作为同条件对照，先预热，再分别恢复相同状态测五次，记录中位数和最小／最大值。首次登记另测，登记导出成本不混入已登记统计；新增放置、原位更新和无变化更新分别比较。

从 CAD 命令行显示的实际路径收集 `ELPERF.log` 和 `ELTRACE-debug.log`；自动释放目录时通常在用户 `runtime-107/output/`。检查：

| 项目 | 预期及比较方法 |
| --- | --- |
| `package` | `package-107.marker` |
| `device-library-loads` | 同一顶层命令正常读取一次；明确打开管理器、刷新或库发生变化会增加 |
| `device-library-matches` / `device-library-unknown` | 与本次实际名称匹配过程一致；重新准备材料表时计数可累积，不当作总设备数 |
| `device-legend-builds` | 日常已登记识别和材料表为 0；登记／修复属于单独场景 |
| `DEVICE_LEGEND` | 读取已保存 SLD；结合读取次数和耗时判断收益 |
| `program-ms` / `after-placement` | 比较程序区间和放置确认后的区间；排除交互等待 |
| `network-build-calls` / `network-verified-reuses` | 保留 095 完整几何复核后的网络复用；输入有变化时允许重新建网 |
| `entity-write-attempts` / `master-write-attempts` / `transaction-starts` | 稳定无变化更新全部为 0 |

保留源图变化测试：移动设备、改导线、改块内部轮廓或可见性，重新统计应发现变化并正确重建；放置时取消应无半成品，保存后 `UNDO` / `REDO` 再统计应保持关联正确。源图扫描优化继续由 [🌟优化耗时](codex://threads/01a120e7-3961-7ff2-9bb5-3fe51a98aac3) 负责。

自动回归和编码／ZIP 检查只能证明对应检查通过。上述 WBlock 导出、跨图纸回调、SLD 显示、DCL 操作、真实 DWG 重开与速度，须以 CAD 实测日志和截图确认。
