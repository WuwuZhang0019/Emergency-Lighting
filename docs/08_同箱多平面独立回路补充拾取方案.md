# 08 同箱多平面独立回路补充拾取方案

日期：2026-10-10
状态：方案已记录，待实施；本次仅落盘文档，未修改程序

## 1. 已确认的需求与范围

同一个实际配电箱可能在两个平面分别表达：一个表达顶面灯具回路，另一个表达地面灯具回路；两类回路也可能在同一个平面表达。

用户已明确：**补充拾取只追加独立回路，原回路保留；不考虑将已有回路的另一段合并进原回路。**

本方案作为方案 04 与方案 06 的增量，不改变原有设备识别、功率计算及系统图模板规则。以下交互和数据处理属于待实施设计，不代表当前软件已支持。

实施默认范围为同一 DWG 内的多个平面表达；跨 DWG 汇总不纳入本次方案。单位沿用项目固定的 mm。

## 2. 交互流程

1. 用户按现有流程拾取第一个平面的配电箱并完成统计，在主面板核对回路与设备功率。
2. 主面板增加“补充拾取”按钮。点击时先保留当前功率草稿、回路设置、选中项及箱体设置，再暂时返回图面拾取。
3. 用户拾取补充来源的箱体：既可拾取另一平面的箱体表达，也可拾取原箱体。此次操作明确表示将补充来源关联到当前配电箱，不按箱名自动认定归属。
4. 沿用现有导线识别方式，识别并集中展示该来源的候选回路；仅将独立且未收录的回路作为新增候选，支持查看整条路径与设备并排除误选项。
5. 用户确认后，新增回路追加到原回路列表末尾，返回同一个主面板。原回路、功率草稿和人工设置保留，新回路按原有规则补齐功率并核对“是否为地面”。
6. 可重复补充多个来源，最终统一保存至同一配电箱记录，并生成或更新同一张系统图。

不增加“并入已有回路”选项。顶面或地面的来源描述不作为自动判定回路类型的依据。

## 3. 追加与去重规则

- 补充拾取属于追加操作，不用补充来源的识别结果替换原配电箱全部回路。
- 原回路的稳定身份 `circuit-uid`、编号、输出顺序、功率及人工设置保留；新增回路获得新的稳定身份，编号不得与已有回路冲突。
- 同一实体、同一已收录回路被再次拾取时跳过，不重复增加回路、设备数量或功率；不能只比较回路名称或显示编号。
- 候选回路与已收录回路共用导线或设备等实体时，标记归属冲突并要求排除或修正，本功能不执行分段合并。
- 两个平面各自绘制的不同实体，不凭同名图块、距离或相同功率判定为同一实际设备。集中核对时由用户排除重复表达，不能自动叠加存在未解决冲突的结果。
- 补充来源已关联到其他配电箱记录时提示冲突，不静默迁移、覆盖或合并记录。
- 没有新增独立回路时明确提示，保持原结果不变。
- 取消拾取、取消候选确认或识别失败时，丢弃本次补充草稿，恢复原主面板和已输入内容，不留下半完成的来源关联。

## 4. 数据保存与后续更新

当前实现通过单个来源箱体句柄查找系统图记录。实施时需扩展为“一个逻辑配电箱记录关联多个来源箱体”，保持同一系统图身份；每条回路记录其来源箱体及识别依据，支持按来源定位和重算。

- 兼容原有单来源记录，首次补充时扩展来源集合，保留原记录和系统图身份。
- 成功保存后，从任一已关联来源箱体进入，均应找到同一配电箱记录并恢复全部来源的回路。
- 补充与重新统计的语义分开：补充只追加；重新统计某一来源时，仅核对和更新该来源的回路，不因其他平面的回路本次未被拾取就将其删除。
- 原有回路确需删除或来源对象已失效时，明确列出待处理项，不静默删除其他来源数据，也不将旧数据标为已重新验证。
- 新增设备类型按既有规则填写功率，已知类型沿用既有功率；整箱汇总包含全部已确认来源的实际回路，完整性及超限判断继续执行现有规则。
- 系统图更新沿用原关联，以稳定回路身份匹配旧行；新增实际回路排列在两条预留之前，预留仍只有两条且不计功率。超出当前模板支持范围时提示处理，不截断回路。
- 保存、回读校验和系统图更新需沿用现有事务保护，失败不能留下部分追加、重复系统图或丢失原回路的状态。

## 5. 实施与验收清单

1. 扩展来源关联、兼容读取及回路来源记录，再接入补充拾取与主面板草稿恢复。
2. 调整按来源重新统计和系统图更新，避免追加被当成替换、其他来源被当成删除。
3. 进行针对性自动检查，覆盖单来源旧记录、多来源保存恢复、稳定身份、去重、取消和事务失败恢复。
4. 实施涉及 LISP/DCL 修改时，按项目规则重新构建 GB2312 交付包并核验目录及 ZIP 内容。
5. 在真实 AutoCAD 2020 中验证下列场景，自动检查通过不代替真实 CAD 验收。

| 场景 | 预期结果 |
| --- | --- |
| 两个平面分别表达顶面、地面独立回路 | 补充后同一箱内保留两组回路，只关联一张系统图 |
| 同一平面补充遗漏的独立回路 | 仅增加遗漏回路，原回路编号与设置保留 |
| 重复补充同一来源 | 不重复计数，不重复新增回路 |
| 补充识别与旧回路重叠 | 显示冲突，不合并为已有回路的另一段 |
| 补充过程中取消或报错 | 原结果、功率草稿和选中项保留，无半完成关联 |
| 保存并关闭、重新打开 DWG | 从任一关联箱体恢复同一箱的全部回路 |
| 仅重新统计其中一个平面 | 其他来源的回路不被误删或覆盖 |
| 已有系统图追加新回路 | 原有行按身份保留或更新，新回路加入，末尾保持两条预留 |
| 保存回读或系统图更新失败 | 事务恢复原状态，不留下部分追加结果 |

当前上述实现与验收均待执行。本次文档落盘不构成功能实现或真实 CAD 验收完成。
