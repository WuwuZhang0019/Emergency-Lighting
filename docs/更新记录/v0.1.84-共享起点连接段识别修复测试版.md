# v0.1.84 共享起点连接段识别修复测试版
日期：2026-10-23
状态：本地测试交付；真实CAD验收待完成

酒店图箱体CACF的五条已选起点中，C874为横向连接段，四个已选支路起点接在其中间。原有起点隔离规则使它无法串入其他支路，但仍作为一条独立空回路显示。本版在完整追踪后判定共享起点空段：其自身必须只有一条直线导线、没有设备和后续对象、追踪完成且无问题，并与至少两个不同位置的已选支路起点实际接触；支路方向也须与共享段不同。

符合证据时不单列该回路。原始起点、源图快照和变化监测保留，其他支路的种子身份、编号及功率对应关系保留；重开面板不恢复该空回路。有自身设备、有后续导线、只有一个接点、相同位置重复起点、共线、未实际接触、高程不同、折线或曲线等不确定情况继续保留。判断使用实际坐标和现有容差，不按水平外观、名称或最近距离过滤，不增加全图扫描，不修改平面。

## 测试步骤

1. 完整解压`应急照明-v0.1.84.zip`，APPLOAD根目录`ELFULL84.lsp`，输入`ELFULL84`。
2. 重新拾取原箱体和导线，可按原五起点复测。C874应在命令行记录为共享连接段，面板保留四条实际支路；其他闭合或功率问题继续仅提醒，未知功率留空。
3. 如缺系统图块或样式，点击“从图库补入缺项”，准备好模板后再生成并选择放置位置。此前模板缺项原面板提示及可见失败原因已纳入本包。
4. 完成或失败后运行`ELDIAG`。`current-result.eld`中的`start-link-exclusions`及`CIRCUIT_START_LINK_EXCLUDED`日志保留原种子和支路依据；`panel-template.eld`保留模板阶段、来源、缺项和失败原因。没有生成记录也可导出模板状态，切图不会混入另一图纸。

## 版本与验证范围

内部`PACKAGE_NO=183`，后备目录`runtime-183`、标记`package-183.marker`。只读对照为`ELCOLD84.lsp → ELCOLD84`，默认Both且不打开统计面板；DLL为`EmergencyLighting.ColdRecognition84.dll`，原生入口`ELNETCOLD84`，精确握手`EL_NET_COLD_PROBE_V1/0.1.84`。只读候选算法保持，旧版交付物保留。
