# v0.1.61 去除空白退出按钮

日期：2026-10-16
状态：源码及 11 项定向适配检查通过；按用户要求提供 CAD2020 试用包，原生显示与退出接收待复测

## 空白按钮

用户确认 v0.1.60 的 Esc、叉叉和空白按钮均能退出，但诊断按钮右侧多出可见空白按钮。普通 `button` 即使设置极小宽高和空标签，仍会绘制边框。

将窄面板及设备库展开面板共用的退出接收项改为无边框空文本，保留 `cancel`、`is_cancel`、原有退出回调及设备库输入保留逻辑；诊断按钮仍负责导出并打开文件夹。9 条及以上回路的提示及生成拦截继续保留。

## 加载与检查

版本为 `v0.1.61`，内部兼容标识 160。完整解压 `应急照明-v0.1.61.zip` 到新目录，用 `APPLOAD` 加载包内 `START-CAD2020.lsp`，确认显示 `CAD2020 v0.1.61`，再运行 `ELSTAT`。历史交付物保持原样，不要直接加载仓库中的 UTF-8 LISP/DCL 源文件。

源码修复提交为 `d3eb9d7`。11 项有限适配检查通过，覆盖真实 DCL 控件类型及空按钮检查、两种布局的退出回调、首页和结果页关闭、有效/无效输入及写入失败后的草稿保留，并回归预览、容量、诊断入口和回路数量反馈。交付检查核对严格 GB2312 编码、LISP 解析、三个入口的最新函数、嵌入界面及源码一致，以及 ZIP 与解压目录的完整文件清单和字节一致性。

文本接收项参考社区使用经验，官方 `is_cancel` 属性表只列出普通按钮。适配器执行回调不代表原生键盘事件已通过；本版仍需在 AutoCAD 2020 中复测空白按钮消失、窗口宽度、Esc 和叉叉退出及当前输入保留。
