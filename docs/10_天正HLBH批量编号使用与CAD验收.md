# 天正 HLBH 批量编号使用与 CAD 验收
日期：2026-10-11
状态：独立功能已实现，自动检查通过；真实 AutoCAD/天正验收待完成

## 加载与使用

只加载本工具：`APPLOAD` 选择 `output/HLPLBH.lsp`。该文件已严格转换为 GB2312，可供简体中文 Windows AutoCAD 2020 加载。仓库内 `src/batch-number.lsp` 是 UTF-8 源码，不作为 CAD2020 的加载文件。

1. 在已经加载天正电气的 CAD 中运行 `HLPLBH`。
2. 输入 `ZE1`，或者直接回车采用默认编号。以后回车保留上次成功批次的起始编号。
3. 框选五条需要编号的独立出线段，回车结束选择。
4. 在左侧或右侧空白处点一次，确定最上方编号的文字折点。

工具在当前 UCS 中按导线中点从上到下排序，同高度按从左到右排序。每个选中的导线对象只生成一组标注，编号为 `ZE1` 至 `ZE5`，文字折点横坐标统一。末尾数字支持连续递增和补零，例如 `4ALE(JZ)-ZE009`、`4ALE(JZ)-ZE010`。点击位置决定第一行的高度和整组标注所在侧。

工具每条线都通过 `HLBH` 提供两个输入：准确的导线对象和线上的连接点，以及程序计算的文字折点。天正浮动窗口保留原命令行为，无需逐条操作窗口。工具只通过标注对象实际开放的 `TextString` 接口核对和设置编号；窗口中的当前编号即使与本次输入不同，也只有在原生文字接口确实可写且回读一致时才会继续。

本工具不分析回路连通性。请只选独立出线段，避免框入母线、已有标注的引线或同一回路的多段线；这些普通线段与导线可能是同一种 CAD 对象，不能仅凭类型自动区分。文字、图块、闭合多段线和不支持曲线接口的对象会被跳过，命令行报告跳过数量。

## 排列和撤销

默认最小行间距依据当前 `TEXTSIZE` 和 `DIMSCALE` 计算，并尽量保留导线的纵向间距。若生成标注开放 `Height` 或 `TextHeight`，后续行会按实际字高增大间距。

需要调整时可单独运行 `HLPLBHSET`，输入最小行间距；输入 `0` 恢复自动计算。正常编号流程不会重复询问间距或单位。

成功批次纳入一个撤销分组，单次 `UNDO` 应撤销整批。失败和中途取消时先停止天正命令，再尝试整批撤销，并核对新增实体和原导线快照。若天正改变撤销分组或自动恢复未确认成功，会保留待恢复状态并给出提示；期间不要继续绘图，在原图运行 `HLPLBHRECOVER`。工具不在其他图纸中执行恢复，也不自动撤销失败后检测到的其他绘图改动。若提示撤销分组已改变，需先手动撤销本批次，再运行恢复命令核对。

## 兼容性失败和日志

日志为 CAD 临时目录中的 `HLPLBH-debug.log`，具体绝对路径会在命令行打印。日志包括排序计划、每条导线的连接点和文字点、天正实际提示、新增实体类型、编号接口及回读结果。

以下情况会停止，不会自动替换成普通文字与线条：

- 天正未加载，或 `HLBH` 的实际提示与截图中的选导线/文字落点流程不同。
- 天正版本不接受程序传入的导线对象和选线点。
- 新标注没有唯一可读取的 `TextString`、编号需要修改但属性不可写，或文字含有不能安全保留的内嵌格式。
- 写入编号后回读不一致、命令退出后编号变化，或原生文字对象类型发生变化。
- 选中导线连接点重合、编号序列超出整数范围，或导线与文字点不在当前 UCS 的同一平面。

这些失败说明当前天正版本需要适配。自动检查不证明天正私有对象开放了 `TextString`；遇到失败，请保留完整命令行及日志，尤其是 `PROMPT`、`CREATED`、`TEXT_INTERFACE_UNAVAILABLE`、`FAILED` 和 `ROLLBACK` 记录。

## 真实 CAD 验收清单

当前环境未运行真实 AutoCAD/天正，以下项目尚未验收：

1. 原图中用 `ZE1` 框选五条独立出线，仅点一次空白处；核对 `ZE1` 至 `ZE5` 自上而下、一线一组、文字对齐、引线落在对应导线上。
2. 天正浮动窗口设置成其他编号，例如 `wl12`，本工具输入 `ZE1`；核对程序能否在原生标注上改号并读回。接口不支持时应报告原因并撤销本批次，不得显示成功。
3. 双击或通过天正编辑新标注，核对原生对象、文字样式、斜线、引线和导线关联是否保留；保存 DWG、关闭并重开后再次核对编号和关联。
4. 在副本图中验证旋转 UCS、左侧放置、密集出线、文字/图块混选和锁层；核对跳过数量、排序和字高间距。
5. 正常完成后单次 `UNDO` 应删除整批标注；中途按 Esc 应撤销本批次并恢复捕捉、正交、动态输入等原设置。没有天正或提示不兼容时，不应撤销之前的绘图操作。
