# 拾取配电箱编号（084）
日期：2026-10-11
状态：历史版本，交互已由 085 连续拾取流程替代

## 操作
1. 解压完整的应急照明-084.zip，APPLOAD 加载 START-CAD2020.lsp；已加载旧版可加载 UPDATE-084.lsp。
2. 输入 ELSTAT，拾取配电箱或集中引出线，进入回路与图块设置。
3. 点击“拾取配电箱编号”，选择图上的编号文字或块属性，自动返回面板。
4. 点击“保存”记录编号；点击“生成或更新”将编号写入系统图编号栏。最后保存 DWG。

没有编号时使用“暂无编号”。取消或选错对象保留当前编号。支持 TEXT、普通 MTEXT、ATTRIB 和 ATTDEF；含格式控制的 MTEXT 会提示选择普通文字或属性。编号作为拾取时的文字值保存，源文字随后修改时须重新拾取。

保存记录显示编号，系统图使用相同编号。旧记录无编号时显示“暂无编号”。箱体仍按内部句柄关联，重复编号不会合并记录。单独 CCKK1 的示例插入行为不变。
