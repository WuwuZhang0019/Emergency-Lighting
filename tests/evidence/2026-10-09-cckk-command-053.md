# CCKK2 命令入口与旧 XRecord 字段替换
日期：2026-10-09
状态：110 项定向自动检查通过；真实 AutoCAD 2020 待复测

## 现场与根因

依据用户 ELTRACE-debug(7).log 的事件 6539～6560：5318 个新字段在写前编解码通过，实际 dictsearch/entget 均返回 5392 个字段，首项仍为旧文本 code 1；相差 74 个旧字段。新类型标记应在首项 code 300，因此解析失败发生在生成前保存草稿，而非回路识别或功率计算。截图的 1 条回路、29 个设备、85W 已进入核对面板。

v52 的按钮只复用了 CCKK2Rows 排布，没有执行 c:CCKK2。v53 将面板生成经 EL:InvokeCCKK2 直接调用 c:CCKK2，以动态作用域传入当前统计、配置、功率与容量。首次生成进入 CCKK2 原生 -INSERT 鼠标放置箱体，随后插回路并保存原有受管身份；已有系统图原位更新，手动 CCKK2 保留独立示例行为。

已有 XRecord 的数据使用 vla-SetXRecordData 完整替换，DXF 40 明确用 double、90 用 long、字符串用 BSTR；不再依赖 entmod 省略旧字段。保持 XRecord 句柄、字典归属、schema 与回路身份；保留写前/写后完整校验与失败撤销。官方 API 依据：[SetXRecordData](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-ActiveX-Reference/files/GUID-8426BA72-1852-40BC-84D4-F63F49A0DE74.htm)。
