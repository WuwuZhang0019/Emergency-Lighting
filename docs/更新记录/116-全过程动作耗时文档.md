# 全过程动作耗时文档
日期：2026-10-13
状态：源码及定向检查完成；真实 AutoCAD 2020 验收待执行

用户反馈操作仍慢，需要看到从加载到退出的每个动作及耗时。本次增加默认启用的动作时间线，不改变识别规则、设备功率或记录存储格式。

## 使用

解压 `应急照明-116.zip`，保留完整目录，在 AutoCAD 中 APPLOAD `START-CAD2020.lsp`，然后运行 `ELSTAT`，按原流程拾取、设置、生成和退出。

加载完成及命令结束时，命令行显示“全过程耗时文档”及完整路径。文件位于实际运行目录的 `output/ELMONITOR-时间-命令.md`。重名时递增后缀，不覆盖旧文档；运行目录不可写时尝试临时目录。无需另外打开监控开关。

每次 ELSTAT 文档包含最近一次插件加载记录及本次执行记录。加载后尚未运行命令的空闲时间不计入程序耗时。每项记录动作序号、父动作、相对开始秒、结束秒、总秒、程序秒、交互秒、中文动作内容、阶段标识和返回或中断状态。

## 记录范围与计时口径

- 加载：入口及公共函数、各源码模块、目录确认及内置资源释放、默认设备库初始化。
- 面板：加载、初始化、拾取按钮、加载保存记录、切换记录、回路和图块填充、翻页、功率及地面状态编辑、设备库操作、保存、生成、取消。
- 业务：拾取、源图收集、建立网络、拆分回路、核对编号、生成前核对、系统图处理、序列化、解析、图纸记录写入、回读核对、上下文提交、视图定位、退出。
- 每个动作按调用开始顺序排列。父动作包含子动作，不能把表格各行相加；没有独立设点的间隔仍在父动作及总时间内。逐实体、顶点等内部循环按批次计时，避免大量日志反过来拖慢操作。
- 面板等待时间扣除本插件控件回调处理。原生放置输入仍包含 CAD 处理鼠标动态预览的时间；未包装的原生提示框等区间不能单独拆分。函数“已返回”不等于业务成功，需结合文档头部业务结果及原诊断日志判断。
- 原生取消或可捕获错误通过现有退出处理收尾，未返回的动作标为中断。强制终止 CAD 进程、断电，或公共函数尚未加载时发生错误，无法生成完整收尾文档。
- 动作只在内存中记录，结束后集中写一次；日志和文档输出不计入业务总时间。文档末尾另记文档生成至末行的用时，不含关闭文件耗时。
- 仓库文档为 UTF-8。AutoCAD 2020 运行时文档与原诊断日志使用系统代码页，简体中文 Windows 可按 GBK 打开；无需调用额外 COM 组件转换编码。
