# 118 按箱拆分存储与兼容迁移
日期：2026-10-13
状态：S1/S2 已实现，定向适配器验证通过；待真实 CAD 验收

- `store-split.lsp` 管理轻量根索引、每箱详情及独立大字段。列表仅解码根索引，打开指定箱才加载该箱快照与配置；已有单体格式仍经原解码器只读打开。
- 明确保存或生成时，先备份旧 XRecord 的原始字段，再将所有旧箱完整拆分并精确比对，之后应用当前修改。兼容无标记文本、EL_TYPED_V1、EL_COMPACT_TYPED_V2/V3。读取、预览和取消不迁移。
- 内容相同的不可变块直接复用，变化详情或快照各自写入。新块完成编码校验及 dictsearch/entget 两路精确回读后才发布根；准备期间原记录改变即拒绝发布。仍使用已有 UNDO 事务和失败恢复。
- 保留字段顺序、类型、双精度浮点、formal-source、未知扩展字段和箱体/回路身份。旧根及历史块作为恢复证据保留；本阶段不自动回收历史块，DWG 可能随多次修改增长。
- `ELSTORELEGACY` 导出当前最新逻辑数据，再停用拆分根；后续再次保存可重新迁移并保留之前备份。
- 定向场景：4 种旧格式读取与迁移、两箱身份与扩展字段保留、列表仅读根、单箱详情读取、修改功率仅新增详情块、空变化不写块、根发布失败全组撤销、原生载荷变化使上下文失效、最新数据导出旧格式及再次迁移。
- 当前完整业务写前仍核对全部可达块，避免仅凭散列或历史缓存覆盖其他修改；减少的是大载荷重复解码与序列化。首次迁移需要处理所有旧数据，不承诺首次保存立刻变快。
- 尚需真实 CAD：原 DWG 保存/关闭/重开、生成失败与 Esc、UNDO、复制对象关联、库功率在另一箱复用，以及时间日志对比。自动适配器结果不代表这些实测已经完成。
