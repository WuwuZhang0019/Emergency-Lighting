# 136 加载资源批量释放

日期：2026-10-14
状态：实现及针对性检查已完成；真实 AutoCAD 2020 加载耗时待实测

## 依据与目标

用户提供的 134 包 `output (5).zip` 中，APPLOAD 为 26.313 秒，其中 `LOAD_ROOT` 为 25.000 秒；模块加载合计 0.219 秒，默认设备库初始化为 0.516 秒。原日志未细分目录查找和资源释放，不能将 25 秒全部认定为某一个子步骤。

目标是把加载压到约 2 秒。本版只调整加载资源路径；该目标须用用户环境中的 APPLOAD 总耗时确认。

## 调整

- 本地运行目录首次初始化时，源码、DCL、标记及设备资源统一通过 MSXML 和 ADODB 批量解码、写入与完整回读；LISP/DCL 仍是构建时严格转换的 GB2312 字节。
- 二进制回读改为比较 MSXML 规范化后的完整 Base64 文本，省去将原始和回读字节展开为两个 LISP 列表。保留全量内容比较，能发现同长度内容损坏及截断。
- 保留已确认同版本目录的复用、无弹窗启动和用户设备库资料。初始化失败不写完成标记；修复旧的残缺运行目录时先清除旧完成标记，以便失败后安全重试。
- `LOAD_ROOT` 下新增 `LOAD_ROOT_SEARCH`、`LOAD_RUNTIME`；资源释放再分为 `LOAD_RUNTIME_TEXT` 和 `LOAD_RUNTIME_ASSETS`。这些是父阶段的子项，不能与父阶段相加。

## 使用与验收

完整解压 `应急照明-136.zip`，在 AutoCAD 2020 中通过 APPLOAD 加载包内 `START-CAD2020.lsp`。分别记录第一次加载和再次加载的实际等待时间及 `output/ELMONITOR-*-APPLOAD.md`。

若日志提示使用本地运行目录，日志位于命令行显示的目录下；`ELROOT` 可手动切回解压包目录。重点比较 APPLOAD 总计、目录查找、源码/UI 释放、设备资源释放和默认设备库初始化。首次加载要计入资源释放，不能用第二次加载结果代替。

Windows COM 检查只能说明批量写入和完整回读有效，不等于 AutoCAD 实测，也不能据此宣称已达到 2 秒。

## 已有检查证据

- 加载与目录专项回归共 22 项，覆盖完整包、路径回退、重复加载复用、失败后重试、原资料保留及回读损坏；测试适配器不启动 AutoCAD。
- `tools/check_startup_com.ps1` 读取生成启动文件中的真实资源载荷，132 个文件（31 个源码/UI 文件、101 个设备资源）共 2,459,180 字节通过 Windows MSXML/ADO 写入、完整回读与独立字节比较。同长度内容损坏及截断均被拒绝。
- 本机该次 Windows COM 操作计时为 0.626 秒，不含 LISP 求值、Base64 分片拼接、COM 对象释放及 AutoCAD 加载；它仅说明原生批量路径可行。
- 交付包 LISP/DCL 严格 GB2312 编码、LISP 解析、ZIP 完整性及压缩包与解压目录一致性已检查。
