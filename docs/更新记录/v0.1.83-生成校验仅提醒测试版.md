# v0.1.83 生成校验仅提醒测试版
日期：2026-10-23
状态：本地测试交付；真实CAD验收待完成

用户提供的酒店办公照明图中，同一回路的导线分别带有 `ZE3` 与 `4ALE(JZ)-ZE3`、`ZE5` 与 `4ALE(JZ)-ZE5`，旧入口因此在放置前弹出编号冲突框。本版将本次源码修复纳入交付：显式点击“生成新系统图”后，编号、连接、功率、超限及源数据变化等校验问题改为命令行和日志提醒，继续按当前面板结果生成。

无法确认的编号显示“待核对-R1”“待核对-R3”等，已确认功率保留；连接、归属或功率不确定时保留图块，整个功率标注留空。输出保持待核对状态，保留原编号候选、导线句柄和问题证据。实际写入失败时撤销本次半成品并返回原面板，保留功率、容量和识别快照供直接重试。当前模板支持1至8条实际回路；超出时保留全部输入并给出文字提示。

## 测试入口

1. 完整解压 `应急照明-v0.1.83.zip`，在测试图副本中 APPLOAD 根目录 `ELFULL83.lsp`，输入 `ELFULL83`。
2. 重新拾取配电箱和起始导线，核对当前显示的回路及功率，点击“生成新系统图”并放置。
3. 编号冲突等问题应只在命令行提醒。结束或失败后运行 `ELDIAG`，保留完整命令行和诊断输出。

诊断包含 `GENERATION_WITH_WARNINGS`、`GENERATION_REVIEW_WARNING` 和 `GENERATION_ROW_IDENTITY_WARNING`。此前天正图块电脑名后缀兼容、四角单线设备识别及空功率生成修复继续保留。每次生成新系统图，原有图形保留。

只读性能对照为 `ELCOLD83.lsp → ELCOLD83`，默认Both，不打开统计面板。内部 `PACKAGE_NO=182`，运行后备目录 `runtime-182`、标记 `package-182.marker`；DLL为 `EmergencyLighting.ColdRecognition83.dll`，原生入口 `ELNETCOLD83`，精确握手 `EL_NET_COLD_PROBE_V1/0.1.83`。只读候选算法保持，旧版交付物保留。
