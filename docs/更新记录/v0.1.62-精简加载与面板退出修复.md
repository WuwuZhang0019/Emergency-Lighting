日期：2026-10-20

## 加载时重复确认

旧精简版入口逐个 `load` 26 个业务模块。在未受信任的安装位置，这些文件可分别触发安全确认，表现为连续点击“始终加载”。

新入口内嵌同源、严格 GB2312 转换后的模块代码，目录和用户数据路径验证通过后才按原顺序执行。模块文件继续保留供诊断及完整性检查。入口自身仍受 AutoCAD 的安全检查约束，不修改 `SECURELOAD` 或自动扩展可信路径。

## Esc 和叉叉退出

v0.1.61 为消除空白按钮边框，将取消接收控件改为 `text`。Autodesk 的 `is_cancel` 属性要求使用按钮，文本控件不能据此建立可靠的原生退出分派。

恢复正常尺寸、带“关闭”文字的标准按钮，放在诊断按钮下方；窄面板和设备库展开面板共享控件。沿用 `EL:PanelExit`，保留无效或保存失败的编辑输入，不因退出重新计算功率。

测试适配器同步限制 `is_cancel` 接收控件必须为 `button`，避免再次将文本属性当作原生按键分派已通过。

依据：[Autodesk is_cancel 属性](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-AutoLISP-Reference/files/GUID-9E400F8C-6E94-4B7E-BDFD-51F7C4AE419B.htm)。

## 贴临设备与后续导线漏识别

本次未修改几何识别规则。核对时，现有精简交付目录、ZIP、CADTools 源码模块及 Release 输出与 v0.1.61 源码对应的精简内容一致，未发现漏同步。

历史原图坐标子集包含 0.0038095 mm 线到图块间隙、0.005 mm 图块间隙。默认 `eps_device=0.01` 时，完整版源码及新精简入口均识别设备 `F099 / 84B8 / 8267` 和导线 `F097 / F159 / F15A`，包括后续断线连接。显式将容差设为 0 时，该历史样本仍会漏识别，符合严格接触语义；这不代表当前用户图纸一定由容差引起。

下一步需取得复现图纸、漏识别位置及“导出诊断日志并打开文件夹”生成的资料，核实实际运行目录、参数、筛选范围和几何。未经这些证据，不放大容差或把外接矩形接触当作真实导通。
