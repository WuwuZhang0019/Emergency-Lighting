# 122 回路起始端定向拾取

日期：2026-10-13
状态：已实现，必要自动检查与交付包检查见测试证据；真实 AutoCAD 2020 验收待执行

## 操作流程

1. 完整解压 `应急照明-122.zip`，APPLOAD 加载 `START-CAD2020.lsp`，确认 CAD2020 v122，运行 `ELSTAT`。
2. 点击“拾取配电箱”，选择实际箱体图块和编号文字；编号可按 Enter 使用“暂无编号”。随后自动进入导线拾取。
3. 连续点选各回路起始导线。点击位置靠近箱体或集中干线的一端，这一端作为搜索起点，黄色箭头指向设备侧。每条回路选择一次；重复点选同一导线会更新起点，不重复增加回路。
4. 点击两端等距位置时，程序要求补点起点附近；Enter 跳过该条。连续拾取阶段按 Enter 完成并开始统计。
5. 后续设备提取、功率、地面设置、编号排序、保存与生成沿用现有流程。重新选择导线可单独点击第二个按钮，无需重新选择箱体和编号。

## 搜索与保存边界

- 直接接箱和集中干线出线使用同一个入口。集中干线场景选取从公共干线分出的回路起始导线，不选公共干线本身。
- 起点必须是所选 LINE 或开放 LWPOLYLINE 的实际端点。若箱侧和负载侧绘制成跨越公共干线的同一个实体，需先提供从回路起点开始的独立导线实体；本次不按内部交点猜测起点。
- 排除在选定起点接入的未选导线，阻断公共干线和箱侧连接段；选定起点不能参与反向断口续接。设备侧正常 T 形分支、设备接触及断口续接保持原规则。
- 搜索只为明确选择的起始导线建立回路。真实下游互连造成的共享设备仍会阻止生成，不能把跨回路连接静默拆开。
- 配置保存起始导线句柄、起点端别及坐标；编号读取使用相同方向。源几何、起点及搜索规则参与来源复核。导线删除、移层或起点移动后须重新拾取。
- 取消拾取不写入 DWG，不改源图形；保留箱体和编号。在已有面板中取消重选，恢复原输入及页面。换图后不复用其他图纸的拾取上下文。
- 历史保存记录仍可按其原识别配置打开；重新点击第二个按钮选择起始导线并保存后，使用新配置。

## 必要验证

自动回归覆盖直接接箱、无箱侧连接段的五回路集中干线、仅选部分回路、反向绘制、共用起点、起点反向断口隔离、设备侧断口续接、下游共享设备、连续选择、重复改向、UCS 转换、取消重试、起点变化及记录往返。交付检查覆盖全部 LISP/DCL 严格 GB2312 解码、ZIP CRC、目录与压缩包字节一致、LISP 解析及三个加载入口的实际拾取流程。

这些结果来自有限 CAD/DCL 适配器，不代表原图或原生 AutoCAD 验收通过。

## 原图复核步骤

1. 分别使用直接接箱和集中干线的实际图纸，核对两个绿色按钮文字、编号拾取顺序和自动进入连续选择。
2. 选择多条不同方向、包含折线的起始导线，确认黄色箭头由箱侧指向设备。重复点选修改方向后，回路数量不增加。
3. 在截图对应的无唯一箱侧连接段图形上选择各出线，确认不再出现旧连接段前置错误，不统计公共干线、箱侧支路或未选回路。
4. 在起点附近有空线和断口时，确认不会向箱侧搜索；设备侧原有断口、分支及设备计数保持预期。
5. 分别在选箱、编号和导线阶段按 Esc；核对原图未改动、箭头及高亮被清除，完成箱号选择后可直接重选导线。
6. 填写功率后重选或取消，核对输入保留；保存草稿、保存 DWG、重开记录，核对方向、编号与回路数量；最后核对系统图生成。
7. 若仍有异常，保留完整命令行及提示路径下的 `ELTRACE-debug.log`，并说明所选起点及预期设备侧。
