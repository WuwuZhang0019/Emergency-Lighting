# 设备库统一数据源与自动入库方案

日期：2026-10-12
状态：可执行方案，待实施；本次仅完成文档落盘，真实 AutoCAD 2020 功能与性能验收待执行

## 1. 目标与范围

设备库统一保存并维护设备图形、图块名、设备名、别名、单个功率和是否地面。平面中发现设备后，已有完整库资料直接使用；未登记设备自动录入图形，再集中补齐资料。主面板不再维护另一套可编辑的设备功率和地面参数。

独立设备库接管主面板的图例展示和设备资料编辑。当前箱的设备列表作为设备库中的一个视图，提供本箱排除、恢复及源图定位；主面板保留回路、功率汇总、容量、保存记录及生成或更新操作。

本方案覆盖 `ELSTAT`、固定出线与干线拾取、受管系统图 `ELUPDATE` 的设备资料流程。复用现有源图采集、建网及真实接触判断，不重写连接算法；高级 `ELTRACE` 的旧身份库及系统图输出模板继续按原流程管理。

## 3. 数据来源与保存边界

| 数据 | 来源及保存位置 | 使用规则 |
| --- | --- | --- |
| 实际设备图形、标准图例 | 用户设备库的 DWG 资产和 SLD 缓存 | DWG 保留原始图形及依赖，SLD 用于显示；只有新设备、资产损坏或明确修复时重新生成 |
| 图块名、设备名、别名、单个功率、是否地面 | 用户设备库的 `catalog.eld` | 作为新流程中设备资料的唯一维护来源 |
| 设备实例数量、位置、回路归属 | 当前平面的实际对象及连接识别结果 | 不从库中推断；数量按实例身份去重，不能用图例或块名代替真实几何判断 |
| 回路及箱子总功率、地面判断结果 | 平面实例与库资料共同计算 | 按实际纳入统计的设备汇总，沿用现有回路判定及容量规则 |
| 本箱排除、恢复状态 | 当前 DWG 的配电箱记录 | 保存设备引用和本箱选择；不修改库条目的启用、删除状态 |
| 已保存参数与资料版本快照 | 当前 DWG 的配电箱记录 | 保留历史显示、追溯和库不可用时的恢复依据，不提供第二套日常资料编辑入口 |

继续使用设备库目录 `%LOCALAPPDATA%/Emergency-Lighting/device-library/`，沿用 `catalog.eld`、`assets` 和 `history` 的组织方式。升级交付包不覆盖用户设备库。

正式设备引用包含 `library-id`、`device-id` 及使用的修订信息。未登记设备先用规范化有效块名标记，入库后补上稳定引用；排除记录在转换前后必须保持对应。当前“排除本箱同类图块”的范围保留，恢复后按当前平面数量重新统计。

## 4. 从平面识别到设备库复用的流程

### 4.1 先发现设备，再匹配设备库

1. 用户拾取配电箱或集中引出线，沿用既有识别入口和回路追踪。
2. 在预设设备图层等明确范围内发现设备候选，再通过实际轮廓、接触和高程判断连接。仅靠近但未接触的对象不纳入；设备库名单不再作为发现设备的必要条件。
3. 排除配电箱、导线、引线及程序生成对象等已有明确类别。发现的库外候选必须保留，不能因缺库资料被静默过滤。
4. 读取本次库快照，建立有效块名及精确别名索引，按设备种类匹配，并收集每种设备在各回路中的实际实例。

自动入库只处理当前统计中实际连接、未被本箱排除的设备候选，不扫描并登记整张图所有图块。误纳入的辅助图块可在当前箱设备视图中排除。

### 4.2 匹配后分流

| 库内情况 | 处理方式 |
| --- | --- |
| 已有启用、资料完整且资产有效的条目 | 直接读取资料及标准图例，计算功率和地面结果 |
| 已有同名或别名对应的草稿 | 复用该条目及已保存图形，集中补填缺失资料，不创建重复项 |
| 完全未登记 | 每种设备选取一个来源实例，导出图形并生成标准图例，自动保存为库草稿 |
| 已删除或明确停用 | 显示该状态并提供恢复、启用或本箱排除入口，不自动恢复成可用项 |
| 资产缺失、名称冲突或资料读取异常 | 保留该设备及统计上下文，列出待处理原因；修复后再重算 |

匹配使用有效图块名和精确别名，不按相似设备名或相似图形猜测。同一有效块名对应一套功率和地面属性；同名动态状态确实需要不同参数时，应拆成不同的登记名称。同名但图形或参数有冲突时，不自动覆盖已有记录。

### 4.3 自动入库与集中补资料

自动导出复用现有多图纸及临时 DWG 流程，保存实际图块结构、属性和依赖，在临时图纸生成 SLD。登记需要 `SDI=0`；条件不满足时保留待登记项并显示具体原因。来源图的对象、图层、视图及相关系统变量应完整恢复。

图形成功保存后，条目先作为草稿保留，功率保持空白。设备库默认展示“当前箱设备”，把待补项集中列出；用户可以切换查看全部设备，也可关闭后稍后继续补填。

- 功率沿用非负整数 W 规则；空白或无效输入不当作 0W，明确 0W 沿用现有确认规则。
- “是否地面”统一使用可见的“是”复选框：勾选为地面，未勾选为非地面，不增加隐藏的非地面确认。
- 保存设备资料后，完整且启用的条目可供统计使用；资料仍缺失的项继续保持草稿。
- 切换设备、进入拾取、关闭或按 Esc 保留已登记图形、已保存草稿和当前会话未保存的原始输入；无效原始文本不被默认值覆盖。关闭 CAD 前，需要保留的未保存资料仍须保存。

图形自动登记和设备资料保存分别记录成功状态。导出失败、图例失败、发布冲突或写入失败不得提示完成；保留已成功条目及其他设备的处理结果，按失败种类重试。

### 4.4 返回当前箱继续统计

库资料保存完成后，从管理器返回原箱，恢复选中回路、编号、容量、排除状态及其他草稿输入，读取新库版本并自动重算。无需再点日常“应用当前库值”按钮，也不重新拾取配电箱。

只更新设备资料时复用仍有效的连接结果；平面对象变化时继续执行现有完整来源复核，按需要重新识别。资料不齐的设备保留数量和待处理状态，可保存本图待完善草稿；生成或更新不得将缺功率按 0W 通过。

## 5. 界面与更新规则

主面板移除并列的图例表、设备资料编辑区及日常“应用当前库值”按钮，保留“设备库”入口与设备种类、数量、待补资料等简要状态。缺资料提示可直接打开对应的当前箱设备视图。

独立设备库在有当前箱上下文时提供图例、名称、数量、功率、是否地面、本箱排除和恢复、源图定位。排除后仍可在本箱列表中查看并恢复；“删除设备”和“本箱排除”名称及效果必须明确区分。独立执行 `ELDEVLIB` 时没有箱上下文，本箱操作不显示为全局管理功能。

在新流程中修改某种设备的功率或地面属性即修改共享库资料。正在编辑的箱返回后自动重算；其他箱在后续打开并刷新、重新统计或更新时使用新资料。

关闭设备库或刷新统计不自动写入源图和已有系统图。仅在用户执行有效保存、生成或更新时，按现有事务流程写入对应记录和系统图；已保存图形不会因后台库变化立即改变。

提交前核对库版本，整个统计和写入使用一致快照。其他窗口同时修改库时刷新当前结果并保留输入，不混用不同修订；已有并发写锁、原子发布和失败恢复继续保留。

## 6. 旧数据迁移与异常恢复

旧 DWG 中的本箱人工功率、地面覆盖及旧辅助缓存先完整读取并保留。打开历史记录不直接覆盖它们，也不把旧箱参数静默发布到共享库。

迁移采用一次集中处理：在设备库中展示历史资料与现库的对应关系；同名同参数可复用已有项，缺库资料转为待完善草稿，冲突集中列出供用户选择并保存。完成映射和保存后，该箱的新统计使用库资料，原记录快照仍可追溯；不再逐次通过“应用库值”维护两套日常参数。

库目录切换、库暂不可用、条目被删除或资产损坏时，保留旧箱记录、已有系统图和当前草稿，并显示修复入口。仅有历史快照不能证明当前库资料完整；需要新统计或生成时完成修复，不把缺失参数转换为 0W，也不自动删除旧系统图。

导出或补资料取消后保留已经入库的草稿，下一次复用并继续补填。库中资料已经明确保存时，取消箱编辑不撤销该次设备库保存；本箱未保存的统计调整仍按当前箱草稿规则处理。

## 7. 性能预期与验证方法

### 7.1 预期收益与实现要求

预期更明显的收益是减少填写、切换窗口和重复制作图例。已登记设备的程序耗时可能降低，具体幅度待实测；首次自动登记包含 DWG 导出和 SLD 生成，可能比单纯查库更慢。平面采集、建网和连接判断仍可能占主要耗时。

- 同一统计批次共用库快照和名称索引；明确刷新、保存库资料及提交前版本复核按需要进行，不为每个实例重复加载全库。
- 同类设备匹配、导出及待补提示按种类去重；数量计算仍按真实实例。
- 已有有效 DWG 和 SLD 直接复用；只修改功率或地面属性不重新导出图形。
- 图例缓存按库身份、设备身份和资产修订定位；库目录、条目或资产修订变化时使对应缓存失效。
- 沿用既有来源复核和网络复用条件，不通过跳过接触检查或忽略平面变化取得提速。

### 7.2 同条件对比

实施时固定机器、AutoCAD 2020、DWG 副本、配电箱、日志设置和输入状态，记录对照版本与新版本。按 [性能优化方案](07_识别与系统图生成性能优化方案.md) 分离程序区间和用户等待；需要预热的场景先预热，再恢复相同状态测五次，报告中位数及最小、最大值。

| 场景 | 单独记录的内容 |
| --- | --- |
| 库资料齐全的统计与重复打开 | 程序耗时、库读取次数、图例生成次数、建网次数 |
| 空库及新设备首次登记 | 每种设备导出和图例耗时、补资料等待、返回原箱耗时；每次恢复独立测试库，不与复用场景混算 |
| 已有草稿补资料 | 是否复用图形、资料保存和自动重算耗时 |
| 修改功率或地面属性后返回 | 是否只更新相关参数、是否重复生成图例或重新拾取 |
| 原位更新与稳定无变化更新 | 写入次数及事务次数；稳定无变化路径应沿用现有零写入要求 |

保留实际路径下的 `ELPERF.log` 和 `ELTRACE-debug.log`，结合 `device-library-loads`、`device-library-matches`、`device-library-unknown`、`device-legend-builds`、`network-build-calls` 等已有计数解释结果。当前计数可能随重复准备累积，不把匹配次数误当作设备总数。没有同条件实测前不承诺提速百分比。

## 8. 实施顺序

| 阶段 | 工作 | 完成条件 |
| --- | --- | --- |
| U01 设备发现与库匹配 | 空库可进入统计；设备发现不受库名单限制，保持真实连接判断 | 库外连接设备不遗漏，未接触及辅助对象不误纳入 |
| U02 自动登记与补资料返回 | 复用图形导出、图例、草稿及跨图纸回调，接入当前箱上下文 | 同类只登记一次；成功、失败和取消均能回到原箱，草稿可继续 |
| U03 统一取值与本箱状态 | 库资料自动重算；排除记录、历史迁移、快照和并发版本检查 | 新流程参数统一取库，排除不影响其他箱，旧数据不丢失 |
| U04 独立库视图与主面板简化 | 当前箱视图、缺资料入口、定位及排除恢复接入后，移除重复区域 | 既有必要功能均可到达，日常无需另点应用库值 |
| U05 回归与交付验收 | 聚焦自动检查、严格编码构建和原生 CAD 场景及性能对照 | 分别记录自动结果、包检查结果和真实 CAD 未验／已验状态 |

实施时按阶段提交本任务所属变更；推送和合并按用户授权执行。修改 LISP/DCL 后使用 `tools/build_cad2020.py` 生成递增序号的完整交付包，严格核对全部 LISP/DCL 的 GB2312 编码与 ZIP、解压目录内容一致性；生成产物不提交，新增临时路径补精确忽略规则。本次文档落盘不生成新交付包。

## 9. 必要验收场景

| 场景 | 预期结果 |
| --- | --- |
| 空库拾取含两种真实接线设备的箱 | 可发现设备并自动登记图形；补资料后直接完成统计 |
| 同种设备多实例、跨多个回路 | 只登记一种图形，各回路实例数量、归属及汇总正确 |
| 完整条目及同名待补草稿 | 完整项直接复用；草稿补资料，不重复登记和导出 |
| 未接触、不同高程及辅助图块 | 几何不满足时不计入；明确排除辅助项后本箱不统计 |
| 本箱排除后恢复、保存重开 | 同类排除范围及恢复正确；其他箱和共享库启用状态不受影响 |
| 空功率、无效输入、明确 0W、非地面 | 空值不通过生成；原始输入保留；0W 沿用确认规则；未勾选地面即非地面 |
| 修改库资料后返回原箱 | 自动重算，回路、编号、容量和排除选择保持，图形不重复导出 |
| 库修改与已保存系统图 | 刷新不擅自改图；有效保存或更新时应用新值并完整回读 |
| 历史人工值及名称、参数冲突 | 旧数据可读取，集中迁移不静默覆盖共享库或历史记录 |
| 取消、写失败、占用、并发修改 | 无半项成功提示，保留原库与草稿，不混用修订，不遗留临时图纸或改变来源状态 |
| 普通、动态、嵌套及天正来源设备 | 有效名、图形、文字、填充和动态状态正确；源对象及真实连接保持 |
| 同条件性能与无变化更新 | 按场景保存五次证据；已登记路径不重建有效图例；稳定无变化路径保持零写入 |

自动检查只能证明其覆盖的规则和接口结果。跨图纸导出、DCL 显示与操作、真实接线、DWG 保存重开及性能收益必须有原生 AutoCAD 2020 的实际日志和场景证据，才能标记为已验收。
