# 03 加载、使用与验收说明

日期：2026-10-09
状态：v30 出线预览显示所选回路全部已识别导线和设备；自动选型规则未启用，真实 CAD 验收待执行

## 1. AutoCAD 2020 加载

完整解压 `应急照明-030.zip`，APPLOAD 根目录 `START-CAD2020.lsp`，选择本包 `src/load.lsp`，确认命令行显示 v30。必须保留 `src`、`ui`、`config`、`output`、`templates` 的相对目录。主面板要求 029 界面标记，不能把更新 LSP 配合旧版不兼容的 DCL 使用。

v30 修正图面预览只亮显起始导线的问题。点击“在图面查看所选回路导线和设备”，黄色显示已追踪导线路径，青色框显示设备，并缩放到所选范围；Enter 返回保留选择。断口处不补画实体，待核对回路仅显示当前识别范围。v30 沿用兼容的 029 界面标记。专项证据见 `tests/evidence/2026-10-09-circuit-preview.md`。

v29 修正出线确认窗口只列导线编号、看不到设备结果的问题。上方显示每条候选的设备数量，下方显示所选出线连接的设备名称及数量，多选按实例去重。点击“确认出线，进入功率表”继续填写功率；显示 0 个时会提示检查连接。该改动不改变接线判定，不能据此认为原图漏识别已获实测修复。

v26 修复新建系统图记录时 `HANDSEED` 返回 nil 引发的字符串拼接错误。`ELSTAT` 及独立打开主面板的流程均记录诊断，结束时显示日志完整路径；通常在本包 `output/ELTRACE-debug.log`。日志无法写入时，命令行仍报告原始错误、失败阶段及最后上下文。再次报错请保留这些内容；详见 [常见错误速查第 14 节](05_常见错误原因与修复速查.md#14-主面板-stringp-nil-且没有日志v26)。

仓库源码为 UTF-8，交付包全部 LISP/DCL 为严格 GB2312。**AutoCAD 2020 不直接加载仓库源码**。旧 GB2312 包的 `config/*.eld` 可备份后复制到新包；UTF-8 配置不能直接混入。先保存 DWG，识别和输出均使用模型空间，单位固定 mm。

## 2. 首次使用

1. 运行 `ELSTAT`，拾取平面配电箱，再拾取本系统任意一条导线确定图层。无需先运行 `ELTEMPLATE`。首次或箱口候选变化时集中核对实际出线，默认全选，只取消明确的进线、非本箱出线；不要为了消除错误取消真实负载回路。可以图面预览，无须逐条重新拾取。保存后相同候选沿用选择。
2. 统计完成后打开主面板。左侧每页 8 行，通过上一页/下一页切换；点击实际回路，右侧仅显示该回路的设备数量和单个功率。预留行禁用功率、地面编辑。
3. 填写非负整数 W，`0` 为有效功率，空值为缺项。同名图块功率统一重算本箱全部相关回路。非法输入会阻止切换并定位输入框。点击“在图上查看该设备”只定位当前回路内的该类设备，Enter 返回；面板“取消”丢弃未保存草稿；有旧系统图时标记其未更新，保留旧图及原确认值。
4. 根据统计结果，在顶部选择箱体 `0.3kW/0.6kW/1kW`。逐页核对实际回路最后一列“地面”：勾选为地面，未勾选为普通。检查全部页后点击“确认全部页回路类型（未勾选为普通）”。按钮确认所有实际回路，包含其他页，不含预留。手动勾选或取消某一回路也确认该条类型。
5. 新箱体容量和未确认回路显示“待核对”。自动容量选档及地面识别规则尚未配置，本版集中人工确认；不会把初始 0.3kW 或未勾选当成已确认结果。“保存”可保留待核对草稿；存在待核对项或模板不可用时保留旧系统图，不覆盖其最后成功结果。
6. 点击“生成或更新”。已有有效模板直接复用；只有缺失或定义变化才提示设置。此时在当前 DWG 拾取两个真实动态块样本：箱体 `dfgjhdrtyjtfgj4SADFG3`、回路 `fghjftyuk`；可先拾取 TEXT 外观样本，Enter 使用当前样式和有效字高。容量名称忽略空白和单位大小写，`1 kW` 与 `1kW` 自动对应；指定回路模板的“埋地”对应输出类型“地面”。唯一匹配自动完成，保留原始动态值，不再要求输入 `1-1`。
7. 模板设置中取消或按 Esc 会返回原统计面板，保留当前功率、容量和类型选择，可继续修改或保存草稿。成功后进入生成；首次指定箱体插入点，可指定 WCS 旋转角和正等比缩放。在真实插入预览中核对母线覆盖、接线、档位及文字，输入 Yes 才保留；Enter/No 或取消撤销预览。
8. 保存或生成成功后，人工选择随箱体及回路 UID 存入 DWG，同图可复用已验证模板；重复统计无需重新对应状态。新增回路重新标为待核对。`ELTEMPLATE` 保留为主动维护模板命令，不是日常统计前置步骤。程序不会炸开、重定义或绘制替代块。

默认 `ELSTAT` 使用所选导线层及图块整体范围，保留 v24 的悬空端点、共线相向、同高程、双向唯一断口续接规则。逐回路使用现有追踪和完整性校验，不均分整箱功率。未完成、缺功率或超过 172W 的实际回路仍在主表显示，只能保存草稿，不能正式输出。

模板中使用自定义状态名称时，命令行会明确提问并列出编号，例如：

```text
箱体容量“0.3kW”对应下面哪种状态？已分配的状态不再列出。
  1. 小容量
  2. 中容量
  3. 大容量
请输入选项前的数字 1-3（回车取消本次模板设置）：
```

按当前菜单选择，不要固定照抄 `1、2、3`：已分配状态会移除，后续菜单会重新编号。输入超出范围可原地重选。未知状态即使只剩一个也要明确确认；拿不准时回车取消，保留原模板，生成入口会返回统计面板；程序不会按容量大小或排列顺序猜测自定义状态。只有存在多个可用控制选项时，才会显示属性名称和各自可选状态，请选择控制箱体容量或回路类型的那一项。只读、空值和不足三种不同状态的属性不会列入菜单。

## 3. 系统图与更新

有 n 条实际回路时，输出 1 个箱体 INSERT、n+2 个回路 INSERT、n 个独立功率 TEXT。首回路相对箱体 `(6427,-5500)`，向下间距 1200；文字相对各回路 `(10636,-438)`。末两条固定预留，不写 `0W`，不创建功率文字。

- `ELPOWER`：编辑当前结果；新流程打开箱体主面板。
- `ELSTAT`：修改接线或设备后重新统计；先进入统计面板，保存或生成时通过完整校验才更新已绑定系统图。
- `ELGEN`：当前固定流程先回到主面板集中确认，再生成或更新当前箱体的一套受管系统图，不重复插入。
- `ELUPDATE`：保存重开后，选择原受管箱体、回路或文字，恢复 DWG 记录，重新识别来源，固定流程进入主面板集中确认后同步。复制实例和跨图对象不能自动继承关联。
- `ELISSUES`：查看高级识别问题；命令行同时报告系统图未更新及原因。

功率变化保留原文字句柄、位置和样式；地面/容量变化原位切换动态属性。回路增加默认追加在实际回路末尾，预留保持最后两行；种子消失时集中显示旧/新身份，只有明确确认删除旧回路并新增后才更新。不会按 R 编号或最近距离猜测对应关系。

单独移动文字不影响仅功率更新。结构变化发现手工布局时，用户选择按模板预览重排或取消保留现场。整套平移/旋转/正等比缩放必须保持成员关系；只移动箱体会被阻止。缺失文字可补建，缺失箱体/回路块、重复标识、锁层或动态属性失效需先修复。失败时保留最后成功图形并记录 stale 状态；成功事务的一次 UNDO 包含图形和 DWG 主记录。

本期没有常驻监听：只修改平面图而不重算时，旧文字不会实时更新。保存重开后的关联恢复也不表示已重新校验。

## 4. 数据与兼容

主记录位于 DWG 命名对象字典 `EL_FIXED_V1` 的 XRecord，实体附 XData；DWG 保存重开带走关联、模板、选项及功率副本。`output/diagram-*.eld` 仅为诊断导出。共享的 `config/block-powers.eld` 按有效图块名跨图复用；有效库值优先，未完成草稿中的明确空值优先保留。DWG 保存成功但外部文件写入失败时会明确报告，其他图纸暂不复用此次共享功率。

旧 `ELTRACE`、`ELSETUP`、`ELGAPTEST`、`ELPAIRGAP`、`ELPAIRLEADER` 和高级设备角色/功率库继续保留。高级 `ELPOWER` 仍使用按身份保存的旧功率，优先级为本次输入、本图保存、设备库；不会静默覆盖按块名功率库。高级结果也可通过 `ELGEN` 接入固定系统图；高级 `ELUPDATE` 集中复核出线。

旧模板配置仍可读取；固定流程生成时仅对缺失或变化的模板进行适配，也可主动运行 `ELTEMPLATE` 维护。旧记录未保存容量确认来源时会要求重新核对一次容量，不能把历史默认档位当成人工确认。旧版未标记的生成图不自动接管；如需使用本版本，保留旧图作对照并首次生成受管图形。自动地面图块规则目前没有用户名单，仅保留接口及人工是/否优先级，不自动猜测。

## 5. 验收

执行 `python -X utf8 tests/run_fixed_checks.py` 复现聚焦证据，执行 `python -X utf8 tools/build_cad2020.py` 重新构建同序号 030 包。v29 出线显示专项证据见 `tests/evidence/2026-10-09-exit-devices.md`；v28 历史证据见 `tests/evidence/2026-10-09-post-stat-workflow.md` 及对应 JSON；S01—S06 历史证据保留。

真实 AutoCAD 2020 仍须按方案 06 的 S-A01—S-A29 中本次已实现部分检验（自动规则样例待规则确定）：三档箱体和三档回路可见效果、母线覆盖、DCL 实际交互、UCS、保存重开、复制/跨图、锁层/Esc、一次 UNDO。自动检查和 GB2312 校验不能替代真实模板 CAD 验收。
