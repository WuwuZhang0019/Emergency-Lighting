# 应急照明智能设计浏览器体验版
日期：2026-10-24
状态：参赛简化交互版；内核检查与 HTTP 浏览器交互、下载验证已完成

## 打开与提交

双击同目录的 index.html，使用 Edge 或 Chrome 打开。无需安装、登录、联网或启动服务，页面不引用外部字体、脚本与资源。向评审发送这一个 HTML 文件，即可体验全部功能；如果比赛要求压缩包，可以将它压缩后以作品名“应急照明智能设计”命名。

原 AutoCAD 项目版本仍为 **v0.1.84**。本页是独立的网页简化适配，不代表 CAD 项目发布新版本。

## 推荐演示顺序

1. 保持“办公楼层”示例，点击“开始体验 · 识别回路”。
2. 查看 4 条回路、19 个连接设备、63 W 已知总功率；点击回路行查看分色。
3. 将应急照明灯功率从 5 W 改为 8 W，设备总功率实时变为 96 W。
4. 选择 ZE1，点击“试试断开末端导线”：ZE1 最后一个指示灯退出统计，恢复连接后重新加入。
5. 将照明灯功率留空，查看“功率待核对”与已知总功率，未知值不会按 0 W 处理。
6. 恢复功率，点击“生成当前箱系统图”，下载 SVG 矢量图或 CSV 统计清单。
7. 可切换“教学楼层”示例，重新识别；刷新页面恢复初值。

## 实际功能与边界

- 实际计算：由各起始导线进行图连通搜索；导线端点重合或落在另一段导线上时连接，中段单纯交叉不连接；导线接触矩形设备区域时将设备纳入搜索，并按设备 ID 去重。
- 可编辑：设备类型默认整数功率、回路编号、数值提醒阈值及示例末端导线的连接状态。修改后立即重算；已生成的系统图同步更新。
- 待核对：未知功率、空回路、重复或缺失编号、多回路设备或导线归属、超过用户输入阈值，均保留提示。阈值只用于数值演示，不代表设计规范或审查结论。
- 示例来源：两张平面图均为本体验版人工构造的教学数据，未使用实际工程图，不宣称复现某一原图的识别结果。
- 不包含：DWG / DXF 导入、天正对象解释、复杂轮廓与曲线、不同高程、完整 CAD 几何算法、DWG 写入、动态块、原生 Undo。页面不连接本机 AutoCAD。
- 导出范围：SVG 是简化示例系统图，CSV 为当前识别结果；均只供功能体验，不作为施工图。刷新会清空本次编辑。

## 必要开发验证

内核边界与统计检查：在仓库根目录运行：

    node --test web-demo/tests/core.test.cjs

测试直接读取 HTML 中的同一份计算代码，不生成额外交付文件。实际浏览器的点击、离线打开及下载还须按演示顺序验证。

2026-10-24 验证结果：

- 10 项内核检查通过，覆盖两示例结果、断线恢复、交叉与 T 接点、矩形设备接触、未知功率、去重与归属冲突、编号及导出转义。
- 浏览器通过本机 HTTP 打开并实际操作：办公示例 4 回路 / 19 设备 / 63 W；修改照明灯功率为 8 W 得到 96 W；断开 ZE1 末端后为 18 设备 / 95 W；恢复后重新计入。
- 功率留空显示已知 8 W，并在生成图保留“功率待核对”；恢复 5 W 后已生成图同步回到 63 W。教学示例为 3 回路 / 17 设备 / 61 W。
- 实际点击 SVG 和 CSV 下载按钮并取得文件；非法阈值阻止导出并显示纠错信息；操作说明可打开与关闭，浏览器未记录脚本错误。
- 单文件资源已全部内置；当前浏览器验证工具只允许 HTTP/HTTPS，file:// 双击打开入口受工具策略限制未实测。收到文件后可用本机 Edge 或 Chrome 双击确认。
