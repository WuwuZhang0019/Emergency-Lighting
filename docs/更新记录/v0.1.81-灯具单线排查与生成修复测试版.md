新增 `DEVICE_WIRE_MISS_DETAILS`，记录通过粗筛后的细判失败：图块名、设备原生边界、容差、WCS导线和设备几何及截断标志。每轮最多8项，导线最多8条线段、设备最多32条线段，只复用现有快照，不新增CAD/COM读取。结束或报错后立即运行 `ELDIAG` 导出；诊断标记 `2026-10-22-line-arms1`。被预设图层、名称或粗筛排除的对象不在此事件覆盖范围。
