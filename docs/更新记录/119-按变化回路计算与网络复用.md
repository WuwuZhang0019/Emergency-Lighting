# 119 按变化回路计算与网络复用
日期：2026-10-13
状态：S3 已实现，定向适配器验证通过；真实 CAD 用时待验收

- 功率统计按回路实际输入复用。功率变更仅重算使用该设备类型的回路；排除变化重算受影响回路；规则、几何、归属冲突等输入变化自动使对应缓存失效。箱体合计、超限及设备库校验继续汇总执行。模板只影响输出，不使功率统计失效。
- 统计依据包括完整块数据、回路非统计字段、归属冲突、该回路的功率记录及其他配置。缓存只保留最近一次计算集合，命令开始清理；纯计算复用不表示源图已经通过生成前核对。
- 保存网络复用候选，包括源输入字段清单、建网改变的原始端点/角色、配置及轮廓依赖。复用依赖已有源快照加差异字段还原输入，未增加第二份完整源快照。
- 每次提交仍完整采集源图并重新读取候选涉及的设备轮廓。两者、配置、箱体以及操作边界均未变化才省略建网；新增/删除导线或设备、轮廓改变、未知配置改变、无法还原输入或不确定状态回到完整路径。S4 的局部几何追踪尚未实现。
- 旧历史记录无候选时执行一次完整核对；核对成功后，保存/生成将有效候选写入最新快照。源图身份仍采用原完整签名，比较时仅剔除可重新生成的候选元数据；输入/写图边界立即清除本次提交的临时有效依据。
- 功率仍即时写入共享设备库；纯功率变化保留图例缓存，改名、别名或图形资源变化仍刷新，避免功率输入导致图形消失或反复读图例。
- 计数：`statistics-circuits-computed/reused`、`network-proof-reuses/rebuilds`、`preview-power-reuses`、`split-chunks-written/reused`、`split-root-publications`。它们说明工作范围，不能替代真实用时。
- 定向证据：局部与完整统计结果相同；更改 A 类型功率时只重算使用 A 的两条回路；重开候选后完整采集和轮廓复核但建网次数为 0；旧签名首次完整核对后可保存候选；轮廓变化和新增源对象使复用失效；即时设备库发布与别名图例刷新继续可用。
- 本次未引入后台线程。AutoCAD 的读图、写图、DCL 仍走现有同步路径。首次迁移、首份候选生成及几何变化保存可能仍耗时；保留历史块使 DWG 有增长风险，本阶段不自动清理。
- 验收：解压完整 119 包，APPLOAD 包内 START-CAD2020.lsp，在原 DWG 副本中依次加载历史、改功率、保存、重开、生成、Esc、UNDO，再比较输出目录的 ELMONITOR/ELPERF。实际速度与鼠标退出状态以原图实测为准。
