# 天正 HLBH 批量编号使用与 CAD 验收
日期：2026-10-11
状态：逐根两个坐标点及固定偏移已实现，46 项离线检查通过；修订 2026.10.11.3 真实 AutoCAD/天正验收待完成

## 加载与使用

只加载本工具：`APPLOAD` 选择 `output/HLPLBH.lsp`。该文件已严格转换为 GB2312，可供简体中文 Windows AutoCAD 2020 加载。仓库内 `src/batch-number.lsp` 是 UTF-8 源码，不作为 CAD2020 的加载文件。

当前独立文件修订为 `2026.10.11.3`。使用旧版后仍停在天正选线提示时，先按回车或 Esc 结束 HLBH，再重新 APPLOAD 上述文件；命令行应显示此修订号。若旧版提示自动撤销未确认完成，先在原图运行 `HLPLBHRECOVER` 核对恢复，再开始新批次。

1. 在已经加载天正电气的 CAD 中运行 `HLPLBH`。
2. 输入 `ZE1`，或者直接回车采用默认编号。以后回车保留上次成功批次的起始编号。
3. 框选五条需要编号的独立出线段，回车结束选择。
4. 工具自动逐根向 HLBH 提供两个坐标点，不再询问额外的空白点。

工具在当前 UCS 中按导线中点从上到下排序，同高度按从左到右排序。第一点是各自导线的真实曲线中点 `(x,y,z)`；第二点默认是 `(x+500,y+500,z)`，即右移 500、上移 500。两个点发送完并核对原生标注后，才处理下一根。每个选中的导线对象只生成一组标注，编号为 `ZE1` 至 `ZE5`。末尾数字支持连续递增和补零，例如 `4ALE(JZ)-ZE009`、`4ALE(JZ)-ZE010`。

选线步骤严格发送纯坐标点，不向 HLBH 传入实体/点组合列表，也不把两个点合并发送。多段线按实际曲线长度的一半取点，不用端点平均值代替。第一点产生的原生标记会纳入同一组，第二点完成后的全部新增对象一起检查。天正浮动窗口保留原命令行为，无需逐条操作窗口。工具只通过标注对象实际开放的 `TextString` 接口核对和设置编号；窗口中的当前编号即使与本次输入不同，也只有在原生文字接口确实可写且回读一致时才会继续。

本工具不分析回路连通性。请只选独立出线段，避免框入母线、已有标注的引线或同一回路的多段线；这些普通线段与导线可能是同一种 CAD 对象，不能仅凭类型自动区分。文字、图块、闭合多段线和不支持曲线接口的对象会被跳过，命令行报告跳过数量。

## 偏移设置和撤销

默认偏移为当前 UCS 的 X 方向 `+500`、Y 方向 `+500`，沿用毫米图纸。文字点随每根导线的中点平移，文字间距跟随导线实际位置，不强制整组共列对齐，也不按字高改动固定偏移。

需要调整时可单独运行 `HLPLBHSET`，依次输入水平和竖向偏移；右、上为正，左、下为负，回车保留当前值。两个偏移不能同时为 `0`。正常编号流程只需输入编号、框选导线，不再重复询问放置点或单位。

成功批次纳入一个撤销分组，单次 `UNDO` 应撤销整批。失败和中途取消时先按 HLBH 的“退出”提示提供空输入，最多两次以取消文字点并退出选线，再尝试整批撤销，并核对新增实体和原导线快照。仍活动时禁止发送 UNDO，保留待恢复状态。期间不要继续绘图，在结束活动命令后于原图运行 `HLPLBHRECOVER`。工具不在其他图纸中执行恢复，也不自动撤销失败后检测到的其他绘图改动。若提示撤销分组已改变，需先手动撤销本批次，再运行恢复命令核对。

## 兼容性失败和日志

日志为 CAD 临时目录中的 `HLPLBH-debug.log`，具体绝对路径会在命令行打印。日志包括工具修订号、偏移、排序计划、每条导线的连接点和文字点、`INPUT_POINT`/`INPUT_RETURN` 的逐点记录、`CMDACTIVE`、`CMDNAMES`、前后 `LASTPROMPT` 文本、新增实体类型、编号接口及回读结果、`ROW_COMPLETE` 以及原生命令退出和取消状态。

用户实测说明 `LASTPROMPT` 有时仍是 UNDO 的历史输出。因此，工具不会仅因该文本没有出现“导线”就中断；没有刷新或只追加输入的提示作为诊断保留，以活动状态、两步输入和实际生成结果继续核对。出现新且不兼容的提示时仍停止。`COMPLETE` 只能记录完整的非空编号列表，空返回或不足所选数量的结果均作为失败处理。

以下情况会停止，不会自动替换成普通文字与线条：

- 天正未加载，或 `HLBH` 的实际提示与截图中的选导线/文字落点流程不同。
- 天正版本不接受程序传入的坐标点，或无法根据该中点选中导线。
- 新标注没有唯一可读取的 `TextString`、编号需要修改但属性不可写，或文字含有不能安全保留的内嵌格式。
- 写入编号后回读不一致、命令退出后编号变化，或原生文字对象类型发生变化。
- 选中导线连接点重合、编号序列超出整数范围，或导线与文字点不在当前 UCS 的同一平面。

这些失败说明当前天正版本需要适配。自动检查不证明天正私有对象开放了 `TextString`；遇到失败，请保留完整命令行及日志，尤其是 `BEGIN`、`PROMPT`、`CREATED`、`TEXT_INTERFACE_UNAVAILABLE`、`FAILED`、`CANCEL_AFTER` 和 `ROLLBACK` 记录。

## 真实 CAD 验收清单

已收到用户 AutoCAD 2020 两轮失败截图和日志：初版在提示判断中断，修订 `2026.10.11.2` 在第一点报“点无效。”。当前执行环境未运行真实 AutoCAD/天正，修订 `2026.10.11.3` 以下项目尚未验收：

1. 在副本图中用 `ZE1` 框选五条独立出线，回车结束选择后直接自动执行，不再点击空白处。核对每条线的第一点是中点、第二点是右移 500 上移 500；该条完整放置后再到下一根，生成 `ZE1` 至 `ZE5`，结束后正常退出 HLBH。
2. 天正浮动窗口设置成其他编号，例如 `wl12`，本工具输入 `ZE1`；核对程序能否在原生标注上改号并读回。接口不支持时应报告原因并撤销本批次，不得显示成功。
3. 双击或通过天正编辑新标注，核对原生对象、文字样式、斜线、引线和导线关联是否保留；保存 DWG、关闭并重开后再次核对编号和关联。
4. 在副本图中验证旋转 UCS、正负偏移、非直线多段线、文字/图块混选和锁层；核对跳过数量、排序、真实曲线中点及固定偏移。
5. 正常完成后单次 `UNDO` 应删除整批标注；中途按 Esc 应撤销本批次并恢复捕捉、正交、动态输入等原设置。没有天正或提示不兼容时，不应撤销之前的绘图操作。

## 自动检查与单文件再生成

46 项检查覆盖实际 LISP 函数的编号规则、排序和 UCS 转换、两次用户输入流程、两个纯坐标逐条传入、第一点已有标记、非直线多段线中点、第二点失败停止下一根、文字回读、原生对象类型保留、取消/失败的撤销以及异常恢复。CAD 和天正接口使用适配器，不能代替上述实测。

```powershell
python -X utf8 -m unittest discover -s tests -p test_batch_number.py -v
python -X utf8 tools/export_batch_number.py
```

第二条命令仅生成 `output/HLPLBH.lsp`，不生成压缩包、不修改应急照明加载入口，也不构建其他模块。
