# 系统图块库

日期：2026-10-15
状态：作者原始 DWG 已纳入，自动导入已实现；真实 AutoCAD 验收待执行

将作者提供的 `系统图块库.dwg` 放在本目录。主面板右侧设备库路径下方的“打开所在文件夹”会打开本目录，文件存在时选中该 DWG；未提供文件时明确提示缺失。

图纸须保留以下完整动态块和配套文字样式：

| 项目 | 名称或要求 |
| --- | --- |
| 配电箱动态块 | `ZYF_Tool_应急照明配电箱图块`；容量 0.3kW、0.6kW、1kW |
| 配电回路动态块 | `ZYF_Tool_应急照明配电回路图块`；普通、地面、预留状态 |
| 文字样式 | `_TEL_DIM`、`ICDA-STYLE1` |
| 单位 | mm |

生成前自动检查上述动态块和文字样式，只从此 DWG 深复制当前图纸缺少的定义；完成后以当前图纸块表和样式表读回确认，再沿原流程检查动态属性并出图。库图纸在 ObjectDBX 后台打开，不切换活动图纸、不保存源 DWG、不将整个库作为外层块插入。已有同名定义保留，动态校验不通过时停止；既有系统图实体保留。

缺少原始文件、库内名称不匹配、ObjectDBX 创建或深复制失败时显示具体原因，当前统计、功率和设备编辑保留，允许修复后重试。运行单独 CCKK 命令时需可定位完整交付包目录或支持路径中的图块库。

构建脚本按原始字节复制此 DWG，并将其包含在独立启动文件的内嵌资源中；仅加载启动文件时，本地运行目录也能提供同一份图块图纸。缺少原始文件或 DWG 版本不受 AutoCAD 2020 支持时，构建停止，避免交付不完整的图块库。
