## 加载与使用

AutoCAD 2020 完整解压 [应急照明-038.zip](output/应急照明-038.zip)，APPLOAD `START-CAD2020.lsp`，选择同包 `src/load.lsp`，确认 v38。启动入口已合并全部模块，选择 src/load.lsp 仅定位目录，不会逐个加载模块。包内全部 LISP/DCL 为严格 GB2312，不直接加载仓库 UTF-8 源码；源代码供 Windows AutoCAD 2021+、LISPSYS=1/2 环境使用。单位固定 mm。

执行 `ELSTAT`，拾取平面配电箱（有歧义时补选本系统导线），核对回路、功率、容量和地面选择后保存或生成。系统图箱体 `dfgjhdrtyjtfgj4SADFG3` 和回路 `fghjftyuk` 自动从本图读取，缺失才提示拷入；不再拾取模板块和文字。文字固定使用 `_TEL_DIM`、高350、宽度因子0.7、`TEL_TEXT` 图层。n 条实际回路输出 n+2 条，末两条预留不创建功率文字。首次插入预览 Enter/Yes 保留，No 撤销。

成功重新统计或保存有效功率/档位后更新原文字和块；`ELGEN` 重复执行进入更新。保存重开用 `ELUPDATE` 选择原受管系统图，重新识别来源并同步。缺功率、识别不完整、超过 172W 或关联冲突时保留上次图形并明确报告未更新。没有常驻监听，平面图编辑后需要重新统计。

操作、数据优先级、手工布局、锁层及撤销边界见 [03 加载使用与验收说明](docs/03_加载使用与验收说明.md)。新功率按有效块名记忆于 `config/block-powers.eld`；DWG 内同时保存关联及功率副本，`.eld` 为辅助导出。旧 `ELTRACE` 及按身份功率流程继续保留，未静默合并两套功率库。
