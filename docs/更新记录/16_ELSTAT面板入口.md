# ELSTAT 面板入口
日期：2026-10-10
状态：已实现，自动检查通过；真实 AutoCAD 2020 验收待执行

输入 `ELSTAT` 后先打开“回路与图块设置”面板，点击左上角“拾取配电箱”再选择平面图配电箱及同系统导线。未拾取时，保存、生成及图块编辑不可用；取消可直接关闭。

识别后的主面板也保留“拾取配电箱”按钮。重新拾取前请先保存需要保留的当前草稿；该按钮不自动保存或生成系统图。

交付版本：应急照明-069。解压完整压缩包，APPLOAD 加载 `START-CAD2020.lsp`，再输入 `ELSTAT`。

实测需确认：首次打开不出现拾取提示、按钮位于左上角、点击后可选择配电箱、识别后回到主面板、重新拾取和取消正常。
