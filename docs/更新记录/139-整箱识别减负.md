# 139 整箱识别减负

日期：2026-10-15
状态：实现与 90 项定向检查完成；原图 AutoCAD 2020 耗时待实测

## 依据与目标

用户希望整箱识别尽量控制在 1 秒内。现有实测依据是 `output (6).zip` 中的 137 版日志 `ELMONITOR-20261014.231247-ELSTAT.md`：

| 阶段 | 程序耗时 |
| --- | ---: |
| 整箱识别 `RECOGNIZE_FIXED_RUN` | 6.797 秒 |
| 候选采集 `SIMPLE_COLLECT` | 3.313 秒 |
| 其中：候选实体读取 | 2.234 秒 |
| 其中：候选过滤 | 1.063 秒 |
| 网络准备 `SIMPLE_NETWORK` | 2.141 秒 |
| 回路划分 `SPLIT_NETWORK` | 1.109 秒 |
| 其中：两次编号范围定位 | 0.704 秒 |

父阶段包含子阶段，不能重复相加。该日志两次采集合计扫描 5,794 个候选实体，读取 1,546 份导线记录、1,766 次图块包围盒。识别结果中的来源导线为 773 条，候选图块为 556 个。

本版减少首次识别本身的重复工作，保留全部来源候选和真实接触判定。尚无本版原图 CAD 实测，不能认定已从 6.797 秒降至 1 秒。

## 修改

- 同一轮采集中，实体普通字段与受管输出标记通过一次选择性 `entget` 读取；导线、轻量多段线及诊断上下文复用这份刚读到的 DXF，减少重复读取。`linenum` 等其他应用的 XData 仍由原来的专用路径读取。
- 名称判断共用一次 `EffectiveName` 查询，并在本轮采集内按实际块定义名复用结果。匿名动态块按各自定义区分；重新采集时重新查询。每个实例的包围盒和需要的真实几何仍分别读取。
- 空间树预先保存排序用坐标，比较时直接访问；单节点不再排序。轴顺序、并列键、树布局及查询顺序保持一致。
- 稳定来源数据保留原始类型和值，普通原子值直接保留，减少逐值递归；实体名仍转为真实句柄。
- 编号范围中的首个设备定位共用线段长度、方向和路径切片，多设备共享同一组 32 次二分。保留原有接触精度、孔洞/线宽判定、反向导线和并列设备选择顺序。

名称复用的 API 依据：Autodesk 将 [EffectiveName](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-ActiveX-Reference/files/GUID-A87607A4-D7F9-40B3-94B5-B9D88011DEB5.htm) 定义为原始块名，并说明动态块可能通过另一匿名块名绘制；这项复用不用于代替实例几何检查。[entget](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-AutoLISP-Reference/files/GUID-12540DAE-C84B-4BDB-AEEC-DDFE5BE3C42A.htm) 可附带指定应用的扩展数据。
