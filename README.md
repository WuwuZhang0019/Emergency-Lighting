# 应急照明回路统计与系统图生成

日期：2026-10-11
状态：持续开发；101 包及对应自动检查已通过，真实 AutoCAD 2020 验收待执行

基于 **AutoLISP + DCL** 的 AutoCAD 辅助设计工具，用于应急照明平面图的回路识别、设备数量与功率统计、设备库管理，以及系统图生成和关联更新。

主要流程：**拾取配电箱 → 识别回路 → 核对设备和参数 → 保存 → 生成或更新系统图**。设计人员可以预览完整回路并核对结果；平面修改后需要主动重新统计或更新。

## 核心功能

| 功能 | 当前行为 |
| --- | --- |
| 配电箱回路识别 | 默认只拾取配电箱，自动推断导线图层与实际线型；有歧义时补选本系统导线。首次或箱口候选变化时集中核对进/出线，之后沿用保存选择 |
| 数量与功率统计 | 按回路查看设备及汇总功率；数量只读，同名设备功率统一重算，可核对容量和地面选择 |
| 回路预览 | 显示选中回路的完整路径和设备，帮助核对遗漏及错误归属 |
| 独立设备库 | 管理图形、图块名、设备名、功率和地面属性，支持新增、查找、修改、删除及恢复，材料表复用标准图例 |
| 平面回路编号 | 读取天正导线 `linenum`，统计面板与系统图使用同一编号；未标号补默认号并避开已占号 |
| 系统图生成与更新 | 使用配套固定图块生成系统图，保存来源关联和参数，后续更新原受管系统图 |
| 保存记录 | 在当前 DWG 保存配电箱记录，首次打开 `ELSTAT` 即可查看已有记录并打开 |

识别以实际几何连接为依据，不能将仅仅靠近但未接触的设备直接纳入。连接、编号或参数存在歧义时，应按提示核对。

## 快速开始

### 1. 环境与加载

- 主要交付目标：Windows AutoCAD 2020；图纸单位固定 **mm**。
- 完整解压 [应急照明-101.zip](output/应急照明-101.zip)，保留包内全部目录。ZIP 是本地构建产物，不纳入 Git；仅克隆仓库时需自行构建或取得交付包。
- 在 CAD 中运行 `APPLOAD`，只加载本包的 **`START-CAD2020.lsp`**，确认命令行显示 **CAD2020 v101**。
- 包内全部 `.lsp` / `.dcl` 使用严格 GB2312。**不要在 AutoCAD 2020 中直接加载仓库 UTF-8 源文件**，也不要混用不同版本的入口和模块。
- 源码面向 Windows AutoCAD 2021+、`LISPSYS=1/2` 环境；具体 CAD 与天正对象表现仍需实测。
- 设备库图形登记涉及多图纸操作，需要 `SDI=0`。

### 2. 准备设备及编号

运行 `ELDEVLIB`，登记设备图形、有效图块名、设备名、整数功率（W）及是否地面。资料完整后保存为可识别设备；缺资料可保留为停用草稿。明确的 0W 需要确认，不能将空功率默认为 0W。

如果需要沿用平面编号，先手工使用天正 `HLBH` 标号，再提取配电箱。程序读取配电箱至各支路首个设备之间源导线的 `linenum`；未标号回路按面板顺序补默认号并避开已占号。重号、多个候选号或读取异常时，修正平面后重新提取。

### 3. 统计与核对

1. 运行 `ELSTAT`。新空图显示“本图暂无保存记录”，通过绿色拾取按钮开始；已有记录可直接打开。
2. 拾取配电箱；导线条件有歧义时补选本系统导线，并按提示核对进/出线。
3. 选择回路，查看右侧设备表，预览完整回路路径和设备，核对归属及数量。
4. 核对功率、容量、地面选择及回路编号。未登记设备应补登记或明确填写本箱参数；数量不符时检查图纸和识别结果。
5. 保存记录，或点击“生成或更新”。操作完成后仍需保存 DWG。

### 4. 生成系统图

箱体块 `dfgjhdrtyjtfgj4SADFG3` 和回路块 `fghjftyuk` 优先从当前图纸读取，缺失时提示拷入配套块，无需另外拾取模板块和文字。

- `n` 条实际回路输出 `n+2` 条，末两条为预留回路，不创建功率文字。
- 文字使用 `_TEL_DIM`，高度 350、宽度因子 0.7，图层为 `TEL_TEXT`。
- 首次插入提供预览：`Enter/Yes` 保留，`No` 撤销。
- 缺功率、识别不完整、编号或关联冲突、超过当前程序 172W 限制时，保留上次图形并明确报告未更新。172W 是当前程序规则，不代表通用规范限值。

### 5. 后续修改与更新

平面设备、导线或编号改变后，重新统计并核对。成功重新统计或保存有效功率/档位后，按已有流程更新原文字和块；重复运行 `ELGEN` 进入更新。保存重开后，可运行 `ELUPDATE` 选择原受管系统图，重新识别来源并同步。

程序没有常驻监听，编辑平面不会立即自动更新系统图。手工布局、锁层、撤销及数据优先级详见 [加载、使用与验收说明](docs/03_加载使用与验收说明.md)。

## 设备库与数据保存

设备库默认位于运行 CAD 的用户目录：

```text
%LOCALAPPDATA%/Emergency-Lighting/device-library/
```

实际路径显示在设备库窗口中，可更改库目录。备份或迁移时复制完整目录，包括 `catalog.eld`、`assets` 和 `history`；只复制索引不能带走图形与图例。

| 数据 | 管理方式 |
| --- | --- |
| 共享设备库默认值 | 按有效图块名及登记别名匹配；仅在管理器明确保存时修改 |
| 本箱人工值 | 随当前配电箱记录保存，不隐式回写共享库；普通默认值刷新保留人工覆盖 |
| DWG 记录 | 保存来源关联与参数快照；保存成功需经过回读验证，关闭前仍需保存 DWG |
| 辅助资料 | `.eld` 用于辅助导出；旧图块功率资料可从设备库导入，补齐图形等资料后启用 |

“应用设备库默认值”会明确重置已匹配设备的人工功率和地面覆盖，使用前核对当前值。其他窗口修改库后，当前面板会先刷新默认值并停留供核对，避免提交时混用不同库版本。

### 设备库占用时

101 版提供占用恢复窗口及本图草稿保存路径：

1. 设备库暂不可用时，可先“保存”当前输入为本图待完善草稿，再保存 DWG；该路径不更新系统图。
2. 点击“独立设备库”进入恢复窗口，先结束其他 CAD 对同一库的写入，再勾选确认并执行“检查并恢复占用”。
3. 恢复会检查索引并归档占用标记，保留原内容；不会自动判断所有 CAD 是否仍在写入，也不会自动补齐功率资料。
4. 提示索引损坏或存在未完成发布时，保留整个库目录和日志，不直接删除索引、历史或暂存文件。

详细步骤及现场验收见 [101 占用恢复与草稿保存](docs/更新记录/2026-10-11-设备库占用恢复与本图草稿保存-101.md)、[设备库 CAD 验证与使用说明](docs/14_独立设备库CAD验证与使用说明.md)。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `APPLOAD` | 加载交付包 `START-CAD2020.lsp` |
| `ELSTAT` | 配电箱统计主面板、回路核对及保存记录 |
| `ELDEVLIB` | 独立设备库管理 |
| `ELGEN` | 生成系统图，已有受管系统图进入更新 |
| `ELUPDATE` | 选择原受管系统图，重新识别来源并同步 |
| `ELDIAG` | 按需导出诊断资料，命令行显示路径 |

旧 `ELTRACE` 按身份功率流程继续兼容；日常固定系统图操作以 `ELSTAT` 流程为主。

## 开发检查与构建

在仓库根目录使用 Python 执行。只修改文档时检查内容及链接；修改 LISP/DCL 后必须重新构建并执行对应必要检查。

```powershell
# 固定系统图聚焦检查
python -X utf8 tests/run_fixed_checks.py

# 设备库及关联工作流联合检查，生成当前版本证据
python -X utf8 tests/run_device_library_checks.py

# 严格转换 GB2312，生成交付目录和 ZIP
python -X utf8 tools/build_cad2020.py

# 核对回归证据、源码、加载入口及交付包一致性
python -X utf8 tests/check_device_library_package.py
```

生成的压缩包、交付目录及临时验证目录不提交；提交源码、测试、文档及构建脚本。新增生成路径应配置精确 `.gitignore` 规则并验证。
