# v0.1.57 加载时自动升级默认功率

日期：2026-10-16
状态：源码及设备库定向检查通过，真实 AutoCAD 2020 验收待执行，本次不打包

此前，内置索引已经包含用户确认的默认功率，但加载程序只向本机用户库补缺少的设备和图形，已有的空功率记录继续保留，因而升级用户需要手动导入才能测试新默认值。本版在加载时自动升级已知旧记录，直接让统计使用已确认的默认功率，无需选择文件、导入或切换库目录。

自带 49 项设备索引与图形、图例保持原字节。46 个未删除灯具使用默认功率并启用名称匹配：35 项 1W、11 项 5W。配电箱和两条已删除记录保持空功率；两项漏填灯具仍按此前确认补为 1W。

升级以两份原始索引为依据：旧内置空功率库，以及用户已确认的导出库。条目修订号、名称、别名、功率、地面、启用和状态等业务字段必须一致；作者导出档还要求相同库身份。升级仅修改功率、0W 确认和可匹配状态，保留个人后续修改、停用、删除及当前未保存输入。已有图形不重新复制。成功后递增修订号，后续加载不再重复写入；升级资料按程序目录和包标识缓存，避免重复解析。

沿用原有写锁、旧索引比较、历史备份、暂存回读和原子发布流程。定向检查覆盖新用户初始化、旧空功率库、作者保存档、图块主名及别名匹配、后续个人修改与停用、0W、地面、删除、未保存输入、重复加载、锁冲突及写入失败。检查使用有限 AutoLISP 适配器与真实临时文件，结果及原始资料摘要见 `tests/evidence/2026-10-16-v0.1.57-default-power-upgrade.json`；原生 CAD 的加载、统计结果、保存重开仍待实测。

版本为 `v0.1.57`，内部兼容标识 156。本次不构建交付包，v0.1.56 历史包不变。后续测试需使用包含本次修改的完整 GB2312 交付包，不直接加载仓库中的 UTF-8 LISP/DCL 源文件。
