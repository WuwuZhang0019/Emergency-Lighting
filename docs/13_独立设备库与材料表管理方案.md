日期：2026-10-12

设备拾取改为设备库里的独立多选入口。选择完成后逐种导出实际设备图块、生成图例并直接写入设备库，不再要求先新增和再次保存图形；已有有效图形复用。新增条目未填功率时保持空白并保存为草稿，不推断功率或地面属性。原有未保存编辑输入保留，补齐资料后明确保存。

图形有效的库草稿可提供统计识别名称和标准图例；只有启用且资料完整的正式条目提供库默认功率和地面属性。未登记的旧名单设备可在多图纸模式下通过本次临时 DWG 生成图例，避免隐藏来源图对象或写入锁层。临时文件只供面板使用，不自动发布成库资料。

生成校验按设备种类合并缺功率提示，保留完整日志及连接等其他问题。下面的旧实施流程以本节的独立拾取流程为准。

## 1. 目标、范围与当前依据

建立独立于具体 DWG 和插件交付版本的本地设备库，保存图块图形、图块名、设备名、单个功率和是否地面。提供增删改查，以及从 CAD 拾取图块登记的入口。日常识别根据有效图块名精确匹配库中设备，自动带入参数；材料表使用库内已生成的标准图例，减少重新截取图例和人工填写。

本方案最初按“先写方案、不改代码”形成；随后用户授权新建分支及工作树，按步骤实施并打包。源图采集、建网和重复复扫继续由会话「🌟优化耗时」独立执行。设备库接入现有识别结果，保留其源图扫描接口。

用户随后授权合并到 `main` 并清理原分支。整合基线为 `main` 的 `9f09818` 与设备库的 `028fb4a`，保留已合入的平面回路编号和空图面板修复；新包为 098。整合及清理记录见 [098 合并记录](更新记录/2026-10-11-设备库合入main-098.md)。

## 2. 设备资料与名称规则

### 2.1 用户可管理的五项资料

| 字段 | 含义与约束 |
| --- | --- |
| 图块图形 | 从 CAD 中登记的实际图块导出为独立 DWG 资产，保留块结构及依赖；另外生成标准 SLD 图例。SLD 是显示缓存，不能代替可重新生成图例的原始图形 |
| 图块名 | 保存原始有效名称，以大小写统一后的完整名称作为匹配键；禁止空名称和重复绑定 |
| 设备名 | 材料表显示的中文设备名称，可搜索和修改；修改设备名不改变图块匹配键 |
| 功率值 | 单个设备的非负整数瓦，与现有统计规则一致；空值表示未完成登记，不能等同于 0W；登记 0W 时明确标记用途已确认 |
| 是否地面 | 明确的布尔值；正式发布的设备项必须已选择，未填写不能自动当作“否” |

内部另保存稳定 `device-id`、库身份及版本、条目修订号、启用状态、资产相对路径和校验值。内部编号不因改设备名、改块名或删除而重新分配；资产路径使用内部编号，避免中文名称、斜杠和重名影响文件操作。原始名称和设备名完整保留，不截短或有损转换。

### 2.2 按名称精确匹配

- 普通块取得块名，动态块使用 `EffectiveName`；不把动态块的 `*U…` 匿名名称作为稳定设备名称。[AutoCAD 2020 官方说明](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-ActiveX-Reference/files/GUID-A87607A4-D7F9-40B3-94B5-B9D88011DEB5.htm)
- 主键采用完整有效名称的大小写统一形式；不使用最近距离、图形相似度、名称子串或去除编号后的模糊匹配。
- 第一版约定一个有效块名对应一种固定设备参数。如果同一动态块的不同状态具有不同功率或地面属性，必须使用不同设备块名，或暂列为待登记；第一版不靠同名猜测状态。只有不改变这两个参数的状态变化可以共用一项。
- 可登记明确的别名，供跨图纸不同名称引用同一设备项；每个别名也必须完整精确匹配，且与所有启用项的主名称和别名共同检查唯一性。改名时保留旧名为别名的选项默认开启，便于旧图继续匹配。
- 名称只决定设备资料。设备实际是否与导线连接、属于哪个箱体和回路，仍读取当前 DWG 的实际实体、位置、旋转、比例和连接几何；图库图形不能直接代替源图轮廓。
- 标准图例表示登记的设备图形，不宣称是任意动态实例当前状态的实时截图；登记状态改变时更新图形与图例。不得为了使平面实例与图库一致而炸开、重定义或替换用户原对象。

## 3. 独立存储与资产组织

### 3.1 第一版存储决定

第一版采用本地文件形式的逻辑设备数据库：一个版本化 ELD 索引，加独立 DWG 和 SLD 资产。通过设备库读写接口实现查询和增删改查，适配当前 AutoLISP/DCL 技术栈；不把元数据接口散落到识别和面板中。

默认位置为 `%LOCALAPPDATA%/Emergency-Lighting/device-library/`，与 `runtime-094` 等交付目录分离。库路径支持一次选择已有目录，并保存到当前用户配置；以后自动恢复。移交另一台机器时复制或导出整个库目录，不能只复制索引文件。首版支持本地单机，网络共享和多人实时协作不作为本次验收要求。

已实现的用户库布局：

```text
device-library/
  catalog.eld                         # 已发布索引，EL_DEVICE_LIBRARY_V1
  assets/<device-id>/<revision>/
    block.dwg                         # 原始标准图块图形
    legend.sld                        # 标准图例
  history/<library-revision>.eld       # 可恢复的历史索引
  history/legacy/<operation-id>/       # 旧资料完整备份
  .staging/<operation-id>/             # 当前操作临时资产与候选索引
```

索引至少包含 `schema`、`library-id`、`revision`、`devices`。各设备项包含上述五项资料及内部字段。新索引使用独立 schema，绝不覆盖旧 `config/device-library.eld` 的版本 2 数据。

库索引约定 UTF-8，实施专用的显式编码读写器；不得直接依赖 AutoCAD 2020 `open/read-line` 的默认代码页读写 UTF-8，也不能为了显示中文修改用户 CAD 的系统编码设置。实现检查覆盖中文、引号、反斜杠和空格，读写后完整相等；转码失败保留原文件并报告具体字符，不忽略或替换。源码和文档 UTF-8，交付 LISP/DCL 仍由构建脚本严格转换为 GB2312。

索引仅作为数据解析，执行完整 schema、类型、引用和路径校验，不作为 LISP 代码加载或执行。库身份、修订号及实际发布内容共同参与一致性核验；不能仅凭文件时间和长度判断库未变化。

### 3.2 发布、并发与恢复

新增或改图形先写入本操作的临时目录，检查 DWG、SLD 和字段后生成候选索引；先发布不可变资产，再替换已校验的索引。发布前再次检查当前库修订，并采用独占写锁防止两个 CAD 窗口互相覆盖。读者只读取已发布索引，不读取半写入的资产。

失败时当前已发布索引和资产保持有效，只清理由本操作创建的临时文件；不删除旧资产。中文路径、只读目录、磁盘写入失败、索引损坏、锁占用均给出可重试原因，并保留尚未保存的编辑值。不得把写入失败显示成成功。

正常删除将条目标为已删除并取消新匹配，保留历史修订和资产，可恢复；不物理删除旧 DWG 已引用的资料。永久清理不属于第一版正常删除。历史索引不可变，用户库和实际登记图形不提交到项目 Git，也不由构建脚本、升级包或默认模板覆盖。

## 4. 增删改查与 CAD 使用流程

管理命令 `ELDEVLIB` 已实现，采用一个中文窗口：搜索框、设备列表、标准图例，以及名称、功率、地面属性编辑区。提供新增、拾取图形、保存、删除、恢复、导入旧资料和修复图例；正常编辑使用明确的保存按钮。

| 操作 | 产品行为 | 完成条件 |
| --- | --- | --- |
| 查 | 按块名、别名或设备名搜索；查看图例和全部五项资料，可切换显示已删除项 | 查询只读，不触发源图隔离、重生成或写入 |
| 增 | 从 CAD 拾取一个图块，自动读取有效名称、导出图形并生成图例；填写设备名、功率及地面属性 | 名称唯一、资产完整、字段有效后发布；待填写状态可留在编辑窗口，不能假报已入库 |
| 改 | 编辑设备名、功率、地面属性、块名或别名；仅更换图形时重新拾取和生成图例 | 发布新修订，历史修订保留；改文字或功率不重复生成图例 |
| 删 | 从新匹配中移除该项，保留历史数据 | 删除后可恢复；引用该项的旧系统图不被删除或自动改写 |
| 恢复 | 恢复已删除项，重新检查名称冲突及资产完整性 | 与当前启用项冲突时说明具体名称，不抢占别人的名称 |

管理窗口发起 CAD 拾取时保存编辑草稿，临时退出或隐藏窗口，拾取后回到同一项；Esc 返回编辑，不发布不完整资料。首次不支持的外参或无法导出的原生对象，明确指出原因，不炸开转成普通块凑齐资料。天正来源块及嵌套依赖的完整导出必须真实 CAD 检查，不能只凭 DWG 文件存在认定成功。

日常统计面板沿用材料表位置，展示“标准图例、设备名、数量、单个功率、是否地面”。选中行仍能高亮本回路实际实例。增加进入设备库和登记未收录项的入口；来回切换保留已输入功率、当前回路和草稿。

材料行按设备 ID 和实际采用的功率、地面值分组，不能仅凭相同中文设备名把不同参数混在一行。别名指向同一项且参数相同可合并；数量按实体身份去重，跨回路或补充平面中的同一设备不重复计数。

## 5. 接入识别、功率与地面属性

### 5.1 一个顶层命令使用一个已发布库快照

识别开始时读库一次，完整校验后建立主名称及别名的内存索引。每个实例取得有效名后从索引查询，不逐个打开库文件。命令内部传递相同库快照，记录匹配来源和条目修订，不反复加载。

首版在既有追踪结果中用库内启用、资料完整的条目分类已知设备；保留实际连接设备、来源配电箱、辅助对象及阻挡和歧义检查。候选采集与建网继续由扫描任务负责，与导线接触或阻挡断口的未知图块仍参与保守检查。

未知设备显示“未登记：<有效图块名>”，列出实际实例供拾取登记。未知设备不能静默剔除后显示功率齐全，也不能默认按 0W 或非地面设备正式生成。可以沿用当前明确的本箱排除操作排除非设备项，保留排除记录；名称冲突、库损坏和缺失资料不得通过自动猜测解决。

### 5.2 默认值和人工值的优先顺序

功率、设备名称和地面属性均保存取值来源。采用以下顺序：

1. 当前窗口已明确输入或选择的值。
2. 当前图纸、箱体或受管记录中已有的明确人工值，包括已记住的功率和地面选择。
3. 本命令设备库快照中的默认值。
4. 未登记或缺项：等待登记或明确处理，不推定有效参数。

旧记录无法区分“库默认”与“人工填写”的值，迁移时按已有明确值保留，不能追溯猜测来源。库管理员修改参数后，不自动改写所有旧 DWG；重新统计或更新时，只有原来源标记为库默认的值才跟随新库修订。本次生成按用户已看到的参数保存。

管理窗口修改库后返回统计面板，重新匹配受影响项目，提示库版本变化并刷新默认值，保留手工输入；不自动生成。生成／更新提交前核验实际已发布索引，若库在其他窗口变化，先返回当前面板完成重新匹配，避免混用两版参数，不新增独立 Yes 确认。

### 5.3 设备地面属性与回路地面状态

库字段表示单个设备是否地面，不能直接当作整个回路的唯一人工结论。第一版沿用现有建议规则：回路内至少有一个已确认的地面设备，回路默认建议为地面；全部已确认设备均为非地面，默认建议普通；存在未知或未确认设备时不自动宣称地面状态完整。

用户明确选择回路“普通”或“地面”均优先于库建议，不能只保留“是”而覆盖人工“否”。建议来源保存库版本和实际命中的设备身份，便于后续核验。

### 5.4 DWG 保存边界

当前 DWG 保存实际采用的设备 ID、条目修订、匹配块名、设备名、功率、地面值及取值来源，作为当次统计快照；继续保存实际实例与回路、系统图的关联。图形 DWG、SLD 和完整设备库不重复嵌入主记录。

关闭重开后，即使库移动、删除条目或暂时无法访问，已保存系统图及已有明确参数仍能读取和显示；后续新增设备、重新匹配或刷新库默认时才提示需修复库。旧图参数不能因加载失败变成 0W，已有系统图不能因库项删除被自动清除。

## 6. 图例生成、复用与失效规则

首次登记或更换图形时，从只读源样本导出标准图块，再在独立临时图纸中生成 SLD；保留线型、文字、填充和登记的动态状态。图例生成不能在日常材料表中逐行隐藏整张源图或切换用户视图。临时图纸、视图和显示状态在成功、Esc 和错误出口都必须恢复。

已登记项的查询和统计面板直接读取已有 SLD。复用键为库身份、设备 ID、图形资产修订与图例校验值；修改设备名、功率、地面值不重截取。读取时校验 SLD 文件头、实际尺寸及内容校验值；图例读取上限 8 MiB，不长期缓存图例字节，面板关闭释放图例路径缓存。

图例缺失或损坏时，保留设备资料并显示“图例待修复”，允许从库内有效 DWG 显式重新生成；不在识别热路径里逐个自动截图。原始图形资产缺失时也不删除元数据，管理窗口提示恢复资产；新登记或改图形的正式发布必须有完整图形和图例。

显示库中预生成图例属于本方案；从库持久复用连接轮廓、减少源图复扫属于扫描优化任务。后者必须验证源图实际定义与动态状态等条件，不能仅凭块名复用任意几何。

## 7. 旧数据迁移及升级

管理器提供“导入旧图块功率 / 设备资料”，默认定位当前插件的 `config`，也可选择旧交付目录的 `block-powers.eld` 或 `device-library.eld`；发现同目录两种资料时一起校验、备份和列出候选。原文件保持不变。同名但不同参数须选定一种；已有名称或别名不被覆盖，需直接编辑原项。

旧库缺少图形、设备名或地面确认时列为“待补资料”；设备名可预填块名，地面属性不推定为否。用户可批量选择导入候选，再逐项从现有图纸拾取样本，补图形、图例及设备参数。未完成项保存为停用草稿。

切换前迁移已有的本箱功率记忆和图纸人工选择。实施阶段应明确切换标记：切换后新管理器是新设备库唯一共享资料写入口，普通材料表编辑先作为本箱覆盖保存，不再隐式回写全局设备功率；只有用户明确选择修改库项时才改变共享默认值。

旧的高级库保留独立读取与写入兼容，不与新 schema 混用。升级包只提供程序和默认空库模板，不覆盖用户目录；回退程序不删除新库，旧已保存 DWG 仍由兼容路径读取。库路径变更需复制全部引用资产并校验，再切换配置。

## 8. 性能基线与两项任务的边界

094 最新样例为新增系统图：程序区间 21782 ms，交互 31077 ms，放置确认后 9297 ms；源图复扫 4 次共 8657 ms，首次采集和后续采集共 5 次，建网共 5 次。解码 3 次、缓存命中 8 次，两次保存回读成功。主记录 106113 字段。这不是之前 093 的一次原位功率更新，不作为同场景提速比例的分母。

本方案预期收益是减少重新填写和材料表的重复图例生成。源图候选采集仍由扫描任务负责。当前已按块名记住功率、单次建网已复用部分轮廓，实际提速应以同场景 CAD 日志对照为准。

拟新增汇总计量：库读取次数与耗时、名称匹配命中／未知／冲突数量、图例读取／生成次数与耗时。正常已登记设备的材料表打开，图例生成、源图隔离和为截取图例执行的 Regen 次数应为 0；不等同于整条 CAD 命令不能有其他必要 Regen。

同一 DWG、配电箱、数据状态、日志等级分别测首次登记、已登记统计、新增系统图、仅功率更新和无变化更新。先预热，再恢复相同状态进行五次测量，报告中位数及范围。读取图形时的登记开销不能混入已登记查询，用户输入不能当作程序耗时，嵌套阶段不相加，不预先承诺百分比。

## 10. 验收清单

### 10.1 必要自动检查

- schema、UTF-8 完整往返、名称大小写、精确别名及冲突、非负整数功率、明确地面值、修订与路径引用。
- 新增、修改、删除、恢复，索引／资产缺失和损坏、发布中断、写失败、两个窗口并发写入及缓存失效。
- 注册项按名自动填值；未登记连接设备保留提示；辅助对象、断口阻挡及本箱明确排除不被库筛选误删。
- 当前输入和历史人工值覆盖库默认，包括人工非地面和 0W；库变更不静默改写旧图，实际设备数量按身份去重。
- 材料表已登记项复用图例，不进入 `ThumbCapture` 和源图隔离；修订变化仅使相关图例失效。
- 原位更新、无变化零写入、取消／失败回滚、保存重开、实际主记录回读及高级旧库兼容等必要流程回归。
