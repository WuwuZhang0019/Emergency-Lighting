本目录保存用户圈选并授权提取的 49 项天正默认设备：1 个明装配电箱、48 个灯具或标志。原始 DWG 和 SLD 来自已校验的 `output/设备库-002`；当前功率来自用户重新保存并导出的 `设备库-op-849505406.zip`，来源及字节摘要见 `import-manifest.json`。

46 个未删除灯具具有默认功率：35 项为 1W，11 项为 5W。楼层标志灯 `$equip_U$00000611`、吊装多信息复合标志 `$equip_U$00000691` 按用户确认补齐为 1W，其余 44 项功率保持导出值。配电箱功率为空；两条已删除设备保留删除状态及空功率。两个地面标志保留地面属性。

模板沿用原内置库身份，资料完整的 46 项默认启用名称匹配，供首次初始化后直接提供功率。用户导出文件中的个人识别预设不作为全体用户的默认图层配置。

该目录作为正式软件资源纳入版本控制，构建时复制进应急照明包，并内嵌到启动文件的备用运行目录初始化数据中。运行时仅作为默认来源；用户功率、名称等改动保存在当前 CAD 用户的可写设备库中。首次启动自动补齐默认项和缺失图形，保留已有设备身份、用户填写内容及删除状态；重复启动不重建已完整的设备库。

修改默认图形时同时更新索引、清单与校验证据。源 DWG 和 SLD 应保持原库字节；变更名称、功率和地面等默认数据须保持 `EL_DEVICE_LIBRARY_V1` 契约。正式提取及 CAD 使用说明见仓库 `docs/16_天正设备库圈选图块导入说明.md`。
