# v0.1.51 图例任务不再阻止功率编辑

日期：2026-10-15
状态：实现与 47 项定向检查通过；修正版兼容试用交付，真实 AutoCAD 2020 验收待执行

用户在设置默认功率时运行 `ELSTAT`，命令只显示“图例正在生成；请等待返回来源图纸”。直接原因是 `c:ELSTAT` 只要发现未完成的 `*EL:DLCaptureJob*` 就调用 `c:ELDEVLIB` 的等待分支，没有进入统计面板。该判断不区分编辑已保存参数与生成新图例，仅凭此消息不能确认任务仍在运行还是回调未完成。

本版取消参数编辑入口上的等待拦截：`ELSTAT` 打开主面板，`ELDEVLIB` 打开设备库，修改已有设备资料后沿用自动保存。保留图例任务、暂存文件及本箱上下文，新的显式打开操作不再自动返回旧面板。任务完成前停用会创建新图形或改变库归属的操作，功率、名称、地面和启用状态仍可编辑。

如果图例任务稍后完成，而功率已自动写入 `catalog.eld`，原任务的旧索引仍会触发冲突保护。回调保留同一设备库、同一设备身份的最新参数及待处理图形，随后继续保存图形时不恢复旧功率。新设备身份的复用要求图块名或明确别名匹配，避免仅凭设备编号绑定无关设备。

本次延续用户“提供新包以重新设置功率”的请求提供修正版，按新的命名约定生成 `应急照明-v0.1.51.zip` 和同名解压目录。内部兼容标识更新为 150，用于避免加载到旧运行目录；对外包名仅使用软件版本。压缩包路径通过追加 `.zip` 生成，避免把点分版本号末段当作扩展名截断。

完整解压到新目录，`APPLOAD` 加载 `START-CAD2020.lsp` 并确认提示 `v0.1.51`。打开设备库修改功率，按 Tab 或选择下一条后确认“已自动保存”；完成后用“功率参数”旁的定位按钮获取当前设备库的 `catalog.eld` 并反馈。

定向检查覆盖命令入口、任务保留、编辑权限、未完成图例时连续功率保存与关闭、延迟回调保留新功率、原有自动保存、图形拾取和源码约束。交付检查只证明对应文件、编码及合并入口一致，不替代真实 CAD 的图例任务、焦点事件与原图验收。
