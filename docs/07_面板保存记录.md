# 面板右侧保存记录
日期：2026-10-10
状态：067 实现完成，自动检查见验收记录，真实 AutoCAD 2020 验收待执行

## 使用

解压完整的 `应急照明-067.zip`，在 AutoCAD 中用 APPLOAD 加载包内 `START-CAD2020.lsp`，运行 `ELSTAT`。如提示选择模块，请选择同一包内的 `src/load.lsp`。

“回路与图块设置”窗口右侧新增“保存记录（本图）”。列表来自当前 DWG 内保存的记录，显示配电箱对象标识、实际回路数和状态；当前箱带 `[当前]` 标记。对象标识不是箱名，保证同名配电箱也能区分。新箱尚未保存时不会出现在列表里。

单击列表只查看标识与状态，不切换，也不保存。选中另一个箱子后，点击“保存当前并打开”：先检查目标箱能否重新识别、当前平面是否仍与面板一致，再写入当前功率缓存及 DWG 草稿；写入与回读成功后，在同一个面板流程中打开目标箱。目标箱按当前平面重新统计，不沿用旧设备数量。

切换只保存草稿，不同步原系统图，当前箱记录标为“待更新”。回到该箱核对后，点击“生成或更新”更新系统图。窗口内的“保存”仍按原流程工作。

当前箱、已删除的来源箱体和高级流程记录不能通过此按钮打开；高级流程沿用 `ELUPDATE`。目标无有效回路、当前平面已变化、缓存写入或 DWG 保存失败时，不切换，当前面板输入保留。成功保存后关闭图纸前仍须保存 DWG。

## 验收边界

没有新增外部数据库，不改变 XRecord 编码。记录以 DWG 中的配电箱句柄和系统图身份关联；复制对象或跨图复制不自动继承关联。
