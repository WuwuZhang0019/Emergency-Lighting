## 修复

- 完整 `run.eld`、`association.eld`、`drawing-store.eld` 等使用原生 `prin1` 直接写临时文件，再由 ADO 转换为 UTF-8，避免在 LISP 中构造整个对象的打印字符串。CAD 2020 临时文件使用 GB2312，交付构建严格转换相应打开方式和读取字符集。
- 完整保存记录与已核对的出图关联继续导出，不截断。`current-result.eld` 改为回路编号、功率、设备/导线成员、状态与问题等业务字段，加源图数量；明确标注未重复展开的内存几何、网络证明和库缓存。
- 增加命令行逐文件进度和 `progress.log`，保存开始、完成与进入 ZIP 的检查点。文件打印异常时关闭句柄、删除临时文件，不报告成功，已完成资料保留。
- 同时交付前一轮源码修复：诊断脚本正文嵌入 LISP，不在启动时释放 `.ps1`；初始化失败后普通命令不再反复弹选目录框；成功后的启动命令位于加载输出最后一行。
