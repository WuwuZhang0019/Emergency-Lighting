# 应急照明回路统计与系统图生成

日期：2026-10-05

状态：方案已落盘，功能待实现

从平面图中拾取应急照明配电箱，识别各条独立出线回路，统计每个回路内各类图块的数量，按用户配置计算设备功率，再利用既有动态块生成配电系统图。
