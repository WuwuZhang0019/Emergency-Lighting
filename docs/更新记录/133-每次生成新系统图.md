# 133 每次生成新系统图

日期：2026-10-14
状态：源码已实现；43 项针对回归与交付包检查通过，原生 AutoCAD 2020 验收待执行

`ELSTAT` 面板“生成或更新”改为“生成新系统图”。每次点击都经过 CCKK2 原生鼠标放置，创建新的箱体、回路及文字，并分配新的 `diagram-id`。已有输出及其记录不修改；同一来源箱体可以保留多张系统图，默认编辑最后一张。`ELGEN` 与 `ELUPDATE` 的显式生成也按此方式处理；高级统计的后台发布只保存草稿。

点击“保存”时，如果已有系统图，会另建草稿记录，保留旧图的实体和记录。保存记录列表继续显示各次输出；当前箱体只解码最新记录，较早的图保持独立关联。生成取消或事务失败时，回滚本次新对象与记录，旧图继续保留。源图复核、真实设备轮廓接触、动态块校验和 DWG 双路回读仍执行。

这项行为改变不保证提速。原位增量更新曾跳过无变化的实体；每次新建则需插入全部实体并保存新记录。先前提供的 129 和 131 日志只含 `ELSTAT` 识别，129 的 `NETWORK_SIGNATURE` 卡顿不受本项影响。若要比较，请在同一原图中分别记录点击生成后的 `ELPERF.log`，分开看鼠标等待与放置后程序时间。

有限适配器针对回归 43 项通过，记录见 [133 回归结果](../../tests/evidence/2026-10-14-generation-only-regression-133.json)。[133 交付检查](../../tests/evidence/2026-10-14-generation-only-package-133.json)核对 324 个目录/压缩包文件逐字节相同、32 个 LISP/DCL 严格 GB2312 往返、6 个本次修改的 LISP 模块可解析。扩展回归中另有 4 项图例/图库窗口模拟测试未通过，发生在本次未修改的窗口路径；不作为原生 CAD 验收结论。

原生 CAD 复测：完整解压并加载 133 包，在同一配电箱连续生成两次，分别选两个空白位置，核对两张图的回路、功率及句柄；确认旧图不变，保存 DWG 后重开并检查历史记录。再从旧图执行 `ELUPDATE`，应放置第三张；按 Esc 取消一次放置，应无残余新图。保留该轮 `ELPERF.log` 与 `ELTRACE-debug.log` 以量化耗时。
