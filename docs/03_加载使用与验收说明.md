# 03 加载、使用与验收说明

日期：2026-10-08。状态：源码及自动检查已交付，CAD 实测待执行。

## 1. 运行条件与加载

首版使用 AutoLISP、Visual LISP ActiveX 和 DCL，目标为 Windows AutoCAD 2021+，`LISPSYS=1` 或 `2`（修改后需重启）。Mac、LT 和其他 CAD 平台未验证。图纸须保存；识别范围为当前 DWG 模型空间二维对象。

将整个仓库放在可信且可写的本地目录，保留 `src/`、`ui/`、`config/`、`output/` 的相对结构。可将 `src/` 加入支持文件搜索路径后 APPLOAD `src/load.lsp`；也可在 CAD 命令行明确设置根目录再加载：

```lisp
(setq *EL:Root* "D:/CAD/Emergency-Lighting/")
(load (strcat *EL:Root* "src/load.lsp"))
```

未找到根目录时，加载器会请用户选择本插件的 `src/load.lsp`。配置和结果使用 UTF-8 数据关联表，读取使用 `read` 和字段校验，不执行配置中的代码。首次生产使用前完成下面的 CAD 清单。

配置读取和保存也会检查插件目录。根目录为空、类型错误或文件已移走时，选择完整包内的 `src/load.lsp` 即可重新定位；取消选择会停止本次操作，不会继续拼接空路径或建立配置。已有完整有效的目录和图纸设置继续沿用。AutoCAD 2020 兼容包必须完整解压。旧包界面目录缺少 011 标记时，需要选择新包 `src/load.lsp`；可先将旧 GB2312 包的 `config/*.eld` 复制到新目录，保留旧目录备份。`UPDATE-011.lsp` 可在尚未设置根目录的当前 DWG 中加载，只有目录检查通过后才显示可用提示，无需手工输入路径命令。

## 2. 命令与操作顺序

| 命令 | 用途 |
| --- | --- |
| `ELSETUP` | 采样箱体、导线、设备图层，可沿用已有采样；单位固定 mm，无需确认；参数回车直接采用显示值，输入 2 调整；首次或改动后输入 1 确认启用统计，回车保存草稿；已确认且未改变的毫米配置沿用确认结果；有效配置保留功率、模板和配对，失效配置先留备份 |
| `ELSAMPLE` | 追加 Panel／Wire／Device／Leader 样本；同层角色须登记相应块身份 |
| `ELGAPTEST` | 点选具体断口端点，临时高亮源／目标／竞争端点，查看拒绝理由；不保存配对、不生成图形实体 |
| `ELTRACE` | 拾取箱体及一段出线样本，集中核对全部出口和未知角色，建立隔离回路；输出阶段耗时与数量 |
| `ELPAIRGAP` | 明确拾取两个端点，说明人工例外原因，经端点占用／层与平面／全局出线隔离检查后保存；核对采用该箱体全部出线候选，若进线同层，先完成样图校准 |
| `ELPAIRLEADER` | 拾取一对跨层引线，登记引线身份，保存双向关系；正式统计仍检查整体归属 |
| `ELCLEARPAIRS` | 明确清理本图 Gap 或 Leader 配对，随后重新识别 |
| `ELSTAT` | 依次执行识别和功率表；功率表每次修改行后点“保存此行”，最后 OK 应用 |
| `ELPOWER` | 使用仍有效的统计重新编辑功率，保存并重算，无需重新追踪 |
| `ELISSUES` | 列出连接、功率和独立对象问题，选择序号高亮对应句柄；下一次拾取命令清理定位高亮 |
| `ELSAVELIB` | 把本图确认值存入项目设备库；同名但定义／动态状态不同的设备须重新核对 |
| `ELSAVERESULT` | 保存统计、连接依据和问题快照到 `output/` |
| `ELTEMPLATE` | 采集真实箱体／回路动态属性、三档样本、接线点、各档文字样本和排列向量 |
| `ELGEN` | 检查统计有效性、172W、真实属性映射，选择档位、顺序、预留、插入点及旋转缩放，临时预览后确认生成 |

采样、统计箱体、断口/引线配对和模板采集中的对象拾取会持续亮显，并在命令行显示对象类型、图层及句柄。已拾取的样本在选择下一个样本和核对参数时仍保持亮显；当前命令正常完成、取消或出错后统一清理。出口表选择项高亮；功率表选择回路高亮整条回路，选择类型高亮本次筛选范围内的同身份实例。亮显只改变显示反馈，不修改对象颜色、图层或几何。实际 CAD 上的视觉效果仍需实测。

`ELGAPTEST` 需要先采样配电箱、导线和设备，才能排除已接设备的整条导线。缺少采样时会提示先运行 `ELSETUP`（可以保存草稿），不再仅凭导线层显示匹配成功。有完整采样后直接选断口，参数自动采用默认值或新规则下已保存的搜索距离，无需逐项确认。

### v11 整箱统计流程

直接运行 `ELSTAT`，依次拾取箱体和靠近该箱出口的导线样本。有效旧导线层继续使用；无需预先采样每类设备。样本未能验证属于箱边出口时重新拾取，不以远处孤立线推断整箱。

出口表显示所有候选，可全选后取消进线及误识别项，不默认猜测哪根是进线。“补充导线图层”作用于整个箱体。发现箱边范围外导线时须补充或明确排除，未处理则整箱未完成。

未知图块按“有效名＋动态状态＋定义签名”分类，未确认不计负载、不作为导电节点；可保留未完成结果。角色会改变接触与整条导线断口排除，分类后重新构建拓扑。

功率窗口同屏列出回路和设备类型。点回路筛选及高亮，点设备行定位该类实例；保存每个修改行后 OK 批量应用到本图。另存设备库须勾选；保存的功率只触发统计重算。未完成回路的部分功率不并入完整回路合计；171/172W 合格，173W 超限。

配置版本 2 保存已确认角色和箱边出口；旧功率、模板及采样保留，不兼容旧断口配对清理并提示。核对期间源图变化不保存本次选择；结果过期后 `ELPOWER`、保存结果及生成均拒绝复用。

### v10 断口规则与操作

- 默认搜索距离为 **2000 mm**，沿所选端点的外伸方向搜索。
- 同一条 LINE/LWPOLYLINE 的任一端接了设备或配电箱，端点在设备真实区域内或中段穿越设备也按已接入处理，整条对象的两个端点均不参与自动搜索，也不能成为另一条线的候选；人工配对也不能绕过这项排除。
- 断口必须共线、相向、同高程，不提供横向、角度或高程偏差调节。内部仅保留 `1e-7 mm` 坐标和 `1e-10` 单位方向向量差的浮点计算余量。
- 非共线的交叉线、轮廓不阻挡续接；同高程且与续接路径共线的线段占用才阻止配对，不用对象包围盒代替共线判断。原有接触、T 接及不支持几何诊断仍保留。
- 双方互为唯一候选才自动配对；正式统计继续检查回路归属。预览不修改图形、不保存配对。

第一次读取旧规则配置时，搜索范围迁移为 2000 mm，旧容差参数归零，旧统计确认失效；采样、功率和模板保留。整箱模式版本迁移清理旧断口配对，跨层配对继续进行实例状态校验。在 `ELSETUP` 核对并保存后，下次沿用新规则参数；后续自行修改的搜索范围不会反复重置。

输入对应字母后回车：

| 输入 | 操作 |
| --- | --- |
| `N` / `Next` | 点选下一处断口 |
| `S` / `Swap` | 检查当前同一条导线另一端 |
| `R` / `Range` | 只改搜索距离，立即重查当前端点 |
| `L` / `Locate` | 放大到断口，退出时恢复视图 |
| `D` / `Details` | 查看前方搜索走廊内候选及拒绝原因；不列出走廊外对象 |
| `E` / `Exit` 或回车 | 退出并清理临时预览 |

正常操作：选断口 → 看结果 → 输入 N 继续，或回车结束。已移除预览中的 P 高级参数。若断口超过 2000 mm，例如约 2500 mm，输入 R 再输入 3000 即可。范围调整仅用于本次预览；正式统计在 ELSETUP 的参数选择中输入 2 设置同样范围并核对。

若出现错误，保留从 CAD2020 v11 加载提示到报错的完整命令记录，尤其是 `ELGAPTEST 失败阶段` 和对象信息。

### 参数提示如何选择

`ELGAPTEST` 自动沿用保存值或采用默认值，无需逐项确认。以下数字提示用于 `ELSETUP`：旧版 `Keep` 的意思是采用屏幕显示的参数，`Custom` 才是逐项修改。现在改为中文数字提示：**参数选择时回车或输入 1 直接使用显示值，输入 2 才调整**。调整时各项回车保留当前值，不会重置已保存的自定义参数。单位固定为 `mm`，不要求输入，也不修改 CAD 图形尺寸。

设置只显示以下三项。接触偏差用于识别已有接线，不用于放宽断口共线规则。

| 屏幕参数 | 用途 | 默认值 |
| --- | --- | --- |
| 线端允许接触偏差 | 判断普通线端是否实际接触 | 0.1 mm |
| 线端到设备轮廓允许偏差 | 判断端点是否接设备或配电箱 | 0.1 mm |
| 断口最大搜索距离 | 限制向前搜索长度，不代替共线和唯一性检查 | 2000 mm |

以下仅适用于 `ELSETUP` 的旧参数核对流程，v11 `ELSTAT` 可直接采用有效参数或默认值。**末尾的“识别参数确认”是另一项选择：未核对时回车或输入 2 保存草稿；已核对后输入 1 启用统计。** 草稿保存后，用 `ELGAPTEST` 检查典型断口、最大断口及邻近回路，确认应连接的目标正确且没有误选邻近回路，同时核对正常接线的偏差，再运行 `ELSETUP` 沿用采样和参数并确认。局部预览通过不代表整箱统计已通过，正式统计仍检查回路归属。

已确认且采样、参数数值和毫米单位未改变时，不重复询问确认。重新拾取样本、更改参数或将旧配置单位改为毫米后，须重新确认；配置保存失败时不显示成功。

## 3. 功率、模板与结果有效性

未知设备必须确认类别。照明灯默认 5W，疏散／出口标志默认 1W；本次输入优先于本图保存值，再优先于设备库。功率只接受非负整数；0W 要明确确认用途。超过 172W、未解决断点、归属冲突和功率缺项均阻止生成。整数运算超范围时报告 `POWER_OVERFLOW`，不输出正常总功率。

模板采集需要两种动态块的六个已显示正确档位的参考实例：箱体 0.3kW、0.6kW、1kW；回路普通、地面、预留。程序从真实属性列表选择档位属性，读取当前真实值及 AllowedValues，不猜测“可见性”等名称。各档点选接线定位点，回路各档再拾取 TEXT／MTEXT 统计文字样本，最后点选箱体相邻两个接线位置取得排列向量。模板样本须为正等比缩放，字体必须存在，输出图层与平面角色图层分开且可见、未冻结、未锁定。保留采集时最后一个箱体／回路样本，生成前会重新检查其属性允许值；删掉样本后重新采集。

实际回路文字模板必须含 `{回路功率W}`，还可用 `{回路编号}`、`{设备数量摘要}`；预留使用独立文字，不伪造 0W 和数量。实际回路只能选择普通或地面；预留须新增。预览显示各档采集轮廓、文字定位标记和逐回路文字明细；字体、动态块最终外观须通过真实模板的 CAD 视觉核对。

修改接线、块状态、几何参数、角色或配对后重新运行 `ELSTAT`；只修改功率可用 `ELPOWER`；只修改模板则重新排布。生成前和预览确认后均检查源快照。首次生成不会覆盖旧图；本次对象组成一个撤销组，失败只清理本次创建对象，启用 UNDO 且不存在外部未结束撤销组时才生成。

## 4. 已支持边界与保留项

导线支持 LINE 和开放 LWPOLYLINE，使用真实邻接线段的端部方向，允许内部转折和弧段。弧形断口没有自动延续模型，明确报告不支持；可用人工例外确认，但不能绕过平面、图层、端点占用或回路隔离。T 接、闭合线路、异常分支和其他配电箱均保留诊断。断口候选及共线路径检查使用平衡空间树，对完整前向走廊查询，不在最近候选处提前停止。对象采集和物理接触阶段仍有全量遍历，大图整体耗时需真实 CAD 测量。

v11 从全部模型空间 INSERT 建立包围盒索引，沿整条导线路径筛选后延迟读取轮廓，不按预采样设备层排除候选。图块轮廓读取当前块记录中的可见 LINE、LWPOLYLINE、CIRCLE、ARC 和嵌套 INSERT，忽略文字／属性，应用旋转、镜像和非等比变换。圆弧采用受控离散（局部误差按变换尺度限制到边界容差约 1/8，最多 4096 段）。实际灯具的内部几何、动态可见状态和接线轮廓仍需样图适配与核对。倾斜平面、外参、其他轮廓实体或退化轮廓报告不支持；不支持对象的包围盒只用于阻止未经验证的连接，不能作为确认连接的依据。

封闭区域要求可验证闭合轮廓；内部开放装饰线不作为孔洞。`EL_HOLE` 图层上的闭合轮廓是显式孔洞约定；没有语义的嵌套闭环报告 `AMBIGUOUS_REGION`，不能自动区分装饰环和孔洞。倾斜轮廓、HATCH 等未支持表达继续标为未完成。中段穿过另一配电箱时保守阻断整条导线，不计箱后负载。

图纸配置以保存路径隔离；改名／另存后建立新配置。人工断口配对保存端点、参数和整个处理范围快照，删除、移动、反转、改层或新增干扰对象时停用；这是一项保守校验，周边无关变更也可能要求重新确认。跨层配对另检查两个实例及其状态，并排除负载统计。跨 DWG、外参内部对象和任意弧端续接未实现。
