# 03 加载、使用与验收说明

日期：2026-10-09
状态：S01—S05 开发及聚焦自动检查完成；S06 交付包已构建，真实 CAD 验收待执行

## 1. AutoCAD 2020 加载

完整解压 `应急照明-025.zip`，APPLOAD 根目录 `START-CAD2020.lsp`，选择本包 `src/load.lsp`，确认命令行显示 v25。必须保留 `src`、`ui`、`config`、`output`、`templates` 的相对目录。新面板使用 025 界面标记，不能把更新 LSP 配合旧包的 DCL 使用。

仓库源码为 UTF-8，交付包全部 LISP/DCL 为严格 GB2312。**AutoCAD 2020 不直接加载仓库源码**。旧 GB2312 包的 `config/*.eld` 可备份后复制到新包；UTF-8 配置不能直接混入。先保存 DWG，识别和输出均使用模型空间，单位固定 mm。

## 2. 首次使用

1. 在当前 DWG 保留两个真实动态块的样本：箱体 `dfgjhdrtyjtfgj4SADFG3`、回路 `fghjftyuk`。程序不会炸开、重定义或绘制替代块。
2. 运行 `ELTEMPLATE`。可拾取一个 TEXT 外观样本，Enter 使用当前样式和有效字高；分别拾取箱体、回路样本。唯一匹配时自动保存属性映射，有歧义时按命令行真实属性和允许值集中选择。
3. 运行 `ELSTAT`，拾取平面配电箱，再拾取本系统任意一条导线确定图层。首次或箱口候选变化时集中核对实际出线，默认全选，只取消明确的进线、非本箱出线；不要为了消除错误取消真实负载回路。可以图面预览，无须逐条重新拾取。保存后相同候选沿用选择。
4. 主面板顶部选择同一箱体的 `0.3kW/0.6kW/1kW`。左侧每页 8 行，通过上一页/下一页切换；每条实际回路最后一列的真实复选框控制“地面”。点击回路，右侧仅显示该回路的设备数量和单个功率。预留行禁用功率、地面编辑。
5. 填写非负整数 W，`0` 为有效功率，空值为缺项。同名图块功率统一重算本箱全部相关回路。非法输入会阻止切换并定位输入框。点击“在图上查看该设备”只定位当前回路内的该类设备，Enter 返回；取消丢弃未保存草稿。
6. “保存”记录功率、档位和地面选择；已绑定系统图在校验通过后同步。“生成或更新”首次要求箱体插入点，可指定 WCS 旋转角和正等比缩放。在真实插入预览中核对母线覆盖、接线、档位及文字，输入 Yes 才保留；Enter/No 或取消撤销预览。

默认 `ELSTAT` 使用所选导线层及图块整体范围，保留 v24 的悬空端点、共线相向、同高程、双向唯一断口续接规则。逐回路使用现有追踪和完整性校验，不均分整箱功率。未完成、缺功率或超过 172W 的实际回路仍在主表显示，只能保存草稿，不能正式输出。

## 3. 系统图与更新

有 n 条实际回路时，输出 1 个箱体 INSERT、n+2 个回路 INSERT、n 个独立功率 TEXT。首回路相对箱体 `(6427,-5500)`，向下间距 1200；文字相对各回路 `(10636,-438)`。末两条固定预留，不写 `0W`，不创建功率文字。

- `ELPOWER`：编辑当前结果；新流程打开箱体主面板。
- `ELSTAT`：修改接线或设备后重新统计；已绑定系统图通过完整校验才更新。
- `ELGEN`：首次生成或更新当前箱体的一套受管系统图，不重复插入。
- `ELUPDATE`：保存重开后，选择原受管箱体、回路或文字，恢复 DWG 记录，重新识别来源并同步。复制实例和跨图对象不能自动继承关联。
- `ELISSUES`：查看高级识别问题；命令行同时报告系统图未更新及原因。

功率变化保留原文字句柄、位置和样式；地面/容量变化原位切换动态属性。回路增加默认追加在实际回路末尾，预留保持最后两行；种子消失时集中显示旧/新身份，只有明确确认删除旧回路并新增后才更新。不会按 R 编号或最近距离猜测对应关系。

单独移动文字不影响仅功率更新。结构变化发现手工布局时，用户选择按模板预览重排或取消保留现场。整套平移/旋转/正等比缩放必须保持成员关系；只移动箱体会被阻止。缺失文字可补建，缺失箱体/回路块、重复标识、锁层或动态属性失效需先修复。失败时保留最后成功图形并记录 stale 状态；成功事务的一次 UNDO 包含图形和 DWG 主记录。

本期没有常驻监听：只修改平面图而不重算时，旧文字不会实时更新。保存重开后的关联恢复也不表示已重新校验。

## 4. 数据与兼容

主记录位于 DWG 命名对象字典 `EL_FIXED_V1` 的 XRecord，实体附 XData；DWG 保存重开带走关联、模板、选项及功率副本。`output/diagram-*.eld` 仅为诊断导出。共享的 `config/block-powers.eld` 按有效图块名跨图复用；有效库值优先，未完成草稿中的明确空值优先保留。DWG 保存成功但外部文件写入失败时会明确报告，其他图纸暂不复用此次共享功率。

旧 `ELTRACE`、`ELSETUP`、`ELGAPTEST`、`ELPAIRGAP`、`ELPAIRLEADER` 和高级设备角色/功率库继续保留。高级 `ELPOWER` 仍使用按身份保存的旧功率，优先级为本次输入、本图保存、设备库；不会静默覆盖按块名功率库。高级结果也可通过 `ELGEN` 接入固定系统图；高级 `ELUPDATE` 集中复核出线。

旧模板配置仍可读取，但新固定生成必须运行 `ELTEMPLATE` 适配指定块。旧版未标记的生成图不自动接管；如需使用本版本，保留旧图作对照并首次生成受管图形。自动地面图块规则目前没有用户名单，仅保留接口及人工是/否优先级，不自动猜测。

## 5. 验收

执行 `python -X utf8 tests/run_fixed_checks.py` 复现聚焦证据，执行 `python -X utf8 tools/build_cad2020.py` 重新构建同序号 025 包。证据见 `tests/evidence/2026-10-09-fixed-diagram.md` 及对应 JSON。

真实 AutoCAD 2020 仍须按方案 06 的 S-A01—S-A23 检验：三档箱体和三档回路可见效果、母线覆盖、DCL 实际交互、UCS、保存重开、复制/跨图、锁层/Esc、一次 UNDO。自动检查和 GB2312 校验不能替代真实模板 CAD 验收。
