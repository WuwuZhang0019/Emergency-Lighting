# 142 放置结束与手动诊断导出

日期：2026-10-15
状态：实现完成；定向检查结果见下述证据，原始 DWG 的 AutoCAD 2020 验收待执行

## 行为调整

用户要求图块和文字完成后直接结束，并将关联诊断改为单独按钮按需导出。本版调整正常主面板的生成路径：

1. 放置前保存一次当前输入，保留原有完整编码回解、原生载荷回读、提交核对及失败回滚。功率、容量、编号、人工覆盖和起始导线配置仍可再次读取。
2. 鼠标确认箱体位置后，在创建回路之前检查模板、编号、设备库和完整源图。该次核对后的结果用于整组回路生成；源图发生变化则撤销刚放置的箱体，已保存输入保留。
3. 回路、功率文字、箱号、回路编号、用途文字沿用原创建逻辑和逐对象回读。各回路及文字完整生成后不再重复扫描源图、保存完整出图主记录或读取其提交上下文，也不执行全图重生成、计算全部实体范围及缩放定位。
4. 成功后的完整出图关联保存在当前图纸的内存中，输出身份使用新箱体的实体句柄区分。再次生成继续新建对象，旧图不改动；失败或取消不会将半成品加入诊断缓存。实体标签仍用于排除系统图输出，避免其被下一次平面识别当作设备。
5. 仍需关闭撤销组、删除临时事务标记和恢复命令设置；这些是确保取消、撤销和后续 CAD 操作正常所需的收尾。不能以自动检查宣称原生 CAD 的收尾耗时严格为零。

这次减少的是最后一个图块及文字完成之后的额外处理，并未省略图块、文字本身的创建，也未取消放置前的输入保存。后续修改平面仍需重新拾取、核对并生成；程序没有常驻监听。

## 手动诊断

主面板左侧增加“导出诊断日志”。生成结束后重新运行 `ELSTAT` 即可点击，无需重新拾取配电箱。也可直接运行 `ELDIAG`。

- 正常 `ELSTAT` / `ELGEN` 的事件与时间先留在内存，退出时不逐条格式化或写出诊断文件。
- 点击导出时生成 `output/ELMONITOR-日期时间-命令.md`，包含原运行时间轴、计数及诊断事件。另有“全部图块和文字完成后的收尾”时间，使用真实结束时刻计算。
- 最近一次成功生成的关联记录导出为 `output/diagram-标识.eld`；导出前核对成员是否仍存在、句柄与所属图纸及输出身份是否一致。外来或缺失成员会阻止关联导出，不修改 DWG。
- 如果此次只有统计失败或取消而没有成功出图，仍可导出本次有效运行日志。每张打开的图纸独立保留最近有效运行和最近成功出图的关联信息。
- 导出不结束正在打开的面板计时，返回面板后保留容量与设备库编辑内容。单纯打开面板、导出、取消，不覆盖之前的有效运行。
- **需在关闭图纸前导出诊断。**内存关联和时间轴不写入 DWG；图块、文字及当前输入仍随 DWG 保存。旧版已经持久化的关联记录继续支持读取和导出。旧高级调用路径继续保持原持久化行为。
