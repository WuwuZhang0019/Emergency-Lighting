# 130：已有系统图仅更新回路功率
日期：2026-10-13
状态：实现及交付包检查完成；原始 DWG 实测待完成

## 使用方法

1. 解压 `应急照明-130.zip`，在 AutoCAD 2020 用 APPLOAD 加载完整目录中的 `START-CAD2020.lsp`，运行 `ELSTAT`。
2. 拾取平面配电箱后，出现“拾取要更新的原系统图箱体”时，可直接选择自己已画好的系统图箱体。手绘图进入仅更新功率模式；本工具保存的原系统图可选择 `Power`（默认）或 `Full`（完整更新）。按 Enter 则继续新建。
3. 已进入统计面板时，也可点击“关联原图功率”选择目标箱体，包括更换目标或重新关联。按钮变成“更新回路功率”。
4. 核对平面回路及设备功率后点击“更新回路功率”。首次框选这一张系统图的全部回路编号和功率文字，包含属性时选中所属图块；Enter 完成选择。
5. 程序按平面实际编号与系统图编号精确匹配，忽略编号两端空白及英文字母大小写。编号相同、方向一致、同排且功率候选唯一时自动对应；位置不明确时高亮该回路编号，提示补点该回路现有功率文字。
6. 全部复核通过才一起写入。关联与统计输入保存在当前 DWG；保存 DWG 后，下次打开记录可继续复用。每次更新仍复核编号和原对象，不自动接管旁边的复制件。

## 修改边界

- 只替换功率文字中的单个数值，保留 W/kW 单位、前后缀、常用多行文字格式、图层、样式、字号、颜色、旋转和对齐锚点。例如 `P=0.020 kW` 可更新为 `P=0.044 kW`。
- 支持模型空间独立 TEXT/MTEXT，以及本地图块实例上的普通 ATTRIB；不拆块，不修改共享块定义、外部参照、ATTDEF 或字段表达式。复杂堆叠、多行属性和无法安全解析的格式不会写入。
- 单位明确的 W/kW 值可以自动对应；纯数字必须在需要补点时明确选择，按 W 解释。
- 不创建、删除或移动箱体和回路，不修改回路编号、预留回路、容量档位、用途或其他文字；仅功率模式不要求生成模板。
- 编号缺失、重复、目标删除、图层锁定、原绑定变化或功率格式不明确时停止。程序自动补出的 ZE 序号不能充当平面原生编号证据。
- 保存按钮仍只保存输入，不更新图中功率。取消或失败返回面板并保留输入；写入和关联保存处于同一撤销组，任何一项失败均走原有事务回滚。

## 原始图纸验收

自动检查不能替代真实 AutoCAD 验收。请在原 DWG 验证：首次框选后编号与功率对应正确；修改设备功率再更新只改变目标数字；保存并重开后无需重新框选；多个同编号或同排功率候选不会写错；取消、锁层或写入失败时原图和输入保持正确。尤其核对 MTEXT 格式、属性刷新、对齐文字锚点及 UNDO。
